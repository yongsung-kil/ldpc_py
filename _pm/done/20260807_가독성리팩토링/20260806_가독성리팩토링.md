## 목적

.py 코드의 짧아서 부정확한 변수명을 풀어 쓰고, 사람이 더 이해하기 쉽게 코드를 다듬는다.
동작(수치 결과)은 그대로 유지한다.

## 배경

- ㉮ `LDPC_base/`는 syndrome-aided 디코더, DAO LLR_MATRIX 로더, 원본 대응 채널 3종까지
  구현이 끝난 상태 (검증 완료, `_test/20260806_setup_구성_실험/README.md`, `차이.md` 참조)
- ㉯ 구현 과정에서 축약 변수명이 많이 쓰였고, 원본 C++ 용어와 이름이 달라
  코드와 C++를 오가며 읽을 때 대조가 어렵다

## 개선 원칙

- ㉮ 원본 C++ 용어와 정합: C++에 대응 개념이 있으면 그 이름을 따른다
  (예: total → sum_t, csum → check_sum). 코드만 보고 decoder.cpp의 어느 부분인지
  찾을 수 있게 하는 것이 목표
- ㉯ 축약어는 풀어 쓴다 (mx, er, es, Ba 등)
- ㉰ 원본에 없는 py 고유 개념은 뜻이 드러나는 이름으로 (idx_active, keep 등은 유지 가능)
- ㉱ 이름 변경과 함께 블록 단위 주석 보강 (각 단계가 C++의 어느 함수 대응인지)
- ㉲ 동작 불변: 수치 결과가 바뀌면 안 된다 (아래 회귀 확인 절차)

## 개선 후보 (사전 조사, 2026-08-06)

### decoder.py

| 현재 이름 | 후보 | 근거 |
|-----------|------|------|
| `mx` | `llr_matrix` 또는 `matrix` | 축약 |
| `total` | `sum_t` | C++ VN_Cal_HD의 sum_t 대응 |
| `raw` | `vnu_out_raw` 또는 `sum_t_minus_in` | C++의 sum_t − VNU_in |
| `c2v`, `c2v_vn` | `vnu_in`, `vnu_in_list` | C++ VNU_in 대응 (또는 c2v 유지 여부 결정) |
| `v2c` | `vnu_out` | C++ VNU_out 대응 |
| `csum` | `check_sum` | C++ CN_STATE.check_sum |
| `esgn` | `edge_sgn` | C++ Check_SRAM_sgn |
| `synd` | `syndrome` | C++ CN_STATE.syndrome |
| `er`, `es` | `edge_row`, `edge_shift` | 축약 별칭 제거 |
| `m1`, `m2`, `p` | `min1`, `min2`, `min1_pos` (임시 변수) | C++ min1_value 등 |
| `Ba` | `n_active` 또는 `batch_active` | 활성 프레임 수 |
| `it` | `iteration` (또는 `iter_no`) | 축약 |
| `dvmap`, `_col_dv` | `col_dv_idx` | llr_matrix.col_dv_idx()와 통일 |
| `le1`, `le2`, `was1` | `is_new_min1`, `is_new_min2`, `was_min1` | 의미 노출 |
| `r_bit` | `read_bit` | 축약 |
| `pos` | `min1_pos` | C++ 대응 |
| `sgnp` (two_set 경로) | `sign_parity` 또는 check_sum 계열로 통일 | 축약 |
| `_mx_vnu_quantize` | `_vnu_quantize_matrix` 등 | mx 축약 제거 |

### llr_matrix.py

| 현재 이름 | 후보 | 근거 |
|-----------|------|------|
| `a`, `b` (group_slices) | `row_start`, `row_end` | 축약 |
| `g`, `r` (루프) | `group_idx`, `row_idx` | 축약 |
| `vals` | `row_values_flat` | 모호 |

### channel.py, sim.py, run.py, pcm.py

| 현재 이름 | 후보 | 근거 |
|-----------|------|------|
| channel `m` | `llr_mag` | \|Lq\| 대응 (C++ Lq_ini_m) |
| channel `cwr` | 유지 | C++ 동명 변수 |
| sim `r`, `b` | `result`, `cur_batch` | 축약 |
| run `p`, `r` | `point`, `result` | 축약 |
| pcm `J`, `K` | 유지 (헤더 표기) + 주석 | Ref-C 헤더 용어 |
| pcm `E` | `num_edges` 검토 | 축약이나 관례성 있음 |

- 후보는 착수 시점에 확정한다 (표는 조사 메모이지 확정안이 아님)
- `hd`/`sd`/`cc`는 original의 HD_input/SD_input/CC_input 대응이므로 유지
