# 2SD/3SD 디코딩 구현

- 등록: 2026-08-09
- 상태: 완료 (2026-08-09). 실물 2SD/3SD LLR_MATRIX 반입 시 toy 파일 교체는
  기존 TODO "실물 파라미터 교체" 항목이 담당

## 목적

HD 전용인 디코더를 2SD(2-bit soft decision)/3SD(3-bit soft decision)까지 확장한다.
채널과 로더는 준비되어 있고 디코더 산술만 막혀 있다.

## 배경

- ㉮ 채널: rber의 2SD/3SD 출력(sd/cc 플래그)과 strong_error(2SD)는 구현 완료
- ㉯ 로더: LLR matrix의 2SD(ch 2개)/3SD(ch 4개) 모드를 파일명으로 판별해 읽음
- ㉰ 디코더: HD 전용 가드가 `decoder_main`에서 명시적 에러를 냄
- ㉱ 실물 2SD/3SD LLR_MATRIX는 저장소에 없음

## 확정 사항 (사용자 결정 2026-08-09)

- ㉮ **toy LLR_MATRIX 파일로 개발**하고 실물은 반입 시 교체한다 (HD와 같은 방식)
- ㉯ **균일 생성 모드도 2SD/3SD를 지원**한다. `internal_quantize.channel_llr`를
  region별 값(2SD 2개, 3SD 4개)으로 받는 설정 확장이 필요하다

## 설계 (확정, 근거는 `cpp_sd_analysis.md`)

- ㉮ **region 매핑**: 파일 ch 열 0..3 = 신뢰 내림차순. 2SD `region = 1 - sd`,
  3SD `region = 2(1-sd) + (cc XOR sd)` (very strong, normal strong, normal weak, very weak)
- ㉯ **VN 판정 동일**: 반전 조건 `sum_t <= 0`, 채널 항 부호 없음, 양자화와 CSW와
  row 선택 전부 HD와 같은 경로. 달라지는 것은 채널 항이 비트별 region 선택값이 되는 것 하나
- ㉰ **Edge Clear**: SD는 restart만 클리어 (iteration 1은 클리어하지 않음)
- ㉱ **Pre 단계**: iteration 0과 SD restart는 채널 magnitude를 min1/min2에 심고
  (부호는 read bit) check_sum과 edge sign은 0으로 남긴다. SD restart는 그 iteration의
  row 값을 쓰지 않고 판정을 read bit로 되돌리며 종료 시 CSW=|syndrome|
- ㉲ **시딩 magnitude**: 3-bit DAO 파일은 C++ 고정 상수 (2SD [5,1], 3SD [7,5,3,1],
  파일에서 읽지 않음). 균일 n-bit는 C++ 대응이 없어 1..top 균등 분할
  (3-bit 3SD에서 C++ 값과 일치. 3-bit 균일 2SD는 [7,1]이 되어 C++ 고정값 [5,1]과
  다르다는 점 유의, 파라미터는 사용자가 실행하며 조정)
- ㉳ **균일 생성 스키마**: `internal_quantize.channel_llr`가 HD는 정수 하나,
  2SD/3SD는 강한 region부터 2개/4개 리스트

## 검증 (2026-08-09)

- ㉮ HD 회귀: 파일 경로와 균일 경로 2종의 FER과 로그 CSV가 수정 전과 완전 일치
- ㉯ region 매핑 전 조합 단위 검사, 시딩 레벨 (2SD [5,1], 3SD [7,5,3,1]) 확인
- ㉰ 에러 없는 입력 iteration 1 성공, weak 에러 8개 정정 성공
- ㉱ SD restart 동작 실증: 정정 불가 프레임의 iteration 11(restart) 에러 수가
  채널 에러 수로 정확히 복귀 (2SD와 3SD 모두)
- ㉲ e2e 4종 완주: rber 2SD(FER 0), rber 3SD(FER 0), strong_error 2SD,
  균일 2SD(생성 파일명 ch10-3 확인)
