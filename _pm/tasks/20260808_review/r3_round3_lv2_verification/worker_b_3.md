## 4. 처방별 부작용

### ㉮ 생성물을 `.gitignore`에 추가

- ㉮ 이미 커밋된 파일은 그대로 추적된다. 실제로 닫으려면 `git rm --cached`가 짝을 이뤄야 한다 (E5)
- ㉯ 패턴이 `run.py:209-211`의 파일명 규약에 결합된다. 규약에서 `uniform`이 빠지면 패턴이 **조용히** 무력화된다 (E5)
- ㉰ 대소문자 처리가 플랫폼별로 갈린다. Windows는 매칭, Linux는 미매칭인 반면 코드는 어디서나 `.lower()`로 판별한다 (E5)
- ㉱ 생성물을 일부러 공유하려는 사용자는 `git add -f`가 필요해진다
- ㉲ 나머지 다섯 하위 문제가 전부 남는다

### ㉯ 파일명에 `dv_max` 추가

- ㉮ 판별부와의 결합은 안전하다. 세 위치 전부 실측으로 정상 로드 (E7)
- ㉯ 커밋된 `..._iter30.txt`가 새 규약과 어긋나 고아가 하나 더 늘거나 별도 정리가 필요하다 (E8)
- ㉰ 문서 2곳(`README.md:70-71`, `_pm/DONE.md:11`)의 예시 이름이 함께 바뀌어야 한다 (E8)
- ㉱ 이름이 길어지지만 파싱에 쓰는 코드가 접두 정규식과 부분문자열 검사뿐이라 파손 위험은 없다

### ㉰ 생성 위치를 `Sim_Output` 계열로 이동

- ㉮ **run 디렉터리를 쓰려면 구조 변경이 따른다.** run 디렉터리는 `report`가 만들고 `setup`은 그보다 먼저다 (E10). 이 선택지는 실제로 두 갈래다.
  - ㉠ **run 디렉터리 안에 생성**: 폴더 생성 시점을 `setup` 앞으로 옮겨야 한다. 대신 실행마다 매트릭스가 결과와 함께 보존되어 재현성 기록(B-14가 지적한 true 가지의 약점)이 오히려 좋아진다
  - ㉡ **고정 하위 폴더(`Sim_Output/_generated/`)**: 구조 변경 없이 지금 코드에서 경로 상수만 바꾸면 된다. 대신 이름 충돌(S3)은 그대로라 ㉯가 여전히 필요하다
- ㉯ round-trip은 위치와 무관하게 성립한다. 실측으로 두 위치의 FER/BER/avg_iter가 완전 동일 (E12)
- ㉰ Round 2가 쓴 "커밋 파일 md5 대조"라는 1회성 회귀 근거는 대상이 사라진다. 저장소에 박힌 테스트가 아니므로 깨지는 자동 검사는 없다 (E12-보)
- ㉱ 재사용(`use_input_llr_matrix: true`로 되돌려 그 파일을 지목) 시 run 디렉터리 방식(㉠)은 지목 경로가 실행마다 바뀐다. 고정 폴더 방식(㉡)은 바뀌지 않는다 (E13)
- ㉲ `llr_matrix.dir`을 안 읽게 되므로 문서 서술 3곳이 참이 되고 S7, B-9가 함께 닫힌다 (E14)

## 5. 조합 가능성과 잔여 위험

**상호 배타 아님. 셋 다 함께 적용할 수 있다.** 다만 중복과 의존이 있다.

- ㉰(어느 갈래든)를 적용하면 생성물이 이미 무시 폴더에 떨어지므로 **㉮는 신규 산출물에 대해 불필요해진다.** 다만 이미 커밋된 파일 1개의 처리(`git rm --cached` 또는 유지)는 ㉰와 무관하게 따로 결정해야 한다
- ㉰의 ㉠갈래(run 디렉터리)를 고르면 이름 충돌이 구조적으로 사라져 **㉯의 필요가 크게 준다.** ㉡갈래(고정 폴더)를 고르면 ㉯가 여전히 필요하다
- ㉮만 단독으로 고르면 S1만 닫히고 S3~S7이 전부 남는다. 가장 싸지만 가장 좁다

**셋을 다 적용해도 남는 것**

- **S4가 어느 처방으로도 닫히지 않는다.** 실측으로 범위를 확정했다. 3-bit 균일 산출물에서 이름의 `uniform`을 지우면 `edge_mag`가 `[3,2,1,0]`에서 DAO 기본값 `[7,5,3,1]`로 **조용히** 바뀐다. 4-bit와 6-bit는 `NotImplementedError`로 요란하게 실패한다. 곧 조용히 틀리는 구간은 `num_bits=3` 하나뿐이며, 세 처방 중 무엇도 이 구간을 건드리지 않는다.
  - 닫으려면 판별 근거를 파일명에서 **파일 내용**으로 옮겨야 한다. 현행 `save()`(`llr_matrix.py:233-259`)는 DAO 포맷 필드만 쓰고 균일 여부를 남기지 않으며, `load()`는 `num_param`에서 `edge_mag`를 역산한다(`:202-203`). DAO 포맷 무변경 요구가 있으므로 포맷 안에 표식을 넣는 안과 짝 파일(사이드카)로 빼는 안이 갈린다. **이는 별도 Decision이다.**
- S6(줄바꿈 플랫폼 종속)은 ㉮·㉰가 diff 소음을 없앨 뿐 원인을 없애지 않는다. `.gitattributes` 또는 바이너리 모드 저장이 따로 필요하다
- S2의 커밋 파일 1개는 세 처방 어느 쪽도 자동으로 지우지 않는다. 유지할지 추적 해제할지가 별도 결정 항목이다
