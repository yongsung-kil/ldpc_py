B. 알고리즘 요약

  1. 대상은 (1024,512) 폴라 코드의 BP(belief propagation) 디코더로, m-stage 팩터그래프 위에서 우→좌(L)·좌→우(R) LLR 메시지를 갱신한다.
  2. 문제: SC 디코더는 직렬로 latency가 크고, BP는 병렬 가능하나 매 클록당 1 stage만 활성화되어 HW 이용률이 1/m로 매우 낮다.
  3. 메시지 갱신은 scaled min-sum 근사식 (1)을 사용하며, 스케일링 파라미터 a로 성능을 SC 수준으로 끌어올린다(선행연구 [8]).
  4. 기법1(iteration-level overlapping): 데이터 의존성을 분석해 idle stage를 다음 iteration 계산에 미리 투입, latency를 m*max_iter → 2*max_iter+m-2로 축소(약 5배).
  5. 기법2(codeword-level overlapping): 서로 독립인 여러 수신 codeword를 idle stage에 채워 이용률 ~100%, throughput 약 m배(메모리 m-1배 증가).
  6. 기법3(joint overlapping): iteration index p와 codeword index i를 동시에 overlap 변수로 사용하는 통합 프레임워크로 이용률 100%(메모리 100% 증가).
  7. 기법4(folding): PE 구조가 stage마다 동일한 점을 이용, folding factor N(≤m)으로 stage 수를 줄이고 라우팅 네트워크로 메시지를 재배치해 HW를 N배 감소.
  8. folding과 iteration-overlapping을 결합하면 stage 수↓와 latency↓를 동시에 달성.
  9. 결과: 45nm 합성에서 Proposed-I/II가 원 systolic 대비 게이트 1.50/2.43배 감소, HW 효율 7.4/2.5배 향상(7-bit 양자화, max_iter=60).
  10. 한계: 폴라 코드 전용이며 성능(정정능력) 개선이 아닌 순수 HW 스케줄링/면적 최적화로, LDPC로의 직접 이식 대상 아님.
