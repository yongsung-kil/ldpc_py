B. 알고리즘 요약

  1. 대상은 소수 q와 정수 j<=q로 정의되는 array code C(q;j): 길이 q^2, 각 열 j개·각 행 q개의 1을 가진 (j,q) regular LDPC 부호.
  2. 패리티체크행렬 H(q;j)는 단위행렬 I와 순환치환행렬 P의 거듭제곱 블록으로 구성되며 Reed-Solomon 패리티체크와 유사한 대수 구조를 가짐.
  3. 각 열을 [x, x+i, x+2i, ..., x+(j-1)i]^T (mod q)로 표현하는 새 표현법을 도입해 인덱스 집합 T 위의 선형방정식 해집합으로 부호를 정의.
  4. 풀려는 문제: 일반적으로 매우 어려운 LDPC 최소거리 d(q;j) 계산을, j=4에서 기존 하한을 개선하는 것.
  5. 핵심 도구 - Lemma 2: C(q;j)는 x -> a x + b 형태의 affine 치환으로 이루어진 이중추이군 G에 대해 불변 -> 일반성 잃지 않고 codeword 지지집합을 표준형으로 가정 가능.
  6. Proposition 1: 두 열이 같은 위치에 두 개의 1을 공유하면 동일 열이므로 Tanner graph에 길이-4 사이클 없음 -> girth 6 보장.
  7. Theorem 3: q>=5에서 d(q;3)=6 (weight-4 codeword 부재 증명).
  8. Lemma 5 / Theorem 6: d(q;4)>=8이고 q=5,7이면 d(q;4)=8, 임의 소수 q>7이면 d(q;4)>=10 (weight-6/8 codeword 부재를 4개 클래스 case 분석으로 증명).
  9. 부수 결과: j=3의 weight-6 codeword 지지집합과 C(5;4),C(7;4)의 weight-8 codeword 지지집합을 군 G의 궤도로 완전 분류.
  10. 한계: j>4 일반화는 case 수 폭증으로 곤란, 순수 이론이며 복호기·시뮬레이션·HW 전혀 없음.
