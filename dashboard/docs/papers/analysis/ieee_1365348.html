B. 알고리즘 요약

  1. 대상: rate (p-1)/p QC-LDPC, H=[H1,...,Hp], 각 Hi는 m×m circulant (다항식 hi(x)로 완전기술).
  2. 문제: irregular column weight를 가진 QC-LDPC의 정정능력(최소거리)을 설계 단계에서 보증할 정량 지표 부재.
  3. 핵심기법1(Theorem 1, bit-oriented bound): HᵀH의 정렬 고유값 µ1>...>µs와 열/행 가중치 ωi로 최소거리 하한 d ≥ (2ω1−µ2)m / (ωp²·(Σωi²/Σωi² − µ2)) 유도.
  4. 핵심기법2(Theorem 2, parity-oriented bound): HHᵀ의 고유값 기반으로 두 번째 하한 d ≥ ... 유도 (irregular 가중치 반영).
  5. 식 의미: 고유값 비 µ1/µ2가 작을수록(그래프 확장성 우수) 짧은 사이클 수가 적고 최소거리 하한이 커짐 → 설계 기준으로 사용.
  6. 예제: (217,7,1) difference family의 5개 base block으로 rate 3/4 QC-LDPC 구성, regular/irregular 각각의 hi(x) 제시.
  7. 관찰: eigenvalue ratio 0.5469(min)인 regular 부호가 0.9543(max)보다 6-cycle 수 1,085 vs 6,727로 적음 (Table II).
  8. 결과: BER 10⁻³에서 min-µ2 부호가 worst 대비 약 0.4dB 우수; irregular에서도 유사 경향.
  9. 검증: AWGN 시뮬레이션 BER 곡선(Eb/No 2~3.4dB) — 유도 bound가 설계 기준으로 유효함 확인.
  10. 한계: 2쪽 요약본, 디코더/양자화/HW 없음, 단일 rate·단일 채널(AWGN) 예시뿐.
