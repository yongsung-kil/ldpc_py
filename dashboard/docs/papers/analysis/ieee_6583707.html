B. 알고리즘 요약

  1. (N,K) LDPC를 belief-propagation(SPA)로 복호하되 HW 비용 큰 tanh를 min-sum으로 근사, 정규화 계수 α로 보정한 NMSA가 기준.
  2. 문제: 기존 NMSA의 α는 채널 SNR·iteration에 의존하나 실무에선 전 SNR·전 iteration 고정값이라 정확도 손실.
  3. 이론(ref[10])상 α는 평균상호정보 I_A에 따라 iteration마다 변해야 하나 I_A는 실측이 어려움.
  4. 핵심: α를 실행 중 쉽게 측정되는 p(실패한 parity-check 식 비율)의 함수 g(p)로 대체 — α = g(p).
  5. 정규화 적응함수 g(·)를 LUT로 사전 구성, horizontal processing에서 L_mn = g(p)·sgn(...)·min(...)로 적용 (식 9).
  6. g(·)는 이론적 유도 대신 Monte Carlo 훈련으로 MMSE 기준에서 결정.
  7. 훈련 절차: 여러 채널·SNR에서 (p, α_opt) 데이터 수집 → curve fitting → 샘플링·양자화로 LUT 생성.
  8. p가 클수록(초기 iteration) α가 작고, 수렴할수록 α가 1에 근접하는 형태(Fig.1).
  9. 결과: DVB-S2 rate 2/5,3/5 (64800) 코드에서 최적 고정 NMSA 대비 약 0.2dB gain, SPA와 0.1dB 이내(최대 iter 50, AWGN, BPSK).
  10. 한계: HW 미설계, 시뮬만, LUT가 특정 부호·훈련 채널 종속. offset min-sum·turbo에도 적용 가능하다고 언급.
