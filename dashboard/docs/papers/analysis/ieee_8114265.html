B. 알고리즘 요약

  1. 대상은 time-invariant SC-LDPC convolutional code (SC-LDPC-CC): 반무한 parity-check H가 HsT 블록을 c씩 수직 시프트해 반복, rate R=(a−c)/a, syndrome former constraint length vs=(mh+1)a.
  2. 문제: 기존은 QC-LDPC 블록부호를 unwrapping해 SC-LDPC-CC를 얻어 constraint length가 큼 → 복잡도(인코딩/복호 ∝ constraint length×column weight)가 큼.
  3. 핵심: 중간단계(unwrapping) 없이 **symbolic parity-check H(x)/HsT를 직접 설계**하고, 고정 entry(all-one border) 제약을 제거해 자유도 확보.
  4. cycle을 HsT 열내 1의 위치차 δ_{i,j}(sl→el)의 부호합 =0으로 표현(길이 2L), starting/ending level 정합 규칙으로 cycle 존재조건을 대수화.
  5. 이 표현으로 주어진 girth g(6/8/10/12)에서 mh(또는 Lh)의 이론적 하한을 Type-1/2/3·w=c=2,3별로 유도(예: g≥8, w=c=3에서 mh≥a(a−1)/8; g≥10은 "difference-of-differences 무중복"이 필요충분).
  6. Type-1(monomial)/Type-2(binomial)/Type-3(trinomial, Perfect Difference Family 활용) 별로 하한에 근접·도달하는 명시적 구성행렬(식31~44) 제시.
  7. g≥8 이상은 exhaustive search 불가 → 정수계획(IP) Min-Max 모델로 등가변환(Lemma 2,3) 하에서 최소 mh 탐색.
  8. border-of-ones 제거로 mh가 Fossorier[17] 대비 약 절반; 예: rate-14/17 g=8 부호 C1은 vs=646 (Tanner code vs=5185 대비 대폭 축소).
  9. 결과: BPSK/AWGN, full-BP 및 sliding-window(100 iter) 복호에서, 작은 window(W=273/38)에서는 짧은 constraint length 부호(C1,C2,C3)가 기존(Tanner/packing/R&M) 대비 우수; 단 C2는 waterfall 급하나 error-floor 존재.
  10. 한계: HW 미설계, AWGN 시뮬만, SC convolutional 계열이라 NAND 블록부호 대상과 부호·복호(window) 구조 상이.
