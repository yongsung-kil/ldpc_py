B. 알고리즘 요약

  1. 대상은 QC-LDPC(3,15)-regular (1890,1512) rate-0.8, WiMAX (1056,528) irregular rate-0.5, PEG (4000,3200) rate-0.8 등 다양한 구성의 binary LDPC.
  2. 문제: SPA/MSA가 trapping set(소수 VN·홀수차 CN 구조)에 갇혀 고SNR에서 error-floor 발생, 기존 대책(bit-pinning, 후처리)은 특정 코드의 dominant trapping set 사전지식 필요.
  3. 모델: BPSK+AWGN, LLR 입력. 복호 실패 시 전 iteration 중 불만족 CN 최소집합 C0와 그 상태 u0를 추적.
  4. 1차 backtracking: |C0|<=tau이면 소형 trapping set으로 간주, N(C0)(불만족 CN 인접 VN) 각각을 u0 대비 최대 LLR로 flip 후 재복호, 성공하면 종료.
  5. flip은 boundary node(실제 오류 VN)를 맞히려는 trial-and-error — 맞으면(hit-trial) trapping set이 더 작은 부분집합으로 축소되어 탈출 가능.
  6. 2차 backtracking: 1차 전 trial 중 u_i != u0인 것에 대해 상관 lambda_i=<y,chi(u_i)> 최대인 gamma개를 ML로 hit-trial 후보 선정, 각 후보의 새 C*로 다시 backtracking.
  7. 구현 디테일: 6-bit fixed-point scaled MSA(scaling 0.75~0.815), correlation은 u0와 다른 소수 비트만 가중합해 저비용 계산.
  8. error-floor 예측: 중요 trapping set 목록(error-impulse 탐색)+각 실패확률을 반해석적 적분(Q함수 근사·외삽)으로 합산, backtracking 후 floor까지 예측.
  9. 결과: 1차 backtracking으로 (1890,1512) floor 2자리수↓, PEG (4000,3200) 4자리수↑ 개선, 2차 backtracking 추가 1자리수↓; P_B(M1+M2)~10^-3로 고SNR 오버헤드 무시가능.
  10. 한계: HW 미설계(원 디코더만 FPGA 참조), 저SNR에서는 재복호 비용 큼, undetected error rate가 backtracking으로 약간 증가.

| 재복호(backtracking) 루프·flip 후 재시작 | decoder.cpp LDPC_Decoder() | 이터레이션 루프 외곽에 재시작 제어 추가, 실패시 재호출 |
| 불만족 CN 집합 C0 추적·최소화 | decoder.cpp C2V_Cal(), CNU_Update_New_Mag() | CN 만족여부 집계 결과 재사용 가능 |
| flip 대상 VN의 LLR 최대치 주입 | ecc_data.h PARAM_LLR, decoder.cpp Get_VNU_Table_Idx() | 특정 VN 입력 LLR을 반대극성 max로 override |
| 조기종료(성공 판정) | partial_CRC.cpp partial_crc_HW_T4(), full_CRC.cpp | 재복호 성공/실패 판정에 재사용 |
| correlation <y,u_i> 계산 | 대응 없음 | ML hit-trial 선정용 신규 상관 연산 필요 |

적용 가치: 중간 — decoder.cpp 이터레이션 루프에 재시작·flip override만 얹으면 되어 이식은 쉬우나(코드 무관 error-floor 저감), 재복호 반복이 NAND 실시간 latency 예산과 상충하고 Prime ECC의 partial-CRC 조기종료·적응형 LLR과 통합 검증이 필요.
