B. 알고리즘 요약

  1. 대상은 (1270, 652) QC-LDPC (rate≈0.51), Min-sum 복호, AWGN/BPSK, Imax=15.
  2. 문제: 저전력 LDPC 복호에서 회로 off/단순화보다 전원전압 Vdd 스케일링이 P∝Vdd^2로 절감효과 큼 — 하지만 피드백 루프라 pipelining 불가, 병렬화는 HW 중복 필요.
  3. 핵심: 대부분 수신어는 Imax보다 훨씬 적은 iteration에 수렴 → 잔여 iteration을 예측해 남은 구간을 느린 클록/낮은 Vdd로 돌려 시간 T를 다 쓰되 전력 절감.
  4. 예측 지표는 NUCE(number of unsatisfied check equations) S(k) — 수렴 케이스는 초기 fluctuation 후 piecewise 기울기로 0에 하강.
  5. In situ 예측(Algorithm A): 연속 두 iteration의 큰 감소(∆S(k),∆S(k-1)>D)에서 기울기 L=(∆S(k)+∆S(k-1))/2, 잔여 Ip=βS(k)/L, 여유계수 β로 over-scaling(→error floor) 방지.
  6. 각 iteration마다 Ip와 남은 시간으로 discrete 전압 Vi 중 조건 만족 최대 Tpd,i 선택.
  7. Initial 예측: 초기 S(0)가 작을수록 빨리 수렴 → offline threshold SVthi로 S(0) 비교해 시작부터 낮은 Vi 선택(비교 몇 번).
  8. 두 예측 결합 가능(Algorithm A 초기 V0를 initial 예측 전압으로 대체).
  9. HW 오버헤드 작음: ROM/레지스터에 d-1(보통 d=3~4) threshold + 비교기 + 소량 로직; 결과 Vdd=1.1/1.0/0.9/0.6V, β=1~2에서 성능손실 없이 동적전력 최대 50% 절감, SNR↑일수록 절감↑.
  10. 한계: 시뮬만(전력은 first-order CMOS 모델 추정), 정정능력·avg iteration은 개선 안 함, β 과소(0.8)면 성능열화, gate count/throughput 수치 없음.
