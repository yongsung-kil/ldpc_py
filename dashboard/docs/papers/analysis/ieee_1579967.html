B. 알고리즘 요약

  1. (j,k)-regular QC-LDPC: PCM은 순환 shift 단위행렬 I_{x_{s,t}} 블록으로 구성, 길이 N=km, rate R≥1-j/k (예제 R≈0.56).
  2. 문제: OMP 복호는 CN/VN 갱신을 겹쳐 throughput ~2배를 노리지만, 기존 SFT 부호는 항상 최대 gain에 도달하지 못함.
  3. HW 모델: j개 k-input CNFU + k개 j-input VNFU + j×k dual-port 메모리뱅크, throughput gain G = 2mn/(n·w_cv + (n-1)·w_vc).
  4. 핵심: intra-iteration 대기시간 w_cv(및 inter w_vc) 최소화, 제약은 데이터 의존성 + HW 제약 w_cv+w_vc≥m; w_vc=m-w_cv일 때 HUE 100%.
  5. 스케줄링([18]): 각 VNFU가 자기 reference block row를 선택 → w_cv*가 최적 w_opt(모든 c,r에 대한 최대 column-address 차이의 최소)와 같음을 증명. [8]의 방식은 준최적.
  6. 코셋 구성: Z*_m을 코셋 C_ui={ui,ui·a,...,ui·a^{k-1}}로 분할, j개 coset leader 선택, x_{s,t}=u_{i_s}·a^t로 설정 → SFT 부호를 부분집합으로 일반화.
  7. coset leader 변경 = 블록행 순환 shift → 대기시간은 바뀌나 girth/d_min은 불변.
  8. 성질: girth g≥6, j+1≤d_min≤(j+1)!, even j면 d_min≥j+2.
  9. 결과: AWGN/BPSK에서 SFT/cyclotomic/coset 부호 BER 동일(N=981, R≈0.56); 예 m=109,j=4,k=9에서 SFT는 G≈1.89이나 coset 부호(H2,H3)는 w_cv*≤m/2로 HUE 100%, G≈1.98.
  10. 한계: BER 개선 없음(성능 동일), HW 합성/gate count 없음, rate 낮음; 이득은 throughput/HUE에 국한.
