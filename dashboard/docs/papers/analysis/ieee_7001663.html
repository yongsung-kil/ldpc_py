B. 알고리즘 요약

  1. 대상은 (dv=3, dc=6) regular LDPC(N=1008), BSC 채널, 유한정밀 Min-Sum 디코더 (q=4bit 메시지, q~=5bit APP).
  2. 풀려는 문제: 나노공정 회로의 faulty logic로 인한 연산 노이즈(computation noise) 하에서 MS 디코더가 얼마나 견디는지 정량화.
  3. 노이즈 모델을 wire 노이즈가 아닌 가산기/비교기/XOR 연산 단위에서 정의 (error injection function ı(v,e), XOR 기반).
  4. 가산기 오류: full-depth(E=V)와 sign-preserving(E={0..+Θ}) 두 모델, 오류확률 pa. 비교기는 min↔max 뒤바뀜 확률 pc, XOR는 flip 확률 px.
  5. noisy MS의 density evolution 방정식을 유도(Appendix A), 대칭성·집중성(concentration)·수렴성 증명을 [3]에서 일반화.
  6. 오류확률 하한 Pe ≥ pa/(2Q) (sign-preserving), Pe ≥ pa/2 + pa/(4Q) (full-depth) → noisy 디코더는 pa>0이면 항상 error floor 존재.
  7. 새 임계값 정의: Lipschitz 상수로 Pe(∞)(χ)의 급변점을 잡는 functional threshold χ̄, noiseless threshold의 일반화.
  8. 비직관적 관찰: µ=1에서 가산기 노이즈가 fixed-point attractor를 탈출시켜 오히려 정정능력이 증가할 수 있음.
  9. channel scale factor µ 최적화가 유한정밀 성능을 크게 좌우 (µ=6이 BP에 근접). full-depth 가산기가 가장 치명적 component.
  10. 한계: HW 미구현, BSC·대칭·memoryless 가정, hard-decision 입력, NAND/soft-read와 직접 관련 없는 순수 이론·시뮬 분석.
