B. 알고리즘 요약

  1. 대상: (d_v, d_c)-regular binary LDPC 부호를 BSC(crossover ε)에서 hard-decision message-passing으로 복호.
  2. 문제: Gallager algorithm A(MB_0)만 벤치마크로 쓰여왔으나, 그 구성블록인 majority-based 알고리즘 계열의 stand-alone 성능이 미규명.
  3. 정의: order b의 MB 알고리즘 MB_b — 변수노드는 채널 메시지 m_0를 전달하되, extrinsic 입력 중 d_v-1-b개 이상이 m_0와 불일치하면 뒤집는다(일반화 다수결). 체크노드는 입력 부호곱 전달.
  4. 분석: density evolution으로 오류확률 재귀식 p_{l+1}=h_ε(p_l) 유도, 고정점·threshold를 분석.
  5. threshold ε*(b): h_ε(x)<x를 만족하는 최대 ε. 다항식 f_ω, g_ω로 정의되어 많은 경우 최소양근으로 해석적 계산 가능.
  6. 핵심 정리(Thm 3): 최소 양의 steady point ω_min이 threshold의 상계이며, 다수 앙상블에서 ε*=ω_min으로 tight함.
  7. Thm 6/7: d_v가 짝수이거나 특정 조건이면 상계가 정확히 달성됨을 Descartes 부호법칙으로 증명.
  8. 수렴속도(Thm 4,5): 낮은 order MB가 후기 반복에서 빠르며, MB_0(=Gallager A)는 지수수렴인 반면 다른 MB는 초지수(super-exponential) 수렴.
  9. 결과: (6,10)-regular, length 100000 부호에서 BER ~10^-5일 때 저차 MB가 Gallager A 대비 2.7 dB/0.5 dB 우수; 평균 iteration도 낮음(예 5.60 vs 13.29).
  10. 한계: BSC 1-bit hard-decision 전용, 이론/시뮬만이며 HW 미설계, error-floor 미분석.
