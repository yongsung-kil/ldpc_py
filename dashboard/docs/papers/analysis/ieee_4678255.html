B. 알고리즘 요약

  1. 대상은 n-queens 문제에서 유도한 Queen-matrix로 구성한 irregular LDPC로, H = [Hp | Hd]이며 Hp는 (N-K)×(N-K) dual-diagonal, Hd는 permutation(queen) submatrix 배열이다(Fig.2).
  2. 풀려는 문제: 일반 LDPC 인코딩은 복잡도가 부호길이 제곱에 비례해 느리고, 큰 N(>1000)에서 HW 구현이 어렵다.
  3. Queen-matrix는 벡터표현(예 Q(5)=(1,3,5,2,4)), 순환·shift 생성, 직교성([Q]^T=[Q]^-1) 특성으로 4-cycle을 방지하고 저장량을 n×n → n으로 줄인다.
  4. 핵심 기법: R = S×G(data S × generator G) 인코딩을 submatrix 곱으로 분할하는 block-coding schedule을 설계한다.
  5. Step1: data 행렬 S를 열 기준 u개 m×v submatrix로 분할(부족분 zero-fill).
  6. Step2/3: generator G를 열 기준 l개로, 다시 행 기준 u개로 이중 분할해 Gij(v×n) 얻는다.
  7. Step4: S×Gj = Σ_i Si×Gij로 submatrix 곱을 병렬 수행 후 합산(식 7), l×u회 submatrix 곱 + 2회 덧셈.
  8. submatrix 차원 m,n,l,u,v는 (i) queen-matrix 차원, (ii) FPGA 곱셈 대역폭, (iii) RAM/SDRAM 버스폭 세 요소로 결정해 메모리·throughput 병목을 완화한다.
  9. 결과: rate-1/2 (1008,504)/(6144,3072)/(12288,6144) 부호를 SPA 복호(AWGN, BPSK)했을 때 random 부호 대비 BER이 약간 상승(길수록 상승폭 작음), Verilog+Modelsim에서 부호화시간 14.6~36.1% 단축.
  10. 한계: 정정성능(BER)은 소폭 악화, gate count/절대 throughput·FPGA 실측 없음, generator 행렬 dense 곱 기반이라 dual-diagonal 선형 인코딩 대비 이점 불명확.
