B. 알고리즘 요약

  1. 2-user 협력 무선망에서 각 사용자가 EG-LDPC(781/1023)로 코드워드를 방송, BS는 4개 패킷 C1~C4 수신 (C3,C4는 GF(4) 네트워크코딩 패킷).
  2. 기존 [1]은 BS에서 4개 개별 디코더 필요 — 릴레이 재인코딩·수신단 복호기 수를 줄이는 것이 목표.
  3. 채널모델은 Rayleigh 페이딩 + AWGN, LLR Li,n = 2*hi*yi,n/σ².
  4. 각 사용자당 PWBF(Parallel Weighted Bit-Flipping) LDPC 디코더 1개만 사용, 둘이 extrinsic soft/hard 정보를 교환하는 조인트 message-passing.
  5. PWBF 신뢰도 Ei,n = Σ(2sm−1)|wn,m| − α|Li,in,n| (α=1.8), unsatisfied check가 가장 불신뢰 VN을 지목, 누적 metric Fn ≥ Fth면 flip.
  6. GF(4) 관계식 Z1=I1+I2, Z2=I1+2I2로 한 사용자 추정 Ĉ1에서 다른 사용자 C2의 확률/LLR을 유도.
  7. 유도된 extrinsic LLR L2,3, L2,4를 채널 LLR에 합산 L2,in=L2+L2,3+L2,4 후 PWBF 재복호, 두 디코더가 교대로 반복.
  8. 학습/최적화 절차 없음 (고정 α, 고정 threshold).
  9. 결과: 다이버시티 order 3 유지하면서 [1] 대비 약 5dB 코딩게인, 2회 반복만으로 큰 개선.
  10. 한계: HW 미설계, 시뮬만, 특정 2-user/GF(4) 네트워크코딩 프로토콜 전제 — 일반 NAND 채널 무관.

적용 가치: 낮음 — 무선 협력망 GF(4) 네트워크코딩과 PWBF에 결합된 구조로 NAND binary QC-LDPC 디코더에 떼어 쓸 요소가 없음.
