B. 알고리즘 요약

  1. 대상은 multitype QC-LDPC = multiple-edge protograph를 cyclic lifting한 부호로, weight-matrix W와 slope-matrix S 두 행렬로 표현.
  2. 각 블록 H_ij는 w_ij개 CPM(circulant permutation matrix, size m)의 합; type-w는 모든 w_ij≤w.
  3. 풀려는 문제: 주어진 W의 최대달성 girth g_max(W) 판정이 기존 [31] 방법(모든 부분행렬의 inevitable-cycle 패턴 P_2i 검색)은 지수복잡도.
  4. 핵심 기법 1단: cycle을 admissible chain으로 표현(Prop 2.3), slope값과 무관하게 항상 성립하는 chain을 inevitable chain으로 정의, 멀티셋 M1(A)=M2(A)로 판정.
  5. Lemma 3.1: g_max(W) = 최소 inevitable chain 길이 → Algorithm 1(DFS)로 다항적 판정, 랜덤 서치로 더 큰 girth/min-distance 상한 weight-matrix 생성.
  6. 핵심 기법 2단: 주어진 W·목표 girth g에 대해 Algorithm 2(DFS)로 slope-matrix를 왼→오 재귀 구성, m=∞(등식) 조건으로 non-proper slope 배제 후 최소 CPM-size m 선택.
  7. min-distance 상한 U_dmin(W)(Eq.1, permanent 기반), U_dmin(H)(Eq.2, 다항식 weight) 두 상한으로 부호 품질 평가.
  8. 최적화: slope·CPM-size를 여집합에서 임의 선택 가능해 더 작은 CPM-size 확보; Algorithm 2 복잡도는 다항(o(n·g²)).
  9. 결과: 동일 girth/column-weight에서 [16][18][20][23]~[25][31] 대비 작은 CPM-size·큰 min-distance(예 24 vs 22)·적은 (6,8)-cycle; SPA 시뮬 BER/FER이 PEG·random·CCSDS·802.11n/ac·5G BG1 표준부호와 동등 이상.
  10. 한계: 순수 부호구성 이론(HW·디코더 미설계), min-distance는 Magma로 사후계산, 성능검증은 표준 SPA 시뮬뿐.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| multitype QC-LDPC H-matrix 구성(weight/slope) | ecc_top.cpp Load_PCM() | Prime는 특정 type-I binary QC-LDPC 고정, multitype(다중 CPM) 재구성은 재검증 부담 큼 |
| girth/min-distance 최적 slope 탐색 | 대응 없음 | Prime는 H-matrix 설계 단계 코드 미포함(부호 고정) |
| 표준 SPA 복호(성능 검증용) | decoder.cpp LDPC_Decoder() | Prime는 min-sum 기반, 부호구성 자체는 디코더와 무관 |

적용 가치: 낮음 — 디코더·HW 요소가 전무한 순수 부호구성 수학 이론으로, Prime의 고정 binary type-I QC-LDPC를 재설계하지 않는 한 떼어 쓸 실행 요소가 없음.
