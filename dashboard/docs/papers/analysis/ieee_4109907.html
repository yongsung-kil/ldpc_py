B. 알고리즘 요약

  1. 대상은 DVB-S2 표준(AWGN 채널, BPSK), 코드길이 L=16200, rate 1/2~9/10의 8종 QC-LDPC.
  2. 기존 rate-compatible(puncturing 기반) 방식과 달리, 서로 다른 rate의 H행렬을 독립적으로(공유 없이) 구조적 변형만으로 생성하려는 문제를 다룸.
  3. 채널 모델은 표준 AWGN, 변조는 BPSK로 단순화해 가정.
  4. 핵심 기법은 replacement and expansion: 베이스 행렬 Hb(M×N, Vandermonde형 구성)의 각 원소(1 또는 0)를 p×q 크기의 서브행렬(Iq, 0p×q, 또는 zero-row-inserted identity αp,q와 그 cyclic shift)로 치환.
  5. 확장 후 rate는 Rate = 1 - (p/q)(M/N)로, p=q일 때 base rate와 동일하고 p를 늘리면 낮은 rate가 얻어짐(식 3).
  6. 베이스 행렬은 permutation matrix A의 거듭제곱(A^x)을 사용하는 Vandermonde-type 구성(V-matrix)으로, girth≥6(4-cycle 없음) 보장.
  7. Tanner graph 관점에서 H(Hb,p,q)의 그래프는 Hb의 그래프 branch를 서브행렬의 그래프로 치환한 구조로, 각 αp,q 섹션은 이전 섹션의 check node 연결을 한 칸씩 shift한 것과 동일(그래프 유도 용이).
  8. 별도의 학습/최적화 절차 없음(대수적/조합적 구성).
  9. 결과: rate 1/2~9/10 8종에서 BER=10^-5 기준 Shannon limit 대비 평균 약 0.72dB 이내(rate별 0.72~0.75dB).
  10. 한계: 시뮬레이션(AWGN, sum-product, 최대 50 iteration)만 수행, HW 구현·복잡도·throughput 데이터 없음. NAND 채널이나 정정능력 개선 주장 없음.
