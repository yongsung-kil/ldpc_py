총평: 홀로그램 메모리 nonuniform 병렬채널용 LDPC 설계·rate-compatible puncturing·UEP를 통합한 부호설계 이론 논문으로, NAND binary QC-LDPC 디코더/HW 이식 가치는 낮음.

B. 알고리즘 요약

  1. 시스템: VHM(volume holographic memory) 페이지를 kr개 병렬 BIOSM 서브채널(중앙→모서리로 SNR 저하)로 모델링, n(j)비트를 채널 j에 전송.
  2. 풀려는 문제: 채널 비균일성을 무시하고 평균 LLR로 설계하는 기존 irregular LDPC는 capacity 접근 시 degree-2 VN 과다로 error-floor 발생.
  3. 핵심 앙상블: g(Λ,ρ) — 타입 j(채널 j로 가는 비트)마다 다른 VN degree 분포를 부여해 어느 비트가 어느 채널로 가는지 사전지식을 부호설계에 활용.
  4. 핵심 기법: 병렬채널용 density evolution/Gaussian approximation 유도 + 안정성 조건을 스펙트럼 반경 r(M)<1(행렬 M) 으로 제시(Thm 1).
  5. 핵심 식 의미: 채널 비균일성이 필요한 irregularity의 일부를 대신 제공 → semiregular(타입별 동일 degree) 부호로도 capacity 접근 가능, degree 최적화 대폭 단순화.
  6. Puncturing 통합: punctured 비트를 "용량 0 가상 서브채널"로 보내는 2병렬채널 모델로 재해석 → 최적 puncturing 분포를 linear program으로 구함(Thm 3, [11]과 동일 결과 재도출).
  7. UEP: 중요비트 집합 A와 깊이 h 이웃 N^j(A)에 고정 degree(dv/dc) 부여한 앙상블 gn(Λ,ρ,h,dv,dc)로 "perfect protection" 달성 조건 제시(Thm 4).
  8. 부수 트릭: expurgated 앙상블(선형 최소거리·stopping set)로 error-floor 저감, degree-2 VN 회피(재생성)로 low-floor 확보.
  9. 결과: 반rate BEC 코드 B가 BER 10^-9까지 error-floor 없음; rate 0.85 VHM 코드가 병렬채널서 등가 단일채널 대비 우수, capacity 격차 length 10^5/10^4에서 0.65/1.04 dB. UEP 코드 c0(len 2000/4000)가 (3,6) 정규부호 대비 BER 우수, 중요비트는 h iteration만으로 조기복호(전체 미복호).
  10. 한계: 전부 이론+SW BER 시뮬(BEC/BIAWGN), HW·QC 구조·NAND read 비용 없음; VHM/OFDM/multilevel 특화 병렬채널 가정.
