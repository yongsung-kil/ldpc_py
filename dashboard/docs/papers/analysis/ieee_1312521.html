B. 알고리즘 요약

  1. 대상은 rate R=k/n short-length irregular LDPC (예: (603,301), rate 0.5), BEC/AWGN 채널.
  2. 문제: 짧은 블록에서는 국소 이웃이 tree-like가 아니라 degree-distribution ensemble 내에서 코드 간 성능 편차가 크고 error-floor가 높음.
  3. stopping set을 PCM 관점으로 재정의: 컬럼 부분집합 S의 실수합 Δ=Σvi가 어떤 성분에도 1을 갖지 않으면(fsc(Δ)=0) S는 stopping set.
  4. 코드생성: 컬럼을 degree 오름차순으로 랜덤 생성하고, Hm은 full-rank 유지하며 각 신규 노드에 Stopping-Set-Check를 통과시켜 추가.
  5. Exhaustive 모드는 크기 ≤d1의 모든 stopping set을 배제하나 조합폭발로 비현실적.
  6. Approximate 모드: 신규 변수노드마다 Viterbi-like trellis 탐색, path metric βp=fsc(Δp)와 cycle metric βc(cycle 내 singly-connected check 수)를 threshold γp,γc와 비교.
  7. merge 시 check-node/variable-node별로 βc 갱신식(식4,5)으로 root 중복 제거; βp<γp 또는 βc<γc면 실패 선언 후 노드 재생성.
  8. survivor path는 merge에서 singly-connected 수가 낮은 쪽 선택(더 stopping set이 되기 쉬움), tie는 사전식 순서.
  9. 저degree 노드는 정확도가 떨어져 ACE 기법을 저degree에, SSC를 고degree에 적용하는 Joint 방식 제안.
  10. 결과: (603,301)에서 Joint이 random 대비 BER 10^-6에서 약 0.5dB 이득, Shannon 한계에서 약 3.2dB. HW 미설계, 시뮬만.
