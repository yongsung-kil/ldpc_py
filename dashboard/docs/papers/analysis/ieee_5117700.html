B. 알고리즘 요약

  1. WiMAX 표준 (2304, 1152) Block-LDPC(QC-LDPC) 코드를 대상으로 layered MPD (LMPD-ICM, identical core matrix 사용) 디코더를 다룬다.
  2. 기존 LMPD-ICM은 매 라운드 모든 레이어(P=96)를 순차 처리해 복잡도가 크다는 문제를 해결하려 한다.
  3. Check-node 관점에서 레이어별 신뢰도를 판단: 레이어 p가 Hp·v̂p^T = 0을 Nat번 연속 만족하면 신뢰 가능(reliable)으로 간주.
  4. 동적 스킵(DS): 신뢰 가능한 레이어의 디코딩을 스킵. 동적 강화(DE): 매 라운드 끝에 H·v̂^T로 만족되지 않은 레이어 집합 Ω를 재처리(최대 NR회).
  5. DS는 error floor를 유발하지만 DE는 BER 열화 없이 복잡도(ANPL)를 줄인다는 것이 핵심 관찰.
  6. Core matrix Hc를 이용한 조기종료: 각 레이어(=시간 순간) 디코딩 종료 시점마다 parity check를 수행, 연속 λ 개(≥P) 레이어가 유효(valid)하면 디코딩 종료 - 기존 전체 PCM 체크(PC-H) 대비 HW 자원을 P배 절감.
  7. DE(NR=1)와 제안 조기종료 결합 알고리즘: 정상 단계에서 연속 유효 레이어 카운터 c를 유지하고, 재처리 단계(Step 7)에서는 카운터를 갱신하지 않아 조기종료가 발생하지 않도록 함.
  8. 별도 학습/최적화 절차 없음(파라미터 Nat, NR, λ는 시뮬레이션으로 튜닝).
  9. 결과: SNR=2dB, LM=9600 기준 DE(NR=2) 사용 시 ANPL 23.7% 감소(719.91→549.25), BER은 열화 없이 4.4×10⁻⁷ 수준 유지; DS 단독 사용 시 ANPL 최대 24.3% 감소하나 BER 열화(2.0×10⁻⁶) 발생.
  10. 한계: HW 구현/합성 결과 없음(순수 시뮬레이션), 단일 코드(WiMAX 2304,1152)만 검증, 정정능력 자체는 개선하지 않고 복잡도/latency만 절감.
