B. 알고리즘 요약

  1. 대상: 분산/클라우드 스토리지용 binary linear LRC(locally repairable code) — 단일 노드 장애를 최대 r개 노드 접근으로 복구, availability t(disjoint repair set 수) 포함.
  2. 문제: 기존 LRC bound 대부분이 field size q를 명시하지 않음, 특히 binary(q=2) 결과가 부족 → q·availability를 반영한 상한과 유연한 구성법 필요.
  3. 기여1(bound): Cadambe-Mazumdar 틀을 확장해 [n,k,d]q (r,t)i-LRC의 minimum distance d·dimension k 상한을 A(r,x,y)=Σ(r-1)yj+x, B(r,x,y)=Σr·yj+x로 유도(Thm 4), 기존 bound보다 tight.
  4. 기여2(고전부호 locality): cyclic code의 locality가 dual code의 minimum distance d⊥-1로 결정됨을 보이고(Lemma 10) RM code에도 적용, extend/shorten/expurgate/augment/lengthen 연산 후 locality 변화 분석.
  5. 기여3(구성): phantom parity-check symbol 기반 Construction A/B/C로 d=3,4,5인 (r,1)i/(r,1)a-LRC 구성 — tensor product code의 phantom syndrome 아이디어 차용.
  6. 핵심 식: local parity pLi=Σμij, global parity pGj=Σi pij, phantom symbol은 최종 codeword에 나타나지 않음.
  7. 구성4(고minimum distance): multi-level tensor product 구조 H=[H1⊗H1'; ...; Hμ⊗Hμ'](Construction D)로 d=2^μ인 고rate (r,1)a-LRC 생성.
  8. availability: one-step majority-logic decodable code(cyclic simplex, difference-set, 4-cycle free regular LDPC/EG-LDPC)의 locality r=ρ-1·availability t=γ 규명, 짧은 부호에서 긴 LRC 구성.
  9. 결과: [240,212,6] r=14 rate 0.8833 등 기존 [255,162,6] r=2 대비 고rate, d=3,4 부호는 bound (6)에 대해 최적임을 증명(이론적, 시뮬/HW 없음).
  10. 한계: 순수 부호이론(정리·증명), 디코더/HW·BER 성능·복잡도 서술 전무, erasure(노드 장애) 모델로 NAND soft-read·error-floor와 무관.
