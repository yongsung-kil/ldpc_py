B. 알고리즘 요약

  1. 대상은 rate-1/2 systematic LDPC convolutional code(LDPC-CC), semi-infinite·주기적 시변 parity-check 행렬 H의 null space(vH=0), GF(2).
  2. 문제: LDPC 블록부호(LDPC-BC)는 임의 길이 패킷을 고정 블록에 맞추는 오버헤드가 커 패킷 통신에 부적합.
  3. 모델: 주기 T, 메모리 M인 (M,J,K) 정규 LDPC-CC. T-1=M인 부류에 집중, 예제는 (128,3,6) (M=128).
  4. 인코딩: H의 상삼각 구조 덕에 v(t)=Σ hu(i)(t)u(t-i)+Σ hv(i)(t)v(t-i) (식2)로 직접 계산, 복잡도는 M과 무관하게 선형.
  5. 핵심 기여: 임의 상태에서 all-zero state로 인코더를 되돌리는 termination — x D = β (식5) 선형시스템을 풀어 종료 시퀀스 x 결정.
  6. 2L ≥ L+M이고 D가 full-rank면 해 존재. (128,3,6)에서 L ≥ M+6이면 129개 phase 모두에서 D full-rank.
  7. Presetting: 패킷 시작 시 이전 비트를 0 가정, 디코더 LLR을 ∞로 설정 → 헤더(주소 필드) 보호 강화(cut-through switching 유리).
  8. 디코더: 무한 Tanner graph를 I개 동일 프로세서의 pipeline으로 분할([2] 참조), 초기 지연 후 연속 복호, global routing 불필요.
  9. 결과: AWGN에서 (128,3,6) LDPC-CC가 termination 오버헤드에도 (1024,3,6) LDPC-BC보다 BER 약간 우수, HER 더 낮음. 단 1024bit 짧은 패킷에선 오버헤드로 열세.
  10. 한계: HW 합성 없이 BER 시뮬만, packet/streaming 특화(고정 블록 NAND엔 부적합), irregular LDPC-CC는 향후 과제.
