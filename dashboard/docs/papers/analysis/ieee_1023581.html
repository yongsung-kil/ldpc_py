B. 알고리즘 요약

  1. 대상 부호: 유한 기하 FG(m,p^s)의 p1-flat/p2-flat 포함관계로 만든 J×n binary parity-check H(m,p2,p1,s,ρ), null space를 type-I 부호로 사용.
  2. 문제: 일반 통념상 길이-4 사이클이 많은 부호는 SPA 성능이 나쁘다고 여겨지나, 본 논문은 이를 반증하려 함.
  3. 구성 일반화: p1=0,p2=1(Kou-Lin-Fossorier)과 p1=p2-1(Lin-Tang-Kou)을 모두 포괄하는 일반 클래스로 확장.
  4. 핵심 관찰: p1<p2-1이면 Tanner graph에 길이-4 사이클이 매우 많지만(수백만 개) SPA로 여전히 우수한 성능.
  5. 예: (5355,5227) Euclidean geometry 부호 d1(4,3,1,2,2)가 SPA로 BER 1e-5에서 Shannon-limit 대비 1.1 dB 이내.
  6. 하이브리드 1단: 길이-4 사이클은 2회 iteration 후에야 복호 상관(correlation)을 유발 → SPA를 딱 2회만 수행.
  7. 하이브리드 2단: 2회 후 hard-decision을 내고, 그 시퀀스를 다단계 다수결(multi-step majority-logic) 복호로 처리.
  8. 부호는 QC 형태로 표현 가능해 shift-register로 인코딩 용이, 다수결 복호 가능성 내장.
  9. 결과: 하이브리드 복호가 SPA 대비 복호 복잡도를 크게 줄이면서 성능 손실은 매우 작음(시뮬 기반).
  10. 한계: HW 미설계, 정확한 rate/복잡도·error-floor 수치 없음, 2페이지 ISIT 요약본이라 상세 부재.

|---|---|---|
| SPA 반복 복호 | decoder.cpp LDPC_Decoder(), C2V_Cal() | Prime은 min-sum이라 SPA(tanh) 자체는 대응 없음; 반복 루프 구조만 대응 |
| 2단 하이브리드(SPA 2회+다수결) 조기종료 | partial_CRC.cpp partial_crc_HW_T4() | 조기 hard-decision 후 후단 복호라는 스케줄 아이디어가 조기종료/후처리 루프와 개념적으로 닿음 |
| finite geometry H-matrix 구성/QC 형태 | ecc_top.cpp Load_PCM() | QC-LDPC H-matrix 로드 경로에 대응하나 부호 자체 교체는 높은 이식 부담 |

적용 가치: 낮음 — 대수적 finite geometry 부호와 SPA+다수결 하이브리드는 Prime의 고정 QC-LDPC/min-sum 파이프라인과 정합성이 낮고 HW·수치 근거가 얕아 직접 이식 가치가 제한적이다.
