B. 알고리즘 요약

  1. 채널은 Gilbert-Elliott 계열의 burst-error 모델을 단순화해, 고정 길이 bmax의 단일 오류 버스트(구간 내 오류확률 p=0.5)만 가정한다.
  2. 기존 sliding-window 복호는 시작위치를 몰라 평균 (n-b+1)/2회 시도가 필요해 비효율적이다.
  3. 신드롬 s=eH^T로부터 파리티체크 실패 열벡터 f=s⊛H를 구하고, 길이 b 구간합 z_i=Σf_k이 버스트 위치에서 커진다는 성질을 이용한다.
  4. 신뢰도 임계값 t=γ/2(majority decoding 문턱)로 낮은 f 값을 사전에 컷오프하면 탐색 후보가 크게 줄어든다.
  5. 실험(4×8×127 QC-LDPC, bmax=126): t=0일 때 평균 시도 E[T]=25, t=2일 때 E[T]=2.5(원래 445.5 대비).
  6. Gilbert code(γ=2) 구조에서는 burst 구간 f_b가 {0,2}값만 가지고 w(f_b)=w(s)/2를 만족하는 위치가 유일함을 증명, 이를 이용한 전용 복호 알고리즘을 제시.
  7. 확장(3-stripe) Gilbert code는 supercode(상위 2-stripe)에서 리스트 복호 후, 전체 PCM으로 신드롬이 0이 되는 오류벡터를 선택하는 2단계 절차로 복호한다.
  8. 학습/최적화 절차 없음(구조적 증명 + 실험적 카운트).
  9. 결과: burst 위치 탐지 평균 시도횟수 445.5 → 2.5로 감소(약 178배); 확장 Gilbert code는 correcting capability m-1까지 보장 복호.
  10. 한계: HW 미설계, 순수 시뮬레이션/이론 증명 수준이며 소프트 정보 없는 discrete burst channel 가정에 국한.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
burst 위치 탐지(신드롬 기반 majority decoding)대응 없음Prime ECC는 랜덤 채널(AWGN/RBER) 기반 min-sum 복호로, discrete burst 위치 탐지 로직 없음
Gilbert/확장 Gilbert code 전용 복호 알고리즘대응 없음Prime ECC는 표준 QC-LDPC(N_b=129, VN degree 17) 구조로 Gilbert code(γ=2,3) 구조와 무관
QC-LDPC block-permutation 구조 분석ecc_top.cpp Load_PCM()부호구조 로드 지점이나, burst correction용 특수 구조는 이식 대상 아님

적용 가치: 낮음 — burst-error 채널 전용 이론/알고리즘으로 NAND의 랜덤 비트오류 기반 binary QC-LDPC 디코더 파이프라인과 직접 연결점이 없음.
