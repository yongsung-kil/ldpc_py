B. 알고리즘 요약

  1. 대상은 소수체 Fq 두 부분집합 S1,S2에서 pk,t = ik×jt (mod q)로 지수행렬을 만드는 algebraic QC-LDPC를 일반화한 variable-rate(VR) QC-LDPC.
  2. 풀려는 문제: 여러 rate를 지원하되 parity-check 행 수 m을 고정(수평 nested)해 저장복잡도·HW 구현을 단순화 - 기존 rate-compatible 방식과 달리 constituent code들의 null space 크기 동일.
  3. 핵심 구조: 열 수 집합 {n1<...<nD}에 대해 하나의 PVR이 D개 constituent code의 지수행렬을 통합하며, 고rate 코드는 저rate 코드 오른쪽에 열을 추가해 얻음(nested).
  4. RC-constraint로 모든 constituent code가 girth ≥ 6 보장, cycle distribution C(x)를 탐색 metric으로 사용.
  5. 핵심 기법 isomorphism 기반 탐색공간 축소(Prop.2): permutation/addition/multiplicity 규칙으로 임의 fully-connected P를 S1*={0,1,...}, S2*={0,1,...} 정규형 P*로 사상.
  6. 효과: kernel P1 탐색공간이 (q-2 choose m-2)×(q-2 choose n1-2)로 감소 - F37,m=3,n1=6에서 1.8×10^10 → 1.8×10^6(약 10^4배 축소).
  7. Algorithm 1: kernel 탐색 후 각 확장부 Δn=nd−nd−1 열을 순차 탐색, metric(연결성/cycle 분포/거리)으로 최적 P 선택.
  8. 학습/최적화: 별도 학습 없이 exhaustive+isomorphism pruning (F31 예제 총 Ntotal=3229175개 행렬만 테스트).
  9. 결과: F31 예제로 (3,6)/(3,9)/(3,13)/(3,18)-regular 코드(186~558 길이) 생성, 5G irregular LDPC 대비 BLER에서 error-floor 없음(10^-5까지) + SPA 50-iter 평균 iteration 감소(Fig.5).
  10. 한계: HW/디코더 미설계, 통신 단블록(rate 0.51~0.84) 대상, non-binary·NAND 고rate와 거리 있음, nested 확장이 고rate 코드 cycle 분포를 sub-optimal화.
