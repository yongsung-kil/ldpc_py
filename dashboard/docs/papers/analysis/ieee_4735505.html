총평: 잘 알려진 PEG로 IRA 인터리버(H1)를 4-cycle 없이 구성해 BER를 높이는 표준적 부호구성 논문으로, NAND 고rate QC-LDPC에 그대로 떼어 쓸 신규성은 낮다.

B. 알고리즘 요약

  1. 시스템: systematic IRA(Irregular Repeat-Accumulate) 부호, H=[H1,H2], H2는 1/(1+D) accumulator의 dual-diagonal 정방행렬, 길이 N=1000, rate 1/3·1/2 두 예제, AWGN·BPSK.
  2. 문제: IRA를 LDPC로 보면 factor graph의 short cycle(특히 4-cycle)이 message-passing BER를 악화 → 큰 girth 구성 필요.
  3. 모델: IRA를 Tanner graph(정보노드 k개, check r=Σqi/a개, parity노드 r개 zig-zag)로 표현, 인터리버 Π 설계 = H1(열무게 [q1..qk], 행무게 a) 설계와 등가.
  4. 핵심기법: PEG(Progressive Edge-Growth)를 IRA용으로 변형 — 새 edge 추가 시 해당 variable node의 local girth를 최대화하며 edge-by-edge로 그래프 성장.
  5. 핵심식/절차: symbol node를 degree 순 정렬 후, 각 sj의 첫 edge는 최소차수 check node에, 이후 edge는 sj에서 깊이 l subgraph를 확장해 girth 손상 최소 check node 선택.
  6. 결과: rate-1/3(a=2), rate-1/2(a=8) IRA, 길이 1000에서 PEG 인터리버가 랜덤 대비 BER 우수(고rate에서 더 뚜렷), PEG 설계는 4-cycle 없음·local girth 6.
  7. 한계: HW 미설계, 시뮬만(AWGN), 최대 iteration 50 고정(감소 논의 없음), IRA(비QC) 저rate 부호 대상.
