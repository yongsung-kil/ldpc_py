총평: LDPC Tanner 그래프의 girth/short-cycle 문제 난이도를 규명한 순수 이론 논문으로, Prime ECC에 떼어 쓸 구성법·디코더·HW 요소가 없어 이식성 하.

B. 알고리즘 요약 (10줄 내외)

  1. 대상: LDPC 코드의 Tanner(bipartite) 그래프에서 짧은 사이클 수와 girth를 다루는 두 결정문제의 계산복잡도 규명.
  2. 문제1 (Min-Short-Cycles): 주어진 degree sequence (π, π')와 정수 α, β, γ에 대해 4/6/8-cycle 수가 각각 α, β, γ 이하인 단순 bipartite 그래프 존재 여부 판정.
  3. 결과1: 문제1은 strongly NP-complete임을 증명.
  4. 증명 방법: 3-Partition Problem → 3-Partition of Odd Numbers Problem → Min-Short-Cycles Problem의 2단계 다항시간 환원.
  5. 핵심 구성: universal check node cu(degree 4n)와 degree-2 check node들을 도입해 semi-normal graph G'로 변환, N4 = nB + Σ(ai choose 2) = α, N6 ≤ n(B choose 2) = β, N8 = 0 = γ로 사이클 수를 3-Partition 해와 대응.
  6. 문제2: 주어진 (variable node) degree sequence π에 대해 girth≥6, dcmin≥2인 단순 bipartite 그래프 존재 여부 판정.
  7. 결과2: 문제2는 다항시간 solvable임을 증명 (Theorem 4).
  8. 증명 방법: girth≥6 bipartite 그래프 ⇔ loopless linear hypergraph의 degree sequence 대응을 확립하고, Bhave et al.의 Erdős–Gallai형 특성화(Theorem 3, 다항시간 검사 가능) 활용.
  9. 결과 수치: 성능·BER·gate count 등 실측 수치는 없음(순수 이론). girth≥6 판정은 조건 (i) 합이 짝수, (ii) 부분합 부등식만 확인.
  10. 한계: HW·디코더·실제 부호 구성 알고리즘 없음. NP-완전성은 존재성 판정일 뿐 부호 생성 절차(PEG 등)를 제공하지 않음.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
girth/short-cycle 구성 이론대응 없음Prime ECC는 특정 QC-LDPC H-matrix 고정, 그래프 구성 판정 로직 미포함
H-matrix 부호구조ecc_top.cpp Load_PCM()이론적 존재성만 다뤄 실제 PCM 로드/생성에 이식할 절차 없음

적용 가치: 낮음 — 계산복잡도 하한/상한을 규명한 순수 이론으로, Prime ECC의 부호설계·디코더·HW 어느 모듈에도 떼어 쓸 구성 알고리즘이나 성능 기법이 없다.
