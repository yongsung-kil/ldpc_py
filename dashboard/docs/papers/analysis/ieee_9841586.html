총평: 궁극 섀넌한계 근접 초저rate SC-PLDPC-Hadamard 부호 — 심우주/다중접속 채널 타깃이라 NAND 고rate ECC와 무관, 이식성 하.

B. 알고리즘 요약

  1. 대상은 rate 0.00295~0.0494의 초저rate 부호로, 심우주 통신·다중접속(IDMA) 등 Eb/N0가 궁극 섀넌한계(-1.59 dB)에 근접해야 하는 시나리오용.
  2. 기존 PLDPC-Hadamard 블록부호(PLDPCH-BC)는 이미 한계에 근접했으나, 공간결합으로 convolutional gain을 추가로 얻는 것이 목표.
  3. 부호구조: 프로토그래프의 SPC-CN을 Hadamard 제약(H-CN)으로 치환하고, 차수-1 Hadamard VN(D1H-VN)을 추가한 generalized LDPC. order-r, 코드길이 q=2^r.
  4. 핵심 기법 1단: 블록부호 protomatrix B를 edge-spreading으로 W+1개 분할행렬 B_i로 나눠 결합길이 L만큼 결합 → SC-PLDPCH-TDC/CC 구성.
  5. 부호율 R_SC-PLDPCH-CC = (n-m)/(n+m(2^r-r-2))로 블록부호와 동일; 결합으로 threshold만 개선(saturation).
  6. 핵심 기법 2단: layered PEXIT 알고리즘 — mutual information I_av/I_ev/I_ah/I_eh를 행(layer)별로 갱신, 원 PEXIT 대비 수렴 iteration 30~62.8% 감소.
  7. 복호: I개 동일 message-passing processor로 pipeline + layered scheduling, 각 processor는 [H_W...H_1 H_0] 대응 블록 sub-decoder, latency (W+1)I·Tr.
  8. 최적화: 유전 알고리즘(GA) — split protomatrix 후보에 crossover/mutation/selection으로 좋은 threshold를 갖는 SC-PLDPCH-TDC 탐색 후 L 확장.
  9. 결과: rate-0.00295 부호가 BER 10^-5를 Eb/N0 = -1.465 dB(궁극 한계 대비 0.125 dB)에서 달성, 블록부호·타 저rate 부호 능가.
  10. 한계: 초저rate 전용 generalized LDPC-Hadamard, HW 미설계(시뮬만), NAND 고rate binary QC-LDPC와 부호패밀리 자체가 상이.
