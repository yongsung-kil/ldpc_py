B. 알고리즘 요약

  1. 대상은 GF(q=2^r)상의 (ns,K) QC 부호(부분집합이 binary QC-LDPC), 예제로 rate 0.858 (3556,3051) binary QC-LDPC(열무게4,행무게28) 등.
  2. 문제: 무선·자기기록·플래시 채널의 다중 버스트(multiple burst) 오류를 기존 랜덤채널용 QC-LDPC로는 최적 정정 못함.
  3. 모델: s-phased-burst(연속 b오류가 σ개 벡터성분에 국한) 채널을 가정.
  4. 핵심 기법1: s-point Galois Fourier Transform(GFT) F와 행·열 치환 π로 QC PCM H를 블록대각 H^{F,π}=diag(B_0,...,B_{s-1})로 변환 — 심볼도메인 버스트가 transform도메인에서 여러 짧은 랜덤패턴으로 흩어진다.
  5. 핵심 정리: 다중버스트 정정능력 = 각 서브행렬 B_t 널스페이스 부호들의 최소해밍거리 최솟값 δ로 결정(Theorem 1), Reiger bound MBE/MBEr=1이 최적.
  6. 핵심 기법2: 대각 서브행렬 B_t를 (n,n-m) MDS(RS/constacyclic) PCM으로 설계 → non-binary QC는 δ=m+1로 최적 버스트정정.
  7. binary 확장: conjugacy 제약으로 B_t를 λ개 cyclotomic coset 대표 B_{t_i}만 설계, B0(all-1) 영향은 pre-coding으로 제거해 점근 최적.
  8. QC-LDPC 특화: B_1을 Vandermonde로 잡고 B_t=B_1^{∘t} 제약 만족 시 QC-LDPC가 되며 RC 제약도 성립.
  9. 결과: (3556,3051) 부호가 AWGN에서 PEG/LS와 거의 동등(MacKay 대비 0.2dB↑), phased-burst 채널에선 transform-domain 디코딩으로 기존 SPA QC-LDPC 전부 능가.
  10. 한계: HW 미설계, 버스트채널 전용 이득, transform-domain BM 디코딩(RS)이라 우리 iterative min-sum과 별개.
