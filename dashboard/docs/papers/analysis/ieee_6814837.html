B. 알고리즘 요약

  1. 대상: rate-compatible Raptor 부호(고rate precode + rateless LT)를 HARQ에 쓰기 위한 HW지향 구성법. 삼중항 (K0,K,N) = 정보블록/LT비트노드/전송비트로 정의.
  2. 문제: 짧은 블록(수 kb)에서 architecture-aware Raptor를 만들면 고정rate LDPC 대비 수렴속도·메시지메모리가 열세 - 이를 좁히려는 것.
  3. 채널/모델: AWGN + BPSK, 성능은 IEEE802.16 LDPC와 FER 비교(간섭/NAND 모델 없음).
  4. 기법1(source matrix): 비아벨 군 G = Dn × Cpq(이면체군×order-pq군)로 K=2npqM 크기 인덱싱, M열 base B를 순열부분행렬로 replication해 HB 생성(protograph식).
  5. 핵심식: K = 2npqM, Dn의 등간격 order로 등간격 블록길이 확보 - 다길이 디코더의 메모리 주소생성을 dihedral 연산 2개로 축소.
  6. 기법2(precode): row merging으로 regular HP 생성 후, splitting-after-merging으로 저rate irregular precode 구성. HW제약 rate 기준 d0 ≥ dv(dvr−V(1−r))^-1 d0로 rate 선택.
  7. 기법3(LT): row-splitting을 겹침 허용 "row-encoding"으로 일반화 후 subcode 구조 제약 - 고rate에서 무잡음 국소복호로 비트 복원 가능하게 함.
  8. 구현: 메모리를 M뱅크로 분할, Cpq 고정순열망 하나로 모든 K 지원(라우팅 오버헤드 축소). TDMP/TPMP 둘 다 적용.
  9. 결과: rate 2/3에서 iteration 격차 3×→1.35×(TDMP), 메시지수 격차 1.3×→1.1×(rate 1/2), FER은 LDPC에 근접(고rate 약간 열세).
  10. 한계: HW 미구현(check-node 복잡도 증가 추정만), 시뮬만, subcode 구조/precode 분포를 체계적으로 정하는 방법 미제시.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
Raptor 이중부호(precode+LT) 구성대응 없음Prime ECC는 단일 binary QC-LDPC(ecc_top.cpp Load_PCM()), rateless LT 개념 없음
군기반 등간격 다길이 메모리 주소생성대응 없음z=32 고정 lifting 구조와 상이(HCU/GT 기반), dihedral coset 라우팅 미대응
TDMP/TPMP row processingdecoder.cpp LDPC_Decoder()개념적 유사(반복 메시지패싱)뿐, 구조 이식 불가

적용 가치: 낮음 - Raptor/LT rateless 이중부호 구성법은 고정 binary QC-LDPC 엔진과 구조가 근본적으로 다르고 HARQ/무선 겨냥이라 NAND ECC 이식 실익이 없음.
