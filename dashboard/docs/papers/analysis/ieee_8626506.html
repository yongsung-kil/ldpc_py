총평: permanent 기반 최소거리 상계를 부호설계 지표로 삼아 error-floor(low-FER)를 개선하는 QC-LDPC 구성법으로, Prime ECC의 H-matrix 설계 단계에 개념 이식은 가능하나 short block·rate-compatible 대상이라 고rate 단일 부호로 직접 적용엔 재검증 부담이 크다.

B. 알고리즘 요약

  1. 대상은 protograph 기반 Raptor-like(PBRL) rate-compatible QC-LDPC 부호이며, k≈198(5G 비교는 k=192) 정보비트, lifting factor 33, 설계율 6/8부터 6/15까지 IR로 낮춘다.
  2. 문제: 기존 PBRL[25]은 iterative decoding threshold를 지표로 설계했으나, threshold는 short block·저FER 영역(error-floor) 성능을 예측하지 못한다.
  3. 핵심 지표: protomatrix P의 permanent로 계산되는 임의 QC-LDPC 부호 최소거리 d_min 상계(Smarandache-Vontobel[14], Butler-Siegel[15])를 설계 목표로 삼는다.
  4. d_min 상계 = min*_{S,|S|=n_c+1} Σ_{i∈S} perm(P_{S\i}) (식 4/5). d_min은 최소 stopping/trapping/absorbing set 크기의 상계이므로 이를 키우면 저FER 성능이 개선된다.
  5. 설계법: HRC part 고정 후 IRC part를 한 행씩 추가하며, 각 행을 permanent 상계를 최대화하도록 exhaustive search(threshold 대체). 채널 비의존적.
  6. 복잡도 절감: PBRL의 identity 구조(P_IR)를 활용해 S가 항상 P_IR 전 열을 포함하는 집합만 고려하면 됨을 증명(Thm 6/8/10), permanent 크기가 n_cH+1로 축소되고 전체 복잡도가 protomatrix 크기에 선형.
  7. 이전 행 계산 재사용(Lemma 11/12)으로 행 추가마다 상수 런타임 달성(threshold법은 행마다 500+ RCA 반복 필요).
  8. 최적 행 탐색을 integer linear program(ILP)으로 등가 표현(식 25), LP 완화는 non-integer 해라 exact하지 않음을 실험으로 확인.
  9. 결과: lifting은 최저율에서만 C-PEG+ACE로 target girth≥6 수행. PBD 부호(P3 등)가 threshold 기반 대비 FER 10^-4~10^-6에서 우수, capacity gap 약 1.5 dB(FER 10^-6)로 전 설계율에서 일정. 5G short PBRL 대비도 저FER 개선.
  10. 한계: BI-AWGN·full-precision flooding BP(최대 100 iter)만 검증, HW 설계 없음, permanent 상계는 실제 dmin과 다를 수 있고 lifting에도 성능 좌우됨.
