B. 알고리즘 요약

  1. 시스템: DNA 데이터 저장(ONT MinION nanopore), inner binary CC(rate 1/2, (kc=1,nc=2,Kc=3)) + outer non-binary LDPC(GF(4), rate R=4/5) 연접부호, N∈{50,54,204}.
  2. 문제: nanopore는 substitution뿐 아니라 insertion/deletion(동기오류)을 유발하며, 오류통계가 입력서열·이전오류에 의존(memory)하는데 기존 i.i.d. 모델은 부정확.
  3. 모델: 채널이벤트 et∈{Ins,Del,Sub,Match}가 현재 k-mer와 직전 이벤트 et-1에 의존하는 k차 Markov 모델 P(et|kmert,et-1)로 정의.
  4. 핵심기법: CC 디코더의 BCJR에 drift 변수 dt = Nb(INS)t - Nb(DEL)t를 상태에 추가해 ins/del로 깨진 Markov성 복원(Dec1).
  5. 상태확장: Dec2는 상태에 직전 edit et를, Dec3는 추가로 k-mer ηt를 넣어 σt=(st,dt,et,ηt)로 채널모델 완전반영.
  6. branch metric은 lattice(Dec2/3은 4-plane 3D lattice) 재귀 Fi,j,e로 계산하며 채널확률 P(et+1|ηt,et)를 대입.
  7. 동적 채널모델: 스케일 파라미터 α로 오류확률을 조정해 다양한 오류율 실험 가능(식 10,11).
  8. 다중서열: J개 read를 각각 CC 디코딩 후 사후확률을 식(43)으로 결합, 이후 GF(4) BP LDPC 디코딩.
  9. 결과: Dec3가 Dec1 대비 BER/FER 유의미 개선(J 증가 시 이득 확대), KL divergence로 채널모델 정확도 우위 입증. 단 Dec2는 오히려 Dec1보다 나쁨.
  10. 한계: HW 미설계, 시뮬만, k-mer 반영으로 trellis가 2^k배 커져 복잡도 급증(저자도 복잡도 감소를 향후과제로 명시).

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
BCJR/CC 동기오류 디코더 (drift, k-mer trellis)대응 없음Prime ECC는 iterative message-passing이며 BCJR/trellis 디코더 없음
non-binary GF(4) LDPC BP 디코더대응 없음Prime ECC는 binary QC-LDPC 전용, non-binary 미지원
ins/del(동기) 채널 모델channel.cpp Set_R_Offset()AWGN/RBER/fixed-error만 지원, 동기오류 모델 없음(사실상 대응 없음)

적용 가치: 낮음 — non-binary LDPC + 동기채널 전용 BCJR 디코더로 Prime ECC(binary QC-LDPC, min-sum)와 알고리즘·부호가 모두 불일치.
