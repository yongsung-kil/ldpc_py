B. 알고리즘 요약

  1. 대상: short-length 선형블록부호(URLLC용), 검증은 extended BCH (128,64)·(64,16), rate 0.5/0.25, 입력 LLR 7-bit.
  2. 문제: OSD는 short-length ML근사 성능을 주나 다수 candidate 탐색에 막대한 연산이 들어 저지연 HW 구현 곤란.
  3. 배경: OSD는 신뢰도 벡터 α_i=|LLR| 정렬 후 π1·π2 permutation과 Gaussian elimination으로 K개 신뢰·독립 열을 잡고, phase-l마다 Hamming weight l인 TEP e로 candidate (v̂⊕e)Ĝ 생성·weighted Hamming distance 비교(ML근사, lmax=dmin/4).
  4. 핵심기법 1: 기존 SDD의 반복 segment 경계 γ_j(식1, 곱·나눗셈·고해상도) 계산을 없애고, 2의 거듭제곱 고정 segment size p로 대체(주소 정렬·fetch 부담↓).
  5. 핵심식: p=4가 BLER 1e-5 목표에서 SDD와 동등 정정력을 주면서 TEP 생성 비용을 원본 OSD 대비 99.97% 절감.
  6. 핵심기법 2: discarding threshold hdis(식2, σ(â)·통계정보 필요)를 고정 파라미터 ρ≈μσ(â)K/(N-K)로 근사(식3), ρ=5.5((128,64), 1e-5)로 shift-and-add만으로 곱 처리.
  7. resolution: γ_j 제거로 SDD가 요구하던 22-bit 고정소수점 대신 7-bit 처리로 충분(hopt 소값은 hdis와만 비교되어 정밀도 덜 중요).
  8. 최적화 절차: 별도 학습 없음, 특정 Eb/N0 조건에서 ρ·segment size를 HW-friendly로 선택.
  9. 결과: 28nm CMOS(Synopsys DC) 합성으로 연산자별 등가 NAND게이트를 32-bit float MUL 기준 정규화, 평균 복잡도를 원본 OSD 대비 1.6×10^4배, SDD 대비 11배 절감, list-4 SCL polar와 비교.
  10. 한계: 절대 gatecount/throughput 미보고(정규화 복잡도만), short·저rate eBCH만 검증, LDPC 아님.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
OSD 전체(Gaussian elimination + TEP reprocessing)대응 없음Prime ECC는 iterative min-sum BP 디코더로 OSD 계열 패러다임 자체가 부재
segment/threshold 조기종료partial_CRC.cpp partial_crc_HW_T4()조기종료 개념은 유사하나 Prime ECC는 CRC 기반이라 OSD discarding 로직과 무관
7-bit low-resolution 양자화ecc_data.h PARAM_LLRLLR 저해상도 처리 착상만 참고 가능, 알고리즘 문맥 상이

적용 가치: 낮음 - OSD는 Prime ECC의 binary QC-LDPC min-sum BP와 완전히 다른 디코딩 방식이고 대상 부호(short eBCH, rate 0.25~0.5)도 NAND 고rate QC-LDPC와 무관해 이식 대응 모듈이 사실상 없음.
