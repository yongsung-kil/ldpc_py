B. 알고리즘 요약

  1. 채널: BSC(파라미터 α), regular LDPC (예시 (155,93) Tanner 코드, dv=3, dc=5, rate≈0.6), 최대 100 iteration.
  2. 문제: 미세공정 소자는 transient/permanent 오류를 일으켜 채널뿐 아니라 디코더 HW 자체가 신뢰불가 → 결함 HW에서도 강건한 디코더 선택 필요.
  3. 핵심 대상: FAID = 4-tuple (M,Y,Φv,Φc), 메시지가 소수 레벨 M={-Ls..Ls}(예 7-level)에 속하고 VN 갱신 Φv는 LUT로 정의, CN 갱신 Φc는 표준 min-sum.
  4. 노이즈 모델: 함수 출력단에 message-level 노이즈를 확률전이행렬 Mc(pc), Mv(pv), Ma로 인가, sign-preserving(진폭에만 노이즈, 부호는 HW 보호) + 대칭 가정.
  5. noisy-DE: pmf 재귀 (3)~(6) — CNU 출력 pmf r에 Mc 곱, VNU 출력 pmf q에 Mv 곱, 국소 독립 가정하 무한길이 앙상블 점근 오류확률 P̃e 유도.
  6. 핵심 정의: useful threshold(=[10])는 noisy 수렴을 잘 예측 못함 → 새 functional threshold α(pv,pc,Φv)를 Pe 극한이 하한 Pe(lb)=pv/2s를 교차하는 α로 정의(Def.1).
  7. 이론 결과: Prop.1 하한 2개, Prop.2 — 교차 시 점근 오류확률이 2Pe(lb)에 매우 근접함을 증명.
  8. 선별 절차: Ns=7이면 FAID 5.3억 개 → trapping-set 분석[8]으로 추린 ND=5291개(양호한 noiseless threshold+error-floor) 대상으로 functional threshold 계산.
  9. 결과: Φv(robust)(noiseless-noisy threshold 차 최소)와 Φv(non-robust)(차 최대) 추출, 유한길이 시뮬에서 noisy 시 robust가 error-floor 최적화 Φv(opt)보다 우수함 확인.
  10. 한계: HW 미설계·gatecount/throughput 없음, BSC·SP·대칭 모델 가정, boolean-level/비대칭 fault는 future work.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
VNU LUT 매핑 Φv (소수 레벨 FAID)decoder.cpp VN_Cal_HD(), decoder.h Get_VNU_*Prime ECC는 min-sum+LLR 테이블 기반, FAID는 별도 VNU LUT 정의 방식이라 직접 대응 아님(부분 유사)
CN min-sum 연산 Φcdecoder.cpp CNU_Update_New_Mag(), C2V_Cal_New_Sgn()Φc가 표준 min-sum이라 CN 연산은 동일 계열
noisy-DE / functional threshold 선별대응 없음fault-tolerance 이론 분석 도구, 코드 모듈에 대응 없음

적용 가치: 낮음 — fault-tolerant 디코더 선별 이론(noisy-DE functional threshold)은 Prime ECC의 실측 HW 파이프라인/양자화 min-sum과 목적이 다르고, BSC(hard) + column-weight 3 + LUT-FAID 가정이라 고rate QC-LDPC/soft-read NAND에 직접 이식하기 어렵다. HW fault 강건성 관점의 참고 정도.
