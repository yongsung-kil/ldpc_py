총평: 패킷/광통신형 소거채널 대상 GJE-ML 소거복호 확장이라 NAND BSC/AWGN용 min-sum QC-LDPC와 계보가 달라 이식성 낮음.

B. 알고리즘 요약

  1. 시스템: BEEC(binary error-and-erasure channel, 소거확률 ε ≫ 에러확률 p)에서 (n,k) 이진 선형/LDPC 부호 복호. 예제 (2048,1024) GeIRA, (1000,500).
  2. 문제: 순수 BEC 소거복호는 non-erased 비트의 소산에러(예 CRC 미검출 p=10⁻⁵)를 무시해 높은 error floor(≈n·p) 발생.
  3. 모델: y∈{0,1,?}, 소거 비트에 대응하는 H 열을 좌측에 모아 H=[H_K̄|H_K]로 분할, 등식 y_K̄ H_K̄ᵀ = y_K H_Kᵀ에서 syndrome s 도출.
  4. 핵심 기법(SEME): H_K̄에 GJE 수행 후 잔여 n−k−e parity 방정식(부행렬 P)을 이용, s̃_L≠0이면 에러 검출.
  5. 핵심 식: 단일 에러시 P의 어떤 열 b=s̃_Lᵀ가 유일하면 x̂_K = y_K + ê(weight-1 정정) — P 열들이 곧 weight-1 error의 syndrome table.
  6. 이론: 랜덤부호 앙상블 R(n,k)에 대해 블록에러 상한을 4개 사건 A/B/C/D로 분해, error floor를 (13)으로 해석적 근사.
  7. 부수: LDPC 희소성 활용 — triangularization → sparse row addition → dense R_L에만 GJE(pivot α 최소화)로 복잡도 절감, 동일 연산을 H_K에도 병행 적용.
  8. 최적화: 없음(구성적 알고리즘).
  9. 결과: 단일에러 정정만으로 error floor를 2~5 orders 낮춤(예 n=1000,p=10⁻⁸시 Pe<10⁻¹⁰), IT 복호 대비 moderate 에러율까지 큰 coding gain. 참고문헌상 (2048,1024) SW ML 소거복호 1.5 Gbps 언급.
  10. 한계: 단일에러 정정으로 제한(다중에러는 floor 유발), erasure 채널 전용, HW 미설계, GJE O(n³) 기반.
