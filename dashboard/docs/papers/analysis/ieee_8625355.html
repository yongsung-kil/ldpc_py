B. 알고리즘 요약

  1. 대상은 LDPC 부호의 Tanner 그래프(bi-regular bipartite, girth g)에서 short cycle 개수 N_i를 세는 문제.
  2. 문제: cycle 개수 계산은 NP-hard이고, Blake-Lin[5]은 스펙트럼+차수정보로 길이 g(girth) cycle만 셀 수 있었으며 g+2 이상은 미해결로 남겼다.
  3. 모델: 그래프 인접행렬 A의 고유값집합(스펙트럼) {λ_i}와, closed walk 총수 tr(A^k)=Σλ_i^k 관계를 활용.
  4. 핵심 기법: 길이 k의 closed walk를 (i) k-cycle, (ii) closed cycle-free walk, (iii) cycle 포함 walk(CWWC) 세 부류로 분해(Lemma 1)하고, cycle 개수 N_i = [Σλ_j^i − Ω_i − Ψ_i]/(2i)(정리 1)로 계산.
  5. 핵심 식 의미: 전체 closed walk 수(Σλ^i)에서 cycle이 아닌 walk 수(Ω_i cycle-free, Ψ_i CWWC)를 빼면 순수 cycle 수가 남는다.
  6. 확장: g+2 ≤ i ≤ 2g-2 구간에서 CWWC를 하나의 cycle + 부속 cycle-free walk로 특성화(Lemma 2,3,4)해 Ψ_{g+2},Ψ_{g+4} 등을 부분범주별 조합계수로 유도(정리 2,3).
  7. 구현 디테일: S_{x,y,i}(노드 자기복귀 cycle-free walk 수)를 생성함수로 재귀 계산해 Table II(i≤10)로 제공.
  8. 이론 결과: 길이 i ≥ 2g는 스펙트럼+차수분포만으로 결정 불가 — Godsil-McKay switching으로 cospectral·동일 차수분포이나 N_12 이상이 다른 두 3-regular girth-6 그래프 반례 제시(Table III).
  9. 결과: bi-regular는 i=g 및 g+2~2g-2에서 계산 가능(P), i≥2g는 불가능(IP)임을 Table I로 정리.
  10. 한계: 순수 이론(counting)이며 부호구성·디코더·HW·성능개선 없음, bi-regular 위주(불규칙/half-regular는 별도).
