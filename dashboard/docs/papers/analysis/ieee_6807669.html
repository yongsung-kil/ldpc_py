B. 알고리즘 요약 (10줄 내외)

  1. 대상은 홀수 소수 q, m ≤ q로 정의되는 대수적 array LDPC 부호 C(m,q) (열가중 m의 regular QC-LDPC).
  2. 풀려는 문제: C(m,q)의 최소거리 d(C(m,q))에 대한 일반 상계가 (m+1)!, 2^m로 느슨하고, 타이트한 값은 특정 소수 m(2~7)에만 알려짐.
  3. 접근: parity-check H(m,q)가 CPM P^r 블록으로 구성됨을 이용해 생성행렬 (2)를 순환행렬 G_i들로 표현.
  4. 핵심량은 G_i의 행가중 w_{m,i} — 이것들의 합 Σ w_{m,i}가 상계를 지배.
  5. 핵심 관찰: G_i = Σ_{R} (Σr) 계산에서 같은 합 S가 짝수 번 나오면 이진합으로 상쇄되어 항이 줄어든다(예제 (m,q)=(4,5)로 예시).
  6. N_S(m,i) = 합이 S인 i-원소 부분집합 수로 정의, w_{m,i}=|O(m,i)| (N_S가 홀수인 S의 개수) (Lemma 3).
  7. 핵심 식: M(m,i;z)=z^{(i-1)i/2} · [m choose i]_z (Gaussian binomial과 연결, Theorem 1) → w_{m,i}는 [m choose i]_z의 홀수 계수 개수 |W(m,i)|.
  8. 주 정리(Theorem 2): d(C(m,q)) ≤ min(Σ_i |W(m,i)|, 2q), 그리고 q ≥ (1/12)(m+1)(m^2-m+6)이면 d ≤ Σ|W(m,i)|.
  9. 결과: 상계가 d(C(m,q)) ≤ cm^3 수준으로, 기존 (m+1)!·2^m보다 크게 타이트. [m choose i]_z는 점화식 (4)로 효율 계산.
  10. 한계: HW 미설계, 디코더 무관, 컴퓨터탐색 기반 best-known보다는 큰 m에서 여전히 느슨(gap 존재); 순수 최소거리 상계 이론.
