B. 알고리즘 요약

  1. 대상은 kN × ℓN block PCM(circulant permutation 블록)로 정의되는 (k, ℓ)-regular binary QC-LDPC로, lifting degree N과 지수행렬 E_{k,ℓ}로 완전히 규정됨.
  2. 문제: 주어진 k, ℓ, g에 대해 girth g ≥ 6를 갖는 QC-LDPC가 존재하는 최소 lifting degree Nmin을 결정 (대부분은 하한만 알려져 있음).
  3. 핵심 가정: girth g≥6 조건은 Fossorier 조건 h_{i1,j1}−h_{i2,j1}+h_{i2,j2}−h_{i1,j2} ≠ 0 (mod N)(식 (3))로 등가 (Theorem 1).
  4. 핵심 기법 1단: 이 조건을 ZN의 결손(deficit) d를 갖는 상호인접 부분 오소모피즘(partial orthomorphism) {σ3,…,σk} 집합의 존재로 환원 (Theorem 8).
  5. 핵심 식 의미: σ는 σ(x)∉{0,x}이고 x−σ(x)도 단사인 사상, 인접성 σ∼τ는 σ(x)−τ(x)도 단사 — girth 위반 사이클을 배제하는 조건.
  6. 핵심 기법 2단: 부분 오소모피즘 그래프 POrth(ZN,d)의 clique number ω로 kmax = ω(POrth(ZN,N−ℓ))+2 (Theorem 11), Nmin = min{N: ω ≥ k−2} (Corollary 13).
  7. 부수 결과: N이 소수면 ω(Orth(ZN)) = N−2 (Prop 15), 일반 N은 최소 소인수 p로 ω ≥ p−2 (식 (5)).
  8. 최적화/구성 절차: 문헌의 대수적 오소모피즘 구성으로 (4,ℓ)·(5,ℓ) 코드의 Nmin 결정 (Theorem 17), (4,15)·(4,21) 지수행렬 명시.
  9. 결과: (4,15)는 N=15, 길이 225; (4,21)은 N=21, 길이 441 — 각각 girth≥6 최단 길이임을 증명, array-based 코드에 행 추가 불가 등 신규 사실 제시.
  10. 한계: 순수 조합론적 존재/구성 이론으로 복호 시뮬·BER·HW 없음, 예시 길이가 매우 짧고 rate 명시 없음.
