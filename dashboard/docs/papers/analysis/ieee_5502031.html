B. 알고리즘 요약

  1. 시스템: 4×4 MIMO V-BLAST, BPSK, CP 삽입한 UWB MIMO-ISI 채널(MPC 수 L=5~20, frame K, L/K 고정), AWGN.
  2. 문제: MPC가 수십~수백인 심한 delay spread에서 최적 MAP 등화기는 복잡도가 KNt에 지수적 → 저복잡도 near-optimal 등화 필요.
  3. 모델: CP로 원형 convolution화 → 선형 벡터 채널 r=Hx+v (식4)로 변환.
  4. 핵심기법: pairwise MRF 그래프 모델로 표현, 결합확률 p(x)∝∏ψ_{i,j}(x_i,x_j)∏φ_i(x_i) (식8) 위에서 BP message passing.
  5. 파라미터 매핑: R=(1/σ²)HᴴH, z=(1/σ²)Hᴴr로부터 coupling J_{i,j}=-Re{R_{i,j}}, local field θ_i=Re{z_i} → φ,ψ 정의(식18,19).
  6. 문제점: 완전/조밀 연결 MRF에서 BP는 발산하거나 marginal이 부정확해질 수 있음.
  7. 핵심 트릭(message damping): iteration t의 새 메시지를 이전·현재의 convex 결합 m^t = α_m·m^{t-1} + (1-α_m)·m̃^t (식23)로 계산(belief/hybrid damping도 정의).
  8. 결과1: α_m≈0.45에서 BER 약 1자릿수 개선; damping 없으면 iter>4에서 발산하나 damping으로 부드럽게 수렴.
  9. 결과2: L/K 고정 시 L,K↑일수록 SISO AWGN에 근접(large-dimension behavior), 20 path에서 BER 10⁻³ 기준 SISO AWGN과 0.25dB 차.
  10. 한계: 순수 시뮬(복잡도 O(K²Nt²)), HW 미설계, LDPC 복호가 아닌 채널 등화, dense MRF 대상.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
MRF 기반 BP 등화기대응 없음Prime ECC는 sparse Tanner graph LDPC 복호 전용, MIMO-ISI 등화기 아님
message damping(convex 결합)decoder.cpp LDPC_Decoder() 이터레이션 루프개념상 반복 메시지 감쇠를 min-sum 루프에 적용 가능하나 LDPC는 이미 수렴 양호, 이득 불확실
pairwise compatibility(HᴴH 기반)대응 없음Prime ECC는 QC-LDPC PCM 기반, dense coupling 행렬 무관

적용 가치: 낮음 — LDPC ECC가 아닌 UWB MIMO-ISI 채널 등화 논문으로 부호설계·HW·NAND 요소가 없고, 유일하게 재사용 여지가 있는 message damping도 dense MRF 발산 대책이라 sparse LDPC에서의 이득이 불확실하다.
