B. 알고리즘 요약

  1. 대상: (dv, dc=kdv, L, M) spatially coupled(SC-LDPC) 부호와 그 tail-biting graph cover 앙상블의 LP(선형계획) 복호를 BSC 위에서 분석. rate/length는 파라미터 종속으로 미제시.
  2. 문제: SC는 BP threshold를 base LDPC의 MAP threshold까지 끌어올리는데(threshold saturation), LP 복호도 같은 이득을 보는지 미해결.
  3. 모델: -BSC에서 all-zero 전송 가정, LLR γi=±1. LP 복호는 codeword polytope를 fundamental polytope P=∩ conv(ζj)로 완화해 argmin Σγi xi 풀이.
  4. 핵심 결과(Thm 2.5): tail-biting graph cover 앙상블의 LP threshold ξGC와 파생 SC 앙상블의 ξSC가 동일 — 즉 LP 복호는 공간결합에서 이득이 없음(BP와 대조).
  5. 증명 도구1(Thm 3.2): LP 복호 성공 ⇔ dual witness 존재. 기존엔 충분조건만 알려졌던 것을 필요충분으로 확장, hyperflow/WDAG와 등가임을 확립.
  6. 증명 도구2(Thm 5.1/6.1): regular LDPC와 SC 부호 모두에서 hyperflow의 임의 edge weight가 block length n에 대해 sublinear(αmax ≤ cn^θ, θ<1)임을 상계, regular에선 tight(Thm 5.11).
  7. 직관: edge weight가 sublinear이라 경계에서의 정정이 중심으로 충분히 전파되지 못함 → BP가 공간결합으로 얻는 이득을 LP는 못 얻음.
  8. 도구3(Thm 8.1): 임의 binary linear code에서 crossover 확률을 모든 변수노드의 "LP excess"(slack)로 교환하는 방법 제시.
  9. 결과: 순수 존재/상계 정리들(Alg 1: WDG→hyperflow WDAG, Alg 2: WDAG→weighted forest 변환)로 구성된 이론 증명. 자체 실험/시뮬레이션 없음(참고문헌 [5]의 수치실험 언급뿐).
  10. 한계: HW·시뮬 전무, LP 복호 자체가 BP/min-sum 대비 계산량 커 NAND 컨트롤러에 부적합, 결과가 부정적(개선 없음).

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
LP 복호 알고리즘 전체대응 없음Prime ECC는 min-sum message passing(decoder.cpp LDPC_Decoder())이며 LP 복호 미사용
SC-LDPC(convolutional) 부호구조대응 없음Prime ECC는 block QC-LDPC 고정, 공간결합 구조 아님
dual witness/hyperflow 임계값 이론대응 없음순수 정보이론 존재증명, HW/알고리즘 이식 요소 없음

적용 가치: 낮음 — LP 복호가 공간결합에서 이득을 못 본다는 부정적 이론 결과이며, min-sum block QC-LDPC 기반 Prime ECC에 대응 모듈이 전혀 없다.
