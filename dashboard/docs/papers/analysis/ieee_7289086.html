B. 알고리즘 요약

  1. (61440, 20480) irregular LDPC 코드(rate 2/3), BPSK/AWGN 채널에서 min-sum 계열 디코더의 정규화 팩터 α를 다룸.
  2. 문제: 기존 정규화 min-sum(NMSA)의 상수 α나 기존 적응형(ANMSA)의 단일 α는 irregular 코드에서 체크노드 degree d_c별 편차를 반영 못해 SPA 대비 성능 열화가 큼.
  3. 가정: α는 이론적으로 체크노드 degree d_c와 사전 상호정보량 I(EXIT 분석 기반)에 의해 결정되나, 실제 구현에선 I 측정이 어려움.
  4. 핵심 기법: 실패 parity-check 비율 p = Σsᵢ/m (hard-decision d=Hᵀ·d로 계산)을 I의 대리 지표로 사용, 체크노드를 degree d_c별 서브그룹 T개로 나눠 각 그룹마다 α = g_i(p) lookup table을 둠.
  5. 핵심 식: 수평처리(check-to-variable) L_mn = α × sign(Z)곱 × min|Z_mn'| (식 12) — 여기서 α=g_i(p)가 매 이터레이션·매 서브그룹마다 갱신되어 min-sum의 soft 정보 정확도를 SPA에 근접시킴.
  6. 두 종류 lookup table: 코드 degree 분포만으로 학습하는 "General-adaptive function"(범용)과 특정 코드로 재학습하는 "Aiming-adaptive function"(코드 특화, 성능 더 우수).
  7. 부수 기법: Genie-Aided Training으로 SPA 출력과 min-sum 출력의 MMSE 기준 최적 α를 Monte Carlo로 곡선적합(curve fitting)·샘플링·양자화해 lookup table 생성, 이론상 상한(Genie-Aided Bound)도 함께 도출.
  8. 학습 절차: SNR을 바꿔가며 반복 시뮬레이션으로 (p, α_i) 데이터 수집 → 곡선적합으로 α=g_i(p) 함수화 → lookup table로 양자화.
  9. 결과: BER 10⁻⁵ 이하에서 기존 NMSA 대비 약 0.24dB 코딩이득, SPA와의 갭은 0.06dB로 축소.
  10. 한계: HW 구현·gatecount·throughput 등 실측 없음(순수 알고리즘 시뮬), 매우 긴 코드(61440)·특정 irregular degree 분포 전용, iteration 수 감소 효과는 언급 없음.
