B. 알고리즘 요약

  1. 대상은 DVB-S2 표준에 정의된 21종 QC-LDPC(IRA, Irregular Repeat-Accumulate) 코드로, 코드 길이 N=16200 또는 64800, 코드율 1/4~9/10이다.
  2. 풀려는 문제는 LDPC는 인코딩 스킴이 원래 정의되어 있지 않고, generator matrix G는 sparse하지 않아 인코딩 복잡도가 크다는 점 - 21종 코드를 하나의 HW로 지원하는 programmability도 필요.
  3. IRA 코드 parity part는 staircase 구조(accumulator에 대응), information part는 매 360열마다 새 컬럼 패턴이 나타나고 나머지는 순환 시프트(quasi-cyclic) 구조를 가진다.
  4. 핵심 기법: shift register 대신 single-port RAM을 사용하는 quasi-cyclic 인코더 구조 - 정보부 H_I의 파티 생성 행렬 G_P^I = H_I^T를 barrel shifter + m개 EXOR + RAM으로 계산.
  5. 인코딩은 m=360 비트 단위로 p=m/s 병렬 입력을 받아 시프트 후 RAM에 mod-2 누적(read-modify-write, 2클록/워드) - 정보벡터 전체(m×k_0 비트) 처리 후 parity 완성.
  6. 확장 기법: 순서 문제(permuted matrix 순서 vs. 원래 parity check 순서 불일치) 해결을 위해 RAM을 b개로 분할하고 데이터를 interleave 저장하는 partitioned RAM 기법(diagonal read).
  7. 부수 트릭: p비트 parallel accumulator(8비트 예시, EXOR 8개+레지스터), 최대 column weight C_max ≤ s/2 조건 하에서 동작.
  8. 별도 학습/최적화 절차는 없음(구조적 설계).
  9. 결과: FPGA(Altera Stratix EP1S80) 합성 결과 11840 LUTs, 11 RAM 블록, 50MHz 클록으로 최대 400Mbps 처리, 기존 shift-register 방식(57k bits 레지스터, 약 0.5M게이트) 대비 복잡도 대폭 절감.
  10. 한계: 인코더 HW 구조에 국한되며 디코더/정정성능(BER, error-floor, iteration)에 대한 언급이나 실험이 전혀 없고, ASIC이 아닌 FPGA 합성 결과만 제시.
