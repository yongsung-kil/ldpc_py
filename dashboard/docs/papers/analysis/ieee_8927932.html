총평: bit-flipping(GDBF) 계열 개선으로 Prime ECC의 min-sum 파이프라인과 알고리즘 패러다임이 달라 이식성 낮음.

B. 알고리즘 요약

  1. 대상은 PEGReg504×1008 regular(3,6) 및 PEGirReg504×1008 irregular LDPC, rate=1/2, length=1008, BPSK/AWGN, BF(bit-flipping) 계열 hard-decision 디코더.
  2. 문제: NGDBF는 random perturbation으로 local maxima 탈출을 시도하나 종종 실패하고 진동함.
  3. 모델: ML 디코딩을 목적함수 f(x)=Σxk·yk + Σsi 최대화 문제로 보고 GDBF가 이를 gradient descent로 근사.
  4. 핵심기법(TNGDBF): NGDBF의 inversion function Ek = xk·yk + w·Σsi + qk(식3, qk~N(0,η²N0/2))를 그대로 쓰되, tabu-list L을 추가.
  5. 식 의미: Ek가 가장 음수인 비트를 flip해 f(x) 증가; tabu-list는 직전 iteration에서 flip한 위치를 후보에서 제외(argmin_{k∉L_{T-1}} Ek).
  6. 확장: tabu-list + random perturbation 병행으로 인접 두 iteration간 동일 비트 반복 flip 차단, local maxima에서 탈출.
  7. 구현 디테일: 매 iteration 단일 비트 flip(single BF), w=0.75, η=1 기본; 최적 η는 SNR별 경험적 튜닝(SNR↑ 시 η→1).
  8. 학습: 최적 noise scale η를 SNR별 시뮬레이션으로 산출(예 3dB η=0.2, 5dB η=0.65).
  9. 결과: BER=10^-6에서 NGDBF 대비 약 0.2dB(regular)/0.25~0.35dB(irregular) 이득, T=200 TNGDBF가 T=300 NGDBF와 동등(수렴 가속).
  10. 한계: HW 미설계(시뮬만), gatecount/throughput 미제시, 짧은 부호·AWGN만, single BF만 다룸.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| GDBF/BF 디코딩 알고리즘 전체 | decoder.cpp LDPC_Decoder() | 이터레이션 루프 위치는 대응하나 min-sum과 알고리즘 패러다임 상이 |
| 목적함수/inversion function Ek | 대응 없음 | Prime ECC는 min-sum message passing, bit-flip 목적함수 미보유 |
| tabu-list (flip 이력 관리) | 대응 없음 | 관련 구조 없음 |
| 조기종료(syndrome 검사) | partial_CRC.cpp partial_crc_HW_T4(), full_CRC.cpp | syndrome 기반 종료와 유사하나 우리 것은 CRC 기반 |

적용 가치: 낮음 — Prime ECC는 min-sum message-passing 디코더인 반면 본 논문은 GDBF bit-flipping 계열로, waterfall·iteration 개선 방향은 겹치나 알고리즘 구조가 이질적이고 HW 미설계라 이식 부담이 큼.
