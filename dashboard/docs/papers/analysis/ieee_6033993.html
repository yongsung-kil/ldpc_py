B. 알고리즘 요약

  1. 대상: 이진 소거채널(BEC)용 LDPC 부호앙상블 (λ(x), ρ(x)) degree distribution 설계, 고정 rate r=0.45~0.6 예제.
  2. 풀려는 문제: BP 임계값 εBP를 최적화하면 degree-2 변수노드 비중이 커져 최소거리가 작아지고 error-floor가 생겨 실용성이 떨어짐.
  3. 핵심 모델: BP를 소거채널에서 재해석한 peeling decoder(PD) — 차수 1 검사노드와 연결 변수노드를 매 iteration 제거.
  4. 핵심 기법 1단: TEP 디코더는 PD 확장으로 차수 2 검사노드도 처리(두 변수가 동일함을 이용, V1이 V2 연결을 상속) → 차수 1 검사노드를 새로 생성.
  5. 핵심 식: 임계값 부등식 εBP ≤ εTEP ≤ εMAP ≤ 1/µ (µ=λ'(0)ρ'(1)), TEP는 선형복잡도로 BP보다 높은 임계값 달성.
  6. 핵심 기법 2단: TEP 임계값 εTEP은 미분방정식으로만 계산 가능(해석식 없음) → PD 잔여그래프 GPD 기반 근사 최적화로 우회.
  7. 부수 트릭: 잔여그래프 크기 e(GPD)를 절대임계점 xabs(εBP+ζ)로 표현(Lemma 1), 이를 최소화하는 것이 TEP 이득 극대화와 강한 상관.
  8. 최적화 절차: min xabs(εBP+ζ) s.t. rate 고정, λ2≤Λmax, δBP≤δmax 제약의 비볼록 문제를 해석 가능한 형태로 변환.
  9. 결과: Ensemble A(r≈0.484) εTEP=εMAP=0.4913, Ensemble B(r≈0.606) εTEP=εMAP=0.3808 — 정규화 이득 Gr=100%(MAP 달성).
  10. 한계: BEC 소거채널 점근 이론뿐, HW 미설계·시뮬 없음·유한길이 실험 없음, NAND soft-read 채널과 무관.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
TEP degree distribution 설계대응 없음Prime ECC는 특정 QC-LDPC H-matrix 고정, 소거채널 앙상블 설계와 무관
BEC peeling/TEP 디코더대응 없음Prime ECC는 AWGN/RBER 채널 min-sum 디코더, 소거 전용 PD/TEP 미대응
부호구조 로드ecc_top.cpp Load_PCM()논문의 앙상블은 H-matrix로 직접 매핑되지 않음(unstructured degree distribution)

적용 가치: 낮음 — BEC 소거채널의 점근 부호설계 이론으로 NAND용 binary QC-LDPC(soft-read AWGN/RBER, HW 고정 H-matrix)에 떼어 쓸 접점이 없다.
