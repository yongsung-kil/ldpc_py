B. 알고리즘 요약

  1. 대상은 protograph 기반 LDPC convolutional codes(LDPC-CC): base matrix B를 size-M permutation으로 copy-and-permute 확장, 여기서는 regular (J,K), rate R=0.5 사례.
  2. 풀려는 문제: LDPC-CC는 무한 비종단(non-terminated)일 때 BP threshold가 용량 근접하나 전체 BP 복호는 latency·복잡도로 비실용적.
  3. 핵심 기법: 윈도우 복호(WD) — parity-check 행렬의 convolutional 구조상 (ms+1) 이상 떨어진 VN은 같은 check에 안 묶임을 이용해 크기 W 윈도우를 슬라이딩하며 targeted symbol만 BP로 복원.
  4. Latency 식: A_WD/A_BP = (W+ms)/L로 latency가 1/L로 감소, W로 성능-지연을 온더플라이 조절.
  5. 구성법: classical construction Cc(J,K)는 ms=a-1 고정·Bi 전부 1 → WD에 부적합(threshold εw=0). Modified construction Cm(J,K)는 ms와 degree 독립, Bi 자유화.
  6. WD 조건: Bo에 1이 있으면 Cm(J,K'J)는 WD에 나쁨(Prop.5) — bad structure 회피 필요. threshold는 P-EXIT 수치해석으로 평가.
  7. BEC 결과: Cm(3,6) 앙상블 C2(ms=3),C3(ms=2)에서 windowed threshold가 W=ms+1에서도 최대치·BP threshold(≈0.4881)에 근접.
  8. 메모리 있는 소거채널: 최대복원버스트길이(MBL) Lmax를 stopping set의 span (S)*로 지배. Cm(J,2J) ms에서 (S)*=2ms가 최적(Prop.7).
  9. MBL 경계: M((S)*-2)+1 ≤ Lmax ≤ M(S)*-1 — regular LDPC-CC의 MBL은 동일 rate MDS부호 대비 bounded away.
  10. 한계: 순수 이론(asymptotic density evolution/P-EXIT + 유한길이 Monte-Carlo), HW·양자화·연판정 없음. 채널은 소거(erasure)뿐, NAND의 AWGN/RBER과 무관.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
LDPC-CC protograph 구성대응 없음Prime ECC는 QC-LDPC 블록부호 고정, convolutional 구조 미지원
윈도우 복호(WD)대응 없음블록 단위 iterative decoder(decoder.cpp)와 슬라이딩 윈도우 방식 상이
소거채널/MBL/stopping set span대응 없음Prime ECC 채널은 AWGN/RBER, 소거·버스트 모델 아님

적용 가치: 낮음 — convolutional code + 소거채널 앙상블 threshold 이론으로, NAND binary QC-LDPC 블록부호의 부호설계/디코더/HW에 떼어 쓸 요소가 없음.
