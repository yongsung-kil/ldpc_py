B. 알고리즘 요약

  1. 시스템: 랜덤 구성 irregular LDPC, code length 7488, rate 0.41, AWGN 채널, density evolution 기반 degree 분포(λ(x), ρ(x)=0.5x⁵+0.5x⁶).
  2. 문제: 같은 SNR에서도 노드의 girth/degree/cycle 분포가 불균등해 noise distribution pattern에 따라 BP 성능 변동이 큼(수렴 반복수가 크게 산포).
  3. 모델: x=1↔+1, x=0↔-1, r=x+n(AWGN). good/bad noise 판별 기준 r=sign(x)·n 도입 — n<-1이면 오판(bad noise), n>0이면 판정 강화(good noise).
  4. 핵심 기법 1: variable node를 GNSR/BNSR/NOR로 구분, 교집합 NSR의 노드가 성능에 지배적. 노드별 noise sensitivity Aᵢ를 표본 통계로 계산, 임계 θ 초과 노드를 NSN으로 지정.
  5. Aᵢ 정의: 각 표본의 iteration Iⱼ·error bits Eⱼ로 만든 good/bad 패턴 정도 f(Iⱼ,Eⱼ), g(Iⱼ,Eⱼ)의 노드별 누적 — bad noise에 민감한 노드를 식별하기 위함.
  6. 핵심 기법 2: systematic part q에 위치한 NSN을 SNSN(system NSN)으로 정의, 이들을 고정값 '1'로 설정하고 인코딩/디코딩 양측이 공유 → 해당 노드의 r이 항상 최대값이 되어 나쁜 패턴 확률 감소.
  7. 구현: 고정 m 비트를 채널로 전송하지 않고 인코더·디코더 구조에 직접 삽입(bandwidth efficiency 논리), f=b/(Iⱼⁿ+Eⱼ/c) 등 상수 a,b,c는 max iteration=200 기준 a=1.5, b=100, c=20.
  8. 최적화: NSN/SNSN은 Eb/N0에 크게 변하지 않음 → 오프라인 통계로 SNSN 100/200/400개 후보 선정.
  9. 결과: SP-LDPC는 원 시스템 대비 BER 0.15dB 미만 열화(고정비트 대역폭 손실)나 medium~high SNR에서 코딩이득 회복(200/400 SNSN에서 약 0.6dB 이득), 평균 반복수 20~40% 감소(원 시스템 52~24 iter → SP 감소).
  10. 한계: HW 미설계, 저rate(0.41) 랜덤 irregular 부호 시뮬만, 고정비트 삽입에 따른 유효 rate/용량 손실 상충.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SNSN 고정비트 인코딩 삽입encoder.cpp LDPC_encoder_4KB(), Generate_PCM_encoding()고정 known-bit를 systematic part에 넣는 부호/인코딩 변경 — dual-diagonal 고정 구조와 상충, 유효용량 손실
noise-sensitive 노드 통계 식별대응 없음오프라인 표본 통계 기반 NSN 탐색은 Prime 코드에 대응 모듈 없음
BP 디코딩 성능/수렴decoder.cpp LDPC_Decoder()알고리즘 자체가 아니라 고정비트로 초기 LLR을 강화하는 시스템 트릭이라 디코더 로직 변경은 없음

적용 가치: 낮음 — NAND ECC는 고정 페이로드에 known-bit 오버헤드를 넣을 여유가 없고(유효용량 직결), 저rate 랜덤 irregular 부호 대상이라 고rate QC-LDPC·dual-diagonal 인코더 구조에 이식할 요소가 사실상 없다.
