총평: 펑처링 rate-compatible LDPC의 error-floor를 right-degree 집중으로 잡은 code-design 논문 — 원리는 일반적이나 NAND 고정rate QC-LDPC엔 이식가치 낮음.

B. 알고리즘 요약

  1. 대상은 hybrid-ARQ용 rate-compatible punctured LDPC로, 하나의 mother code(rate 0.5)를 펑처링해 0.5~0.9412 범위 rate를 지원한다.
  2. 문제: 기존 E2RC 구조는 선형인코딩·좋은 BER은 주지만 base rate에서 error-floor가 높아 ARQ 재전송이 과다해진다.
  3. 핵심 원인: E2RC의 parity sub-matrix Hp가 recursive dual-diagonal 형태여서 ρ(x) (right degree distribution)가 dispersive해지고 max right degree가 행 수 m에 비례해 커진다.
  4. SR(step-recoverable) 개념: 펑처 노드가 몇 번째 iteration에 복구되는지로 G1,G2,...를 나눠 낮은 SR 노드부터 펑처(빠른 복구 = 좋은 성능).
  5. 제안: Hp를 blocksize b=2^δ 단위 E(b,j) 블록의 recursive 구조 (5)로 일반화 — δ=d면 E2RC와 동일한 특수경우.
  6. 효과: δ로 max right degree를 직접 제어 → 작은 δ(예 4)로 PEG가 concentrated right degree distribution을 생성.
  7. 대가: 펑처 가능 심볼이 m-mb로 제한돼 최고 rate가 1/(1+2^(d-δ)/k) = 0.9412(k=512,δ=4)로 소폭 손실.
  8. 펑처 순서는 식 (7) pj = r·b+q+1로 블록 간 라운드로빈하게 낮은 SR 노드부터 선택.
  9. 결과: length 2048에서 waterfall 성능은 E2RC와 동일하되 base rate 0.5 error-floor가 크게 낮아지고, decoding error rate(DER)가 약 10배 감소(Table I).
  10. 한계: HW 미설계, AWGN 시뮬만, 순수 부호구조 설계로 QC-LDPC circulant 구조나 NAND 응용은 다루지 않음.
