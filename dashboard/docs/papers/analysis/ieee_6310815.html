B. 알고리즘 요약

  1. 대상은 인접행렬 H=[H1 H2] 형태의 효율적 인코딩(EE) 블록부호 (LDPC/GLDPC/DGLDPC), 예제 rate 1/2, length 1000~10000.
  2. 문제: erasure-filling(반복 MAP) 디코더로 인코딩할 때 인코딩 속도를 높이면 error-floor가 나빠지는데 이 트레이드오프를 정량 제어하고자 한다.
  3. 모델: 각 CN/VN을 임의 선형 컴포넌트부호 C(n,k)로 일반화, H2의 envelope(대각형 구조)이 순차 parity 결정으로 선형/서브선형 인코딩을 가능케 함.
  4. 핵심: recovery vector n=[n1,...,nD] (Σni = Mc) 도입. 길이 D가 인코딩 사이클 수를 결정 → 짧은 n일수록 빠른 인코딩.
  5. envelope 아래 Ci 집합으로 constrained/free edge 배치 규칙을 정의, MAP 디코더가 최대 D스텝에 codeword 인코딩 보장.
  6. EE-LDPC용 추가규칙: envelope 생성 후 두 번째 edge를 최소 degree CN에 append → IRA(n=[1,...,1]), EERC(n이 공비 0.5 등비수열)를 특수경우로 유도.
  7. 구현 디테일: degree-1 VN 수 = nD, n이 급감하면 마지막 CN들이 dispersive high-degree → 둘 다 error-floor 악화 요인.
  8. 최적화: degree 분포를 differential evolution + EXIT chart로 도출, PEG로 그래프 구성.
  9. 결과(시뮬, Imax=200, SPA): n 원소가 커질수록(=D 짧을수록) error-floor 심화; 같은 D라도 세심한 설계(L5)로 완화 가능. GLDPC(Hamming 컴포넌트)는 짧은 D에서도 floor가 양호.
  10. 한계: 순수 부호설계 이론+시뮬(짧은 부호), HW/throughput 없음, binary SPC-LDPC보다 GLDPC/DGLDPC 위주.
