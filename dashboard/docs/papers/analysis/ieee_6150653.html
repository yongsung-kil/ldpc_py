총평: QC protograph LDPC의 short cycle 수를 고유값으로 빠르게 세는 분석 도구로, girth 평가엔 유용하나 Prime ECC 부호설계·복호에 직접 이식할 알고리즘은 아님 — 이식가치 낮음.

B. 알고리즘 요약

  1. 대상: QC protograph LDPC (base graph를 lifting degree N으로 순환치환 lift한 QC 코드), 예로 (155,64), IEEE 802.11 n=1944/1296/648.
  2. 문제: 이터레이티브 복호 성능은 Tanner 그래프의 short cycle 분포와 직결되므로, 다양한 길이의 short cycle을 효율적으로 세는 알고리즘이 필요.
  3. 기반: 유향에지(Hashimoto) 행렬 Ae의 거듭제곱 trace가 tailless backtrackless closed walk 수를 주고, k<2g이면 이는 길이 k 사이클 수와 일치.
  4. 핵심 식 (2): Nk = Σ λi^k /(2k), 즉 Ae 고유값 λi만 알면 2g 미만 사이클 수 계산 가능.
  5. 복잡도 축소 착안: 이분그래프라 Ae는 블록 B,C 형태(3), Ae^2의 고유값은 BC와 CB의 합집합 → 더 작은 행렬만 다루면 됨.
  6. QC 구조 활용: protograph lift로 B=Bcirc(Bb,0,..), C=Bcirc(C0,..,CN-1)이 되어 BC(7)가 블록순환 구조를 가짐.
  7. 핵심 정리 2: 블록순환 행렬의 고유값은 N개의 |Eb|×|Eb| 행렬 H(ρ)(ρ는 N차 단위근)의 고유값 합집합 → 복잡도 O(N^3|Eb|^3)→O(N|Eb|^3).
  8. 비교: 기존 [11] 알고리즘 O(gN^2|Eb|^2) 대비, gN이 |Eb|보다 빨리 커지는(작은 base·큰 lifting) 경우 더 저복잡.
  9. 결과: (3×5) base·N=400/1000/2000에서 1.1/6/18s (기존 [11] 3.5/20/119s, [7]은 메모리 부족); QC 코드가 유사 랜덤 코드보다 girth/short-cycle 분포 우수(예 N=2000시 g=12 vs 랜덤 g=6).
  10. 한계: 순수 분석(계수) 도구로 부호구성·복호 알고리즘 자체는 제시하지 않음, MATLAB 실행, HW·정정성능 무관.
