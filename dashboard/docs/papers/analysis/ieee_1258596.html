총평: array-code QC 구조를 p-blocked 처리+프로그래머블 스위치로 다룬 초기 SPA 아키텍처. 부분갱신 스케줄과 스위치 라우팅 아이디어는 참고가치 있으나 min-sum 기반 현대 QC-LDPC HW와 직접 매핑은 제한적.

B. 알고리즘 요약

  1. 대상: array-code 기반 regular QC-LDPC. PCM은 소수 p와 정수 j,k(열/행 무게)로 jp×kp 크기, blocks는 p×p 항등행렬 I와 순환치환행렬 α의 거듭제곱으로 구성.
  2. 문제: 완전병렬 SPA는 메모리 大 + 그래프 edge로 인한 복잡한 인터커넥트 → 긴 부호·다양한 파라미터 대응이 어려움.
  3. 채널: AWGN, 이진/다치 전송. 입력은 채널통계로 얻은 LLR L(xn).
  4. 핵심 SPA: check-node에서 Λ~m,n = σm − φ(|λm,n|), φ(z)=log tanh(z/2) (full sum-product, tanh 기반) + sign 곱, symbol-node에서 λm,n = λn − Λm,n.
  5. 핵심 통찰: α와 그 거듭제곱을 "p-입력 p-출력 스위치 유닛"으로 보고 SPA를 p-wide 벡터연산으로 표현 → edge 라우팅을 스위치 설정으로 흡수.
  6. 아키텍처: symbol-node 변수 λ를 j개 레지스터 뱅크에 저장, 상·하 스위치 유닛이 α^(p-1)ql 곱을 암묵 수행, 누산기(ACC)로 σ 계산(식8~12).
  7. 메모리: check-node 메시지 저장이 jp(부호길이·edge수 무관), 완전병렬(2jpk) 대비 최대 ~50% 저장 절감.
  8. 스위치 구현: 논블로킹 위해 Benes 또는 Banyan 스위치. Banyan은 α가 순환shift 치환일 때 논블로킹 성립(Lemma, 부록 증명). p를 2의 거듭제곱 P에 임베딩+MUX단 추가.
  9. partial-update 스케줄: 각 iter마다 j개 뱅크 중 하나만 갱신(round-robin) → iter당 처리시간 2k(1+j)t → k(2+j)t, 처리속도 ~60% 향상.
  10. 결과/한계: (2209,2024)/(4489,4224) 부호에서 부분갱신은 20 iter 제한 시 ~0.25dB 손실, iter 늘리면 손실 무시가능. gatecount/throughput 본문 미제시, DSL(~100Mbit/s)·자기기록 타깃.
