B. 알고리즘 요약

  1. 대상: (N,3,6) regular QC-LDPC(circulant 순환행렬 배열)에서 유도한 encodable irregular QC-LDPC, 예제 (282,3,6) p=47, rate 1/2.
  2. 문제: QC-LDPC의 인코딩 문제 — 패리티검사행렬에 종속행이 있어 systematic 생성행렬용 부분행렬 A가 특이(singular)해 역행렬을 못 구함.
  3. 기존 방식 한계: A를 bi-diagonal 행렬로 대체하면 가역이 되나 짧은 girth 유발·최소중량 저하 → 무게 1 코드워드 발생해 BER 악화(Example 1의 [11], DVB-S2/802.16e류).
  4. 핵심 기법: A의 일부 circulant만 zero 행렬 Z로 바꿔 가역으로 만들되(식 8~9), 부분행렬 B는 유지 → 새 short girth 없이 큰 최소중량/거리 보존.
  5. 핵심 식: girth-4 판정 O=H^T H의 대각 외 성분이 모두 0/1이면 girth-4 없음(Theorem 1), 세 열벡터의 겹침으로 girth-6 판정(Theorem 2).
  6. 부수 도구: 최소중량 추정 알고리즘 — 생성행렬 G 행벡터 최소중량 wmin(g)과 실제 wmin(c)를 디코더로 추정([20]).
  7. 결과: (282,3,6) 예제에서 제안 코드(15)는 girth-4/6 모두 0, wmin(g)=62/wmin(c)=35로 최대, 기존 (17)은 wmin(c)=1로 BER 최악.
  8. 검증: BPSK AWGN + BP 디코더(최대 20 iter) 시뮬로 제안 코드가 기존 encodable irregular QC-LDPC보다 우수한 BER 확인(Fig.3).
  9. bi-diagonal A를 재적용하면(Case 2) 세 코드 모두 girth-6 증가·최소중량 감소로 BER 악화 → bi-diagonal 방식의 부작용 입증.
  10. 한계: 저rate 소형 코드 예시뿐, HW 미설계, 고rate/대형 코드로의 확장 미검증.
