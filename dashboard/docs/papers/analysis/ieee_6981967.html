B. 알고리즘 요약

  1. 대상 시스템: 확률 그래프 모델(Ising/Potts) 위 BP와, 응용으로 (3,6)-regular LDPC(길이 2640, rate 0.5) BP 디코더.
  2. 문제: 나노소자 HW가 본질적으로 불안정 → BP 메시지 계산이 zero-mean transient additive 잡음 w를 받아 nominal BP가 수렴하지 못하고 fixed point 주변에서 진동.
  3. 모델: 메시지 업데이트 m^ℓ = f(m^{ℓ-1}) + w^ℓ, contraction mapping 조건 sup‖f'(u)‖ = K < 1 가정(수렴 보장 그래프).
  4. 이론 기여: fixed point 거리 상계 ‖m^ℓ-m*‖ ≤ ‖m^0-m*‖K^ℓ + (1-K^ℓ)/(1-K)·ξ, ℓ→∞이면 ξ/(1-K)로 수렴 잔차만 남음(Corollary 1).
  5. 기법1 Censoring BP: ‖m^ℓ-m^{ℓ-1}‖ > K‖m^{ℓ-1}-m^{ℓ-2}‖이면 오계산으로 간주해 재계산(backoff τ 포함). soft-adder처럼 잡음이 확률 pw로 정확히 0일 때 유효.
  6. 기법2 Averaging BP: 최종값 대신 지금까지 모든 iteration 메시지 평균 m̄^ℓ = (1/ℓ)Σ m^i를 belief로 사용 → zero-mean 잡음이 평균으로 상쇄.
  7. 핵심식 의미: E‖m̄^ℓ-m*‖_1 상계가 대략 1/ℓ로 감소(Prop.2) → 일반 zero-mean 잡음에 대해 수렴 보장, censoring보다 오버헤드 약간 큼(합만 누적, 상수 메모리).
  8. LDPC 적용: Gaussian approximate density evolution으로 채널잡음 σch·계산잡음 σcmp 평면의 decoding threshold σ*ch(σcmp) 유도. 이진 LDPC라 부호 판정만 필요해 division 생략, Σ m_v^i의 부호로 결정.
  9. 결과: σch=0.6 저계산잡음 영역에서 averaging BP 디코더가 nominal 대비 잔차오류율 약 20배 감소. random bit-flipping(5bit 양자화) 모델에서도 sign-bit flip 상쇄로 개선. min-sum 디코더에도 유사 개선 관찰.
  10. 한계: HW 미설계(향후 과제로 명시), 시뮬만, contraction mapping은 유한길이 사이클 그래프에서 미성립(tanh^-1 발산), 저잡음 영역에선 평균화가 오히려 수렴 지연.
