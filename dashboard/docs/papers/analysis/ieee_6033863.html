B. 알고리즘 요약

  1. 대상: 결합(spatially-coupled) sparse graph 코드 = LDPC convolutional(LDPCC) 앙상블 (l,r,L,M)을 BEC에서 유한길이 분석. 예시는 regular (3,6) protograph 체인, 길이 (2L+1)M.
  2. 문제: threshold saturation(BP threshold가 underlying (l,r)의 MAP threshold로 상승)의 유한길이 스케일링이 미해명 — L을 M의 함수로 키울 때 현상이 유지되는가.
  3. 모델: (2L+1)개 (l,r) protograph를 좌우 l̂=(l-1)/2개 check에 결합·종단, design rate R = (k-1)/k - 2l̂/(k(2L+1)).
  4. 핵심 결과1: threshold saturation은 L이 M보다 상당히 빠르게 커도 견고. 지수 스케일링이 정확히 경계 — subexponential 성장이면 유지, superexponential이면 붕괴.
  5. 복잡도: 필요 iteration 수 분포 ϕ(ℓ)를 실측. ε≥ε_BP에서는 "decoding wave"가 경계에서 중앙으로 등속 이동 → iteration이 L에 선형 증가.
  6. 관찰: M 증가 시 iteration 분포가 평균 주위로 집중되나 heavy-tail(power law) 존재 → 일부 인스턴스는 훨씬 많은 iteration 소요.
  7. error-floor: weight-2 codeword/stopping set만 고려 (고weight는 M에서 빠르게 소멸).
  8. 핵심 식: weight-2 codeword 개수 N2H ~ Pois(λ), λ = C(k,2) k^(l-2) (2L+1)/M^(l-2). error-floor level Pb ≈ 2λ/(M(2L+1)).
  9. 결과: no-error-floor 코드 비율 ≈ exp(-λ). L이 M^(l-2)보다 느리게 크면 expurgation 쉬움. Poisson 근사가 실험(10^4 samples)과 거의 완벽 일치.
  10. 한계: BEC 전용, HW 미설계, 시뮬/이론뿐. spatially-coupled 구조는 Prime ECC의 고정 QC-LDPC와 상이.
