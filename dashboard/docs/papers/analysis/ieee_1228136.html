B. 알고리즘 요약

  1. 대상은 2-(v,k,1) design(사영평면 PG(2,q), affine평면 AG(2,q))의 incidence matrix를 패리티 검사행렬로 쓴 LDPC 부호다.
  2. 문제: BEC 반복복호 성능은 최소거리가 아니라 최소 stopping set 크기 s_min으로 결정되며, 작은 stopping set이 없어야 좋은 부호다.
  3. stopping set S는 Tanner 그래프에서 이웃 체크노드가 모두 S에 최소 2번 연결되는 변수노드 집합으로 정의된다.
  4. 핵심 하한(Theorem 1): 2-design D에서 s_min(D) ≥ k+1이며, D가 GPC(generalized Pasch configuration)를 포함할 때만 등호.
  5. 의미: k ≥ t인 2-design을 고르면 크기 t 이하 stopping set이 없는 LDPC 부호를 구성할 수 있다(정정능력 하한 설계법).
  6. 부호 최소거리와의 연결(Corollary 2): d_min(C)=k+1 ⟺ s_min(D)=k+1.
  7. 상한(Theorem 3, Corollary 4): 블록 disjoint 집합 E_P 구성으로 s_min(D) ≤ b-(r-1)min(k,r-2)-1.
  8. PG(2,q), AG(2,q)는 q=2^s일 때 GPC를 포함해 하한 등호 달성, 이때 s 증가에 따라 rate가 1에 접근.
  9. 결과 예: 홀수 q에서 s_min(PG(2,q))≥q+3이나 rate가 1/(q^2+q+1)로 매우 낮고, q=3에서 s_min(PG(2,3))=6, s_min(AG(2,3))=5.
  10. 한계: BEC·반복복호 stopping-set 이론에 국한, 유한길이 BER/AWGN·NAND 채널·디코더·HW 미제시(1페이지 correspondence).

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
2-design(finite geometry) 기반 H-matrix 구성ecc_top.cpp Load_PCM()Prime ECC는 특정 QC-LDPC H-matrix 고정, 기하기반 부호구성으로 교체는 재검증 부담 큼(이식 난이도 높음)
stopping set 크기 하한 → error-floor 보증대응 없음부호구조로 error-floor를 보증하는 이론이나 stopping-set 분석 모듈 없음
BEC 반복복호 성능 분석decoder.cpp LDPC_Decoder()복호기는 있으나 BEC/stopping-set 관점과 달라 min-sum AWGN/RBER 대상과 상이

적용 가치: 낮음 — stopping set 하한으로 error-floor를 이론적으로 보증하는 가치는 있으나, 유한기하 2-design 부호구성이 Prime ECC의 고정 QC-LDPC와 구조가 다르고 홀수 q에서 rate가 극히 낮아 고rate NAND ECC에 직접 이식하기 어렵다.
