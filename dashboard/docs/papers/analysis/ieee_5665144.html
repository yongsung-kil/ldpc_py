총평: CRT 기반 임의(nonprime) 블록길이 irregular QC-LDPC 구성법으로, 특정 QC-LDPC가 고정된 Prime ECC 부호구조 교체 부담이 커 이식성 하.

B. 알고리즘 요약

  1. 대상은 magnetic recording용 4Kbit 고rate(R=0.81, 0.9) irregular QC-LDPC이며 AWGN 채널, 디코더 iteration 상한 30.
  2. 기존 CRT 결합법([4],[6],[7])은 prime-prime sub-matrix 크기만 지원해 임의 블록길이를 못 만든다는 한계를 푼다.
  3. 핵심은 두 성분부호 H1,H2의 지수행렬 E(H)를 CRT로 결합해 큰 길이 L=L1·L2의 부호를 만드는 것(식 (9)~(11)).
  4. Dmn = Σ Dmn^q · bq · L'q mod L, L'q=L/Lq, bq·L'q ≡ 1 mod Lq 로 각 성분지수를 합성한다.
  5. 이 식은 girth가 성분부호 이상으로 유지되게 하는 표준 CRT 결합(식 (11) cmn).
  6. 확장: GCD(L1,L2)≠1(nonprime-nonprime/nonprime-prime) 경우를 case 2 절차로 다뤄, H2를 H1의 수정판(am2n = am1n ± x)으로 구성해 CRT 규칙 amn/Lq = amn^q 을 만족시킨다.
  7. 구현 트릭: 결합 후 Modified Array Codes(MAC) 구조로 재배열해 하삼각 '1' 수를 줄여 인코딩을 단순화하고, [13] interleave(식 (5), T-matrix 이동)로 성능을 약간 개선.
  8. 학습/최적화 절차 없음(순수 대수적 구성).
  9. 결과: MAC[9] 대비 우수, nonprime-prime 쌍이 약간 더 좋고, interleaving은 BER=1e-6에서 약 0.1 dB 개선.
  10. 한계: HW/디코더 미설계, prescribed girth는 못 만들며 H2에 cycle-4 잔존(성능엔 영향 없다 주장), 이득이 소폭.
