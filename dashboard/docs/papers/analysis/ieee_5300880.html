B. 알고리즘 요약

  1. DVB-S2 LDPC(rate 1/2, N=16200/64800, 실험은 1/15 축소한 N=1080)의 encoding용 parity-check matrix H=[Ha Hb] 구조를 다룸.
  2. 축소 코드에서 Hb가 bi-diagonal 구조를 유지할 경우 girth-4와 저최소가중치 코드워드가 발생해 error floor가 심해지는 문제를 분석.
  3. Theorem 1: HH^T의 대각선 외 원소가 모두 0/1이면 girth-4 없음. Theorem 2: 생성행렬 G의 행벡터 최소가중치 wmin(g)가 코드워드 최소가중치의 상한.
  4. 기존 축소 DVBS2_1080 코드는 wmin(g)=16으로 저가중치 코드 다수 존재, HHT에 2 이상 원소 존재하여 girth-4 발생 확인.
  5. 개선안: Hb를 순환천이 항등행렬 I(p(z_f,i,1)) 12x12 블록의 quasi-bi-diagonal 구조로 재설계 (식 11), shift 값은 p(z_f,1,1)=3, p(z_f,i,1)=0 (i=2~11), p(z_f,12,1)=7.
  6. 설계 알고리즘 4단계: (1) Ha 재설계, (2) Hb를 quasi-bi-diagonal로 설계, (3) shift 값 조정하며 Hb 비특이성/girth-4/저가중치 여부 검사, (4) 결합해 최종 H 생성.
  7. 개선 코드는 wmin(g)=97로 저가중치 코드 제거, Theorem 1 검증 결과 HHT 대각선 외 원소 모두 1 이하로 girth-4 없음 확인.
  8. 학습/최적화 절차 없음(수동 shift 파라미터 탐색).
  9. 결과: AWGN+BPSK 채널, 최대 20회 반복복호 시뮬(200 프레임, 프레임당 540비트). 개선 코드 BER 곡선이 랜덤 LDPC 코드에 근접(기존 축소코드는 2~3.5dB 구간에서 완만히 하강, waterfall 없음).
  10. 한계: 실제 DVB-S2 전체 길이(16200/64800)가 아닌 1/15 축소 코드로만 검증, HW 구현/게이트카운트/throughput 없음, 순수 시뮬레이션.
