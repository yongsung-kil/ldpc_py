B. 알고리즘 요약

  1. 대상: P×P circulant로 구성된 binary QC-LDPC를 exponent matrix E+circulant size P로 표현, Tanner graph girth를 8 이상(4/6-cycle 제거)으로 보장.
  2. 문제: girth≥8과 dual-diagonal(DD, 인코더 복잡도 저감) 구조를 검색 없이 동시에 명시적 구성하는 방법이 부재.
  3. 프레임워크: GCD 제약 — 삼중항 [ai,aj,ak]가 (ak-ai)/gcd(ak-ai, aj-ai) ≥ L이면 girth-8 (J,L)-regular 부호 생성, P ≥ (a_{J-1}-a0)(L-1)+1.
  4. DD 구조: 기존 E에 우측 E_R2 부분행렬을 붙이고 단일 미결정항 x 하나만 남긴 exponent matrix E_dd2 정의(Theorem 1/2로 4/6-cycle 불발 조건).
  5. 핵심 하한: J=2m+1, i=m에서 P > P0 = 2(L-1)[(2m-1)(L-2)+4]이면 4/6-cycle 없는 x가 최소 P-P0개 존재(Theorem 3), 6-cycle 유형 A~F 계수로 유도.
  6. 신규 구성: 열가중치 J=7, 임의 L에 대해 E1 = [0,1,L+1,5L+2,6L+2,6L+3,7L+3]^T·[0,...,L-1]로 girth-8 보장(Theorem 4, P≥(7L+3)(L-1)+1).
  7. circulant size 이점: 신규 구성은 약 7L^2(경험적으로 (2L-3)(3L+1)≈6L^2)로, 기존 base-expansion(~L^3)/max-function 대비 L≥14에서 대폭 작음(Table IV).
  8. DD의 x 공식: mod(L,7)=5에서 x ∈ {-L, -L(L-2), -L(L-5)}가 girth-8을 보장(Remark 2), 검색 불필요.
  9. 결과: (3146,1452)@P=242, (4550,2275)@P=325 예제 — x=0은 최악, 랜덤 x=121은 severe error floor, 공식 x=-L(235)이 최상 성능; 신규 DD가 GCDg8 검색 부호와 동등~우수, masking 적용도 동등.
  10. 한계: BPSK/AWGN·SPA 50 iter 시뮬만, HW 미설계, J=7 고정, rate 미확정, Remark 1/2의 일반 L 증명 및 x-성능 관계(trapping/absorbing set) 미완.
