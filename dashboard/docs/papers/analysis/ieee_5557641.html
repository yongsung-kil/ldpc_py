B. 알고리즘 요약

  1. 대상은 dual-diagonal parity 구조의 binary QC-LDPC(802.11n/802.16e류), AWGN-BPSK 채널, layered min-sum(max 25 iter, LLR 5bit 양자화).
  2. 문제: 기존 QC-LDPC는 정보부 circulant를 랜덤 선택해 parity-check matrix 저장 메모리가 크고 인코딩 구조가 비체계적.
  3. 핵심: q=2^s, m=q-1 circulant P에 대해 F_q 상 MDS 코드(길이 q+1, 최소거리 q)의 self-reciprocal 생성다항식 g(x) (계수 g_i=g_{q-1-i}) 정의.
  4. g(x) 지수를 λ 사상으로 옮겨 r×(q+1) block circulant H_r 구성 — 각 row block이 앞 row block의 cyclic shift라 parity-check 저장 메모리를 1/r로 절감, Tanner graph는 four-cycle 없음(girth≥6).
  5. masking: 이진 M과 H_r의 entrywise product M⊛H_r로 일부 circulant를 zero로 대체 → edge 감소·girth 증가.
  6. 핵심 정리(Thm.1): M=(M_I M_D)에서 M_D를 dual-diagonal 패턴으로 두면 M⊛H_r가 식(1) 형태(dual-diagonal parity)가 되고, r≥4면 M_I를 골라 full-rank·선형시간 back-substitution 인코딩 가능한 column block(식(2)) 확보.
  7. 결과 부호는 길이 q²-1, 차원 (q+1-r)(q-1); 예: q=64,r=18→(2268,1134), r=6→(2268,1890).
  8. 최적화: 성능은 M의 열/행 weight 분포 v_w,c_w에 좌우되며 density evolution으로 최적화, weight-2/3 열 서브그래프 girth 최대화.
  9. 결과: (2268,1134)/(2268,1890) 구성 부호들이 802.11n(1944)/802.16e(2304/2304) 표준 부호와 대등한 BER/FER, 구조 제약에 의한 성능저하 없음.
  10. 한계: HW 미설계, 길이·circulant 크기가 q에 종속돼 임의 rate/length 부적, 인코더/디코더 단순화는 정성적 언급에 그침.
