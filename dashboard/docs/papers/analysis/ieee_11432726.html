B. 알고리즘 요약

  1. n×m MRAM(MTJ) binary 메모리로 아날로그 MVM(dot-product) 수행, cell conductance G_ij=g_ij+Δ_ij, Δ~N(0,σ²), 열 누적 후 mid-tread 양자화로 y_j 산출.
  2. 문제: 아날로그 in-memory MVM은 행 병렬수 n 증가 시 DP 오류확률 ξ=2Q((t-0.5)/√n σ) 급증, 자주 외부 PU 정정 시 효율 손실.
  3. 핵심: 코드 parity 제약을 노이즈 추정에도 활용 - d개 P-state 짝수를 만족하는 셀집합의 analog syndrome s_A=[y_j] mod 2를 in-memory DP로 계산.
  4. unsatisfied analog check 확률 ρ_u(σ;d)=2Σ(-1)^ℓ Q((ℓ+0.5)/√d σ)이 단조증가·가역이라, syndrome Hamming weight w_A로 ML 추정 σ̂_A=ρ_u^{-1}(w_A/m;d).
  5. Fisher 정보 I_A(σ;d)로 CRLB 분석: σ→0 지수감쇠, σ→∞ 다항감쇠 → 각 check degree d가 특정 σ 구간만 α-정확 추정(예 d=4,16,64가 σ∈0.03~0.28 커버).
  6. analog syndrome이 logical(hard-decision XOR) syndrome보다 낮은 σ 관측성 우수 - 큰 magnitude DP 오류가 발생하는 저σ 영역에서 유리.
  7. 부호설계: bilayer LDPC(local-global), H_L(열-지역 check, 추정용)+H_J(행렬-전역 check, 정정용), column-systematic generator U로 부호화.
  8. H_L check degree 분포는 목표 평균차수 a_R*에 맞춰 Σ 커버하도록 quadratic integer programming으로 설계(Algorithm 1), VN분포·H_J는 EXIT chart로 로컬/글로벌 threshold 설계.
  9. 아키텍처: MVM 중 주기적 σ̂_A 추정(Algorithm 2), ξ>ξmax면 전체행렬 read 후 LLR 2G_ij/σ̂_A로 BP 복호·재기록.
  10. 한계: HW 미설계, 이론/해석 위주(수치검증 그림만), MRAM 아날로그 MVM 전용 모델.
