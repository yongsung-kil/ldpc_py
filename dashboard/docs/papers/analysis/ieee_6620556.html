B. 알고리즘 요약

  1. 대상: 이진 "pattern erasure" 부호 C(n,m,c,t) — 소거가 임의 위치가 아니라 정해진 패턴 집합 P(m-regular, cover number c)에서만 발생하는 채널.
  2. 문제: array/burst 소거의 일반화. RAID·디스크 어레이에서 그룹 단위(같은 디스크/전원)로 동시에 실패하는 소거를 정정하되 parity 밀도를 낮추려는 것.
  3. 모델: 코드워드 길이 n, 각 패턴 크기 m, 각 원소가 최대 c개 패턴에 등장. t-pattern erasure 부호 = t개 패턴 소거 복구.
  4. 상한(Thm 1): |C| ≤ 2^{n-max|∪T|}로 Singleton bound·Rieger bound를 일반화, 등식 만족 시 P-MDS 부호.
  5. 구성 정리(Thm 3): m×n GF(2) 행렬 M이 full rank이고 모든 p∈P의 열부분행렬이 full rank면 그 null space가 P-MDS Clin(n,m,c,1).
  6. 저잉여 구성(Thm 7): 열 단위 그리디로 M 생성, 벡터공간 커버링(Lemma 5,6)으로 잉여도 ≤ log2(c-1) 보장, c=2에서 P-MDS 달성.
  7. 저밀도 구성(Thm 8): Clin(n,2,2,1)을 disjoint cycle로 분해, cycle 따라 (0,1)/(1,0) 교대 배치로 parity 1의 개수 n+z(z=홀수 cycle 수)로 최소밀도 달성.
  8. 확장(Thm 9): m-regular multigraph를 Petersen 2-factor 정리로 m/2개 2-factor로 분해, 각 2-factor에 Thm 8 적용 후 direct product로 Clin(n,m,2,1) 구성.
  9. 결과: 저밀도 parity(최선 n개, 최악 약 1.3n개 1) 구성 및 c=2 P-MDS 존재 증명, Conjecture 2(c≤m+1)는 미해결.
  10. 한계: 순수 조합론적 소거부호 구성 이론, HW·시뮬·오류(비트 flip)정정·반복복호 전무, c=3·t>1 미해결.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
pattern erasure P-MDS 부호 구성대응 없음Prime ECC는 소거가 아닌 비트오류 정정용 binary QC-LDPC이며 MDS 부호 아님
저밀도 parity 행렬(2-factor 그래프)대응 없음QC-LDPC는 base+circulant 구조로 이 조합론적 구성과 무관
erasure 복구(선형대수 rank)대응 없음Prime ECC는 min-sum 반복복호(LDPC_Decoder()), erasure 복구기 아님

적용 가치: 낮음 — RAID/디스크 어레이 소거(erasure) MDS 부호의 존재성·저밀도 구성 이론으로, NAND page-level binary LDPC의 비트오류 정정·min-sum 디코더·부호설계에 이식할 요소가 없음.
