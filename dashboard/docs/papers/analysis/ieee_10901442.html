추가확인OSD 계열(Gaussian elimination, TEP 정렬)은 코드길이 증가 시 복잡도 급증 - Prime ECC의 대형 QC-LDPC(N_b=129 col-block)에 적용 시 GE 비용이 실질적인지 확인 필요

총평: BP+OSD 계열 concatenated 디코더로 short LDPC 오류성능/복잡도를 개선하나, 대상이 short block-length·non-binary/5G RC 코드이고 OSD의 Gaussian elimination 기반 구조라 HW/대형 QC-LDPC 이식에는 재검증 부담이 있어 이식성은 중간 수준.

B. 알고리즘 요약

  1. 시스템: AWGN+BPSK 채널에서 rate-compatible(RC) short LDPC 코드 C(n,k), LLR L_i=2y_i/σ², 실험은 non-binary LDPC C(128,64)와 5G RC 코드(k=45, 48≤n≤138).
  2. 문제: short block-length에서 BP는 Tanner graph의 짧은 cycle 때문에 sub-optimal이고, 기존 OSD/BP-OSD는 ML급 성능에 여전히 고복잡도.
  3. 핵심 가정: girth g인 LDPC는 g/2번째 반복 전까지 메시지가 독립이며, 이후 반복 출력 LLR은 신뢰도가 낮아짐(short cycle 영향).
  4. 핵심 기법1: ordered likelihood decoder(OLD) - TEP likelihood R(e)=Σα_j e_j를 최도-정렬된 reliability curve α_B의 구간별 선형근사(r_j=s_d j+I_d, 세그먼트 D개)로 모델링, TEP를 확률 내림차순(=R 오름차순)으로 직접 생성.
  5. 핵심 식: Pr(e)∝exp(-Σα_j e_j)이므로 TEP 생성 순서를 근사식 (9)로 정렬해 OSD처럼 조합 전수탐색 없이 순차 생성.
  6. 핵심 기법2(MB-OLD): BP 반복 l=0,...,g/2-1의 출력 LLR을 L'=Σβ_l L^(l) 가중합(β_l은 density evolution 기반 정규화 정확도)으로 결합해 OLD 입력으로 사용.
  7. 부수 트릭: stopping criterion(SC)으로 D*=D_MRB*+D_LRB*를 추정해 최적 TEP 발견 시 조기 종료(식 16~18), 최대 TEP 수로 복잡도 상한 설정.
  8. 최적화 절차: girth g와 iteration 수 T_max는 사전 분석(density evolution)으로 결정, 최적 반복수 이후 OLD 활성화.
  9. 결과: C(128,64) NB-LDPC에서 MB-OLD가 OSD(order=3)/mBP-OSD/BP-OSD2007 대비 각각 0.35/0.45/0.65dB 개선(BLER=1e-4), 5G RC 코드에서도 NA bound에 근접하며 낮은 복잡도.
  10. 한계: HW 구현/합성 없음(시뮬만), 실험은 short block-length(n≤138) 및 non-binary/5G 코드 중심이라 NAND급 대형 binary QC-LDPC로의 복잡도 확장성 미검증, Gaussian elimination 기반 OSD 구조 특성상 대형 코드에서 비용 증가 우려.
