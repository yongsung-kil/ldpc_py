B. 알고리즘 요약

  1. 시스템: BPSK/AWGN, SPA 복호(max 100 iter), short-to-medium QC-LDPC(길이 378/762bit, rate 0.51~0.52).
  2. 문제: 저지연 통신용 단파장 부호에서 PEG 구성 대비 short-cycle을 더 줄여 성능을 높이려 함.
  3. 핵심기법(girth-6): weight-3 Hamming codeword c1..cl(집합 B3, |B3|=n(n−1)/6)를 열로 세운 H는 Hamming dmin=3 성질로 length-4 cycle이 원천 배제됨(Lemma 3).
  4. 핵심식: 등가류 Sc와 다항식 C(x)=x^e+x^b+x^a, shift C*(x)=x^β C(x) mod (x^n+1)로 CPM 생성.
  5. 구성(Algorithm 1): 각 codeword 등가류 행렬 Ωv를 3개 CPM P1,v,P2,v,P3,v로 분해, Λv=[P1;P2;P3]를 g개 이어붙여 H_HM-QC-LDPC=[Λ1..Λg].
  6. 확장(girth-8): v≥3에서 Λv의 6가지 CPM 순열 중 length-6 cycle 패턴(Fig.1)을 안 만드는 것을 고르고, 복수면 length-8 cycle 최소인 것 선택.
  7. 파라미터화: g=N/n이 rate를 결정(설계 rate=(g−3)/g), non-full-rank라 실제 rate는 더 큼; m 홀수면 최대길이 (2^m−1)(2^m−2)/6.
  8. cycle profile(Table II, 378bit): girth-8 부호는 length-6 cycle 0개, length-8 1638개로 PEG(1749)보다 적음.
  9. 결과: 378bit girth-8이 PEG 대비 0.3dB(BER 10^-8), IEEE802.22(384bit rate0.5) 대비 0.2dB 이득; 평균 SPA iteration도 더 빨리 수렴.
  10. 한계: HW 미설계·시뮬만, 수백 bit 저rate short code에 국한, non-binary 확장은 future work.
