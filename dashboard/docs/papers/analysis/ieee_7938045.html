B. 알고리즘 요약

  1. BEC 채널, rate-1/2 protograph 앙상블(lifting factor Q, 대표 code length n=10000)을 유한 최대반복 imax=10 환경에서 설계 대상으로 삼는다.
  2. 기존 PEXIT 분석은 무한반복 threshold를 예측하도록 정의되어, 반복이 작게 제한된 경우 BER waterfall 위치를 신뢰성 있게 예측하지 못하는 문제를 푼다.
  3. 채널은 BEC(erasure 확률 ε), 성능지표는 각 VN의 a posteriori MI IAPP(j)와 그 평균 Iavg(ε)(식 (5)).
  4. 핵심 관찰: imax회로 제한한 modified PEXIT로 얻은 Iavg(ε) 곡선이 급증하는 지점(1로 올라가는 구간)이 BER waterfall과 일치한다.
  5. Algorithm 2: Iavg의 1차 도함수 peak 중 최소 ε을 iteration-constrained threshold ε*로 정의(식 (7)) — waterfall 위치 근사.
  6. Algorithm 3: 1차 peak 위치가 부정확한 경우를 보완, 2·3차 도함수를 이용해 더 견고한 finite-iteration threshold 정의(식 (8),(9)).
  7. 구현 디테일: modified PEXIT는 초기화 후 Step 3~5를 imax회만 반복해 디코더 동작을 모사, Δε 스텝으로 ε을 스윕한다.
  8. 최적화: degree-16 VN 1개 + degree-3 VN 7개 + CN 4개로 이뤄진 protograph 족(isomorphic 제거 후 114,803개, Protograph A 포함)에서 ε* 최대 protograph 탐색.
  9. 결과: imax=10에서 Algorithm 2/3가 각각 Protograph H/I를 찾았고, 이들 BER은 hand-designed Protograph A와 매우 유사(ε*=0.474/0.415 등). Protograph A가 이미 best-in-class임을 확인.
  10. 한계: BEC 전용 이론·시뮬 분석, BI-AWGN·실채널 미적용, HW 미설계, threshold-waterfall 상관도 protograph별 편차 존재.

| protograph 앙상블 부호설계 | ecc_top.cpp Load_PCM() | Prime ECC는 특정 QC-LDPC H-matrix 고정 — 앙상블 설계 파이프라인 미대응, 이식 부담 큼 |
| finite-iteration threshold(MI 도함수) 분석 | 대응 없음 | 코드베이스에 DE/PEXIT/MI 분석 도구 없음, 오프라인 설계 이론 |
| 조기종료/평균 iteration 절감 관점 | partial_CRC.cpp partial_crc_HW_T4() | 논문은 짧은 반복 최적화 지향이나 CRC 조기종료와 메커니즘 상이, 직접 대응 아님 |
| lifting / copy-and-permute | 대응 없음 | QC circulant lifting과 개념 유사하나 랜덤 permute 앙상블로 QC 구조와 불일치 |
