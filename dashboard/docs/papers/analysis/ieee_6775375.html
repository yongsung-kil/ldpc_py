B. 알고리즘 요약

  1. 시스템: OFDM 다중반송파, IS-LDPC 부호 N=1024/2048, R=1/2 또는 3/4, irregular(dvmax=15), QPSK.
  2. 문제: coding 기반 candidate generation PAPR 저감 시 후보 탐색 복잡도가 2^U로 폭증(특히 codeword가 K개 OFDM 심볼로 전송될 때).
  3. 핵심 개념: invertible subset S — 어떤 유효 codeword에서 subset의 비트를 모두 반전해도 여전히 유효 codeword가 되는 인덱스 집합.
  4. 정리: S_IS가 invertible subset일 필요충분조건은 H_IS 각 행의 Hamming weight가 짝수(모든 check node가 V_IS와 짝수 개 edge로 연결).
  5. 핵심 기법(IS-PEG): PEG 알고리즘을 변형해 V_IS의 후반 edge를 홀수 연결된 check node로 강제 연결(P<Q 조건)하여 subset invertibility를 보장.
  6. 다중 subset 확장: U개 disjoint subset을 독립적으로 IS-PEG 적용, 각각 짝수 연결 유지.
  7. 구현: subset을 uniform interleaved 분할 S_u={u, u+U, ..., N-U+u}, 각 OFDM 심볼에 U/K개 subset 배정 → 심볼별 독립 PAPR 최적화.
  8. 복잡도 결과: 탐색 복잡도 2^U → K·2^(U/K)로 대폭 감소(U=32,K=4 시 [11] 대비 2^22배 절감).
  9. 성능: U≤32일 때 PEG LDPC 대비 BER 열화 미미(펑처링 후 <0.2dB), U=8/16/32에서 PAPR 0.7/2.4/4.1dB 저감(CCDF=10^-4).
  10. 한계: HW 미설계, AWGN/Rayleigh 시뮬만, QC-LDPC 미지원(향후과제), 4-cycle 불가피로 U=64 이상 열화.
