B. 알고리즘 요약

  1. 대상: binary 정칙(left-regular) QC-LDPC, MS(min-sum) 복호, 고정소수점 quantization(채널 Λmax, extrinsic Umax, qe비트), AWGN 대칭채널. 예제 부호 rate 0.5~0.8, length 2640~30480.
  2. 문제: error-floor를 유발하는 elementary absorbing set(AS)의 유해성을 정량 지표로 예측하고, quantization만으로 무해화할 조건을 찾음.
  3. 모델: elementary AS 내부 extrinsic 메시지 x가 x(k+1)=sat(A(x-1)+(d-1)·1+Rλ) 선형+포화 시스템으로 진화(A=라우팅, R=반복 행렬, λ=스케일 채널 LLR).
  4. 핵심: 각 AS에 threshold τ=max min(λ) (equilibrium 중 최소 채널값의 최대) 정의. λ>τ면 AS가 디코더를 트랩하지 못함.
  5. 의미: τ는 AS 유해성과 직결 — τ 클수록 위험, 음수면 무해화 가능.
  6. 확장: limit cycle·비주기 궤적도 equilibrium보다 덜 유해하며, generalized equilibrium으로 τ 계산이 단순화됨(반복 제약 R 제거).
  7. HW 함의: -1≤τ≤d-2, 짝수 VN degree 정칙부호는 τ≥0(무해화 불가), 홀수 degree(d=3,5)는 음수 τ AS 다수 존재.
  8. 무해화: τ<-λmax이 되도록 Umax(즉 λmax=Λmax/(2^{qe-1}-1))를 키우면 해당 AS 자동 비활성화(Theorem 12).
  9. 결과: Margulis(2640,R=1/2), R=4/5 QC-LDPC(30480), array SC-LDPC, d=5 RS기반 부호에서 IS 시뮬로 τ-WER 상관 확인. qe 증가 시 음수 τ AS들이 순차 비활성화, τ=0인 (12,4)·(14,4) AS만 floor 지배.
  10. 한계: HW 미설계, elementary AS·정칙 좌차수·AWGN 대칭채널 가정, 비대칭/메모리 채널은 범위 밖.

적용 가치: 중간 — 우리 고정소수점 min-sum의 extrinsic 동적범위/양자화 설정으로 error-floor 흡수집합을 무해화하는 정량 지침을 주지만, AS 열거·threshold 계산 도구가 별도로 필요하고 HW 미설계라 즉시 이식보다는 부호·양자화 튜닝 참고용.
