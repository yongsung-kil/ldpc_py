B. 알고리즘 요약

  1. 대상: QC-LDPC를 base matrix(mother matrix)를 circulant로 확장(lifting)해 girth를 올리는 구성법의 이론적 한계 분석.
  2. 문제: base matrix에 존재하는 balanced cycle(= inevitable cycle) 때문에 circulant만으로는 girth를 특정 값 이상 올릴 수 없음 - 이 최단 balanced cycle을 모두 찾아야 함.
  3. 정의: matrix M의 nonzero 위치를 point로 보고, path/cycle을 RC(matchable subset) 기반으로 정의. balanced cycle은 모든 point가 짝수번(홀·짝 index 동수) 등장하는 cycle이며 그 최단 길이를 B-girth B(M)로 정의(최소 12).
  4. 핵심 기법 1: Theorem 1 - M이 balanced cycle을 가질 필요충분조건을 3개 simple path의 조합(조건1) 또는 2개 simple cycle+연결 path(조건2)로 제시.
  5. 의미: balanced cycle의 존재를 국소적 simple cycle/path 구조로 환원해 exhaustive search 없이 판정 가능케 함.
  6. 핵심 기법 2: Theorem 2 - "simple path γ와 P1γ, γP2가 non-simple"이라는 더 간단한 등가 조건 제시.
  7. 구조 규명: minimal matrix S(a,b,c)(Figure 1의 밴드형 패턴)를 정의, B∗C-minimal임과 B-girth s(a,b,c)=4c (a+b<c) or 2(a+b+c)를 증명.
  8. 최적화 절차: 없음(구성적 증명). BC/BC∗/BG/BG∗-minimal 4가지 minimal 정의가 모두 동치임을 Theorem 3·4로 증명.
  9. 결과: Corollary 3 - 임의 M의 최단 balanced cycle을 담는 최소 submatrix가 어떤 S(a,b,c)와 equivalent - submatrix를 S(a,b,c)와 비교하는 간단한 탐색법 제공.
  10. 한계: HW·복호·BER 성능 전무, 순수 조합론적 특성화이며 rate/length 등 실제 부호 사양 미제시.
