B. 알고리즘 요약

  1. 대상은 BSC 상의 3-left-regular(column-weight γ=3) girth g=8 LDPC, 예제는 QC-LDPC(n=768, R=0.75, dmin=12).
  2. 문제: 표준 parallel bit-flipping은 nc_u(v)=2와 =3을 동일 취급해 weight-2 오류패턴(8-cycle)에서 진동·미수렴, column-weight-3 코드에서 보증 정정능력이 ⌈g/4⌉-1로 낮음.
  3. 핵심 아이디어: VN이 이진 {0,1} 대신 Av={0s,0w,1w,1s}(strength 1비트 추가) 값을 갖고, unsatisfied CN 수에 따라 flip 전 strength만 먼저 낮춤.
  4. TBFA1: 함수 f1: Av×{0,1,2,3}→Av(Table I)로 병렬 갱신. nc_u(v)=2인 VN을 즉시 뒤집지 않고 완충 → weight-2 패턴 정정.
  5. 보증 정정능력(Prop.1): girth g≤12이고 weight w<g codeword가 없으면 최대 g/2-1 오류 정정 → parallel BF 대비 최소 2배, Gallager A/B 이상.
  6. TBFA2: CN에 previous/newly(satisfied/unsatisfied) 상태 비트를 추가, f2: Av×{0,1,2,3}^3→Av로 CN 신뢰도까지 반영해 TBFA1이 실패하던 weight-4 구성 정정.
  7. 실패 분석 프레임워크: 초기오류 subgraph I를 재귀적으로 확장해 알고리즘이 실패하는 최소 유해 subgraph 집합 Ser를 열거, 보증 정정능력을 유도.
  8. 알고리즘 선택 기준(Prop.3): Ser 내 최소 subgraph의 VN 수를 최대화하는 f가 우수.
  9. 결과: BFD2(55개 알고리즘 concatenation, 최대 1950 iter)가 Gallager A/B·min-sum을 능가, FER 곡선 기울기가 BP보다 커 error-floor 성능 잠재력; α<2.5e-3에서 99.99%가 첫 알고리즘으로 복호되어 평균 iteration은 BFD1 수준.
  10. 한계: HW 미설계·시뮬뿐, BSC(hard)·column-weight-3 girth-8 예제 중심, concatenation 제어/룩업 오버헤드.
