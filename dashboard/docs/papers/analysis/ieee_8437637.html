B. 알고리즘 요약

  1. 시스템: 짧은 RM(r,m) 부호(n=2^m, n=32/128, rate 0.23~0.77), BEC/BI-AWGN/BSC 채널, ML 근접 복호 목표.
  2. 문제: RM은 ML서 우수하나 실용 반복복호로 near-ML 달성 여부 미해결; 전체 MWPC 사용은 복잡(예 RM(3,7)은 weight-16 PC 94,488개).
  3. 모델: 이진선형부호의 dual codeword가 유효 PC 행; RM(r,m)의 dual은 RM(m-r-1,m), MWPC weight 2^{r+1}, 개수 F(r,m)(식(1)).
  4. 핵심기법1: 최소무게 dual codeword만 행으로 담은 과잉(redundant) PC 행렬 Hfull에 반복복호(peeling/BP/LP/BF) 적용.
  5. 핵심식: MWPC는 (r+1)차원 affine subspace의 indicator → Algorithm 1로 지정 r+2비트를 포함하는 MWPC 생성.
  6. 핵심기법2: 수신 LLR γ 정렬로 good(G)/bad(B) 비트 분할, bad 1개+good r+1개로 MWPC 뽑아 수신벡터 맞춤 Hsub(s행) 구성(Algorithm 2, 파라미터 f).
  7. 구현 디테일: BP에서 cycle correlation 과신 완화 위해 bit-node 입력 message에 scaling w<1 곱(min-sum overconfidence 대책과 동일 취지); LP는 ADMM(µ,Tmax).
  8. 최적화: f(신뢰비트 비율)와 행 수 s를 부호별 튜닝(RM(3,7)은 ~3% MWPC로 full 대비 향상).
  9. 결과: RM(2,5)는 BEC/AWGN/BSC 모두 near-ML; RM(3,7)은 Hsub 3%로 full 대비 최대 0.5dB 향상(cycle 감소), n=128서 MRB 대비 ~0.25dB.
  10. 한계: HW 미설계·시뮬만; short block RM 대수부호의 automorphism 유래 대칭성에 의존해 QC-LDPC로 일반화 불가.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
MWPC 과잉 PC 행렬 / 수신맞춤 Hsub 생성대응 없음RM automorphism 유래 대칭 PC, 고정 binary QC-LDPC(ecc_top.cpp Load_PCM())엔 대칭성·중복 PC 개념 없음
BP message scaling (w<1) 과신 완화decoder.cpp CNU_Update_New_Mag() (min-sum)개념 유사하나 이미 보유(min-sum magnitude), 신규성 없음
LLR 신뢰도 정렬 기반 비트 분류channel.cpp Set_LLR_Th() (부분 유사만)복호 전 PC 선별 목적이라 NAND read LLR와 용도 상이
peeling/LP/BF 복호대응 없음Prime ECC는 min-sum QC-LDPC 전용, 해당 복호기 미보유

적용 가치: 낮음 — 짧은 RM 대수부호의 automorphism 유래 MWPC 과잉행렬+수신맞춤 선별 기법으로, 대칭성 없는 NAND binary QC-LDPC ECC에 이식 불가(단 BP message-scaling은 이미 min-sum으로 보유).
