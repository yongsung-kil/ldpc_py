B. 알고리즘 요약

  1. 대상은 SFA(simple and full-length array)-LDPC 코드 CA(q,j): q×q cyclic shift 행렬 P를 블록으로 사용한 parity check 행렬 H_A(q,j)로 정의되는 array-type LDPC.
  2. 목표는 코드의 성능을 근사하는 데 쓰이는 최소 weight codeword 개수 |A0|를 계산하는 것(전체 weight distribution은 계산 난이도가 지수적이라 실용적 대안).
  3. 가정: q는 소수, j<q; 채널/노이즈 모델은 다루지 않는 순수 대수적 코드 구조 분석.
  4. 핵심 개념 "cyclic shift closure" CSC(v) = BLOCK(BIT(v)) 도입, 최소 weight codeword 집합 A0가 이 closure들로 분할됨을 증명.
  5. 핵심 식 |A0| = q^2·|A1|/w_min (식 1) - closure 크기(q^2)와 대표 codeword 집합 A1의 크기로 전체 개수를 환산.
  6. j=3의 경우 컴퓨터 탐색+Yang의 기존 결과를 결합해 닫힌 공식 |A0| = q^2(q-1)(q-2)/6 유도(Lemma 3.5).
  7. j=4, j=5는 대수적 구조(A2 generator 집합, GF(q) 위의 일반형)를 컴퓨터 실험으로 찾아 4q^2(q-1) 이상(j=4), q^2(q-1)/2 이상(j=5) 하한 공식 도출.
  8. 최적화/학습 절차는 없고 컴퓨터 프로그램으로 소규모 q에 대해 A2를 구성한 뒤 패턴을 귀납적으로 일반화하는 방식.
  9. 결과: q=71까지 표(Table I)로 실제 개수 제시, j=3은 정확값, j=4/5는 컴퓨터 탐색 범위 내에서 하한과 실측이 일치함을 확인(추측이지만 미증명).
  10. 한계: 순수 이론(컴퓨터 탐색+대수 유도)만 있고 시뮬레이션/디코더 성능/HW 언급 전혀 없음; j=4,5는 정확한 공식이 아니라 하한.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SFA-LDPC weight distribution 이론 분석대응 없음특정 array-code 클래스(CA(q,j))의 순수 조합론적 성질 규명이며 Prime ECC의 QC-LDPC 설계(Load_PCM())와 코드 구조가 다르고 디코더/HW에 닿는 요소가 없음

적용 가치: 낮음 — 부호설계 개선이나 디코더/HW 기법이 아닌 특정 array-LDPC 클래스의 순수 수학적 codeword 개수 분석이라 이식할 알고리즘/구조가 없음.
