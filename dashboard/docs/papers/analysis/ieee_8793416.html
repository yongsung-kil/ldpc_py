총평: SC-LDPC 윈도우 복호의 serial 스케줄 수렴이점을 EXIT 이론으로 확인한 순수 분석 논문 — serial/shuffled 스케줄 아이디어 자체는 참고 가능하나 SC 구조+이론뿐이라 Prime ECC(고rate binary QC-LDPC block)로의 이식성은 하.

B. 알고리즘 요약

  1. 시스템: protograph 기반 SC-LDPC(convolutional LDPC), AWGN 채널, coupling length L=500, base matrix Bt=[3 3], memory mcc=2.
  2. 문제: SC-LDPC 윈도우 복호의 flooding vs serial 스케줄 성능/수렴을 이론적으로 정량 비교할 도구 부재.
  3. 모델: edge spreading으로 시간 t의 VN 엣지를 t+i(i=0..mcc) CN에 분산, 윈도우 크기 W ≥ mcc+1.
  4. 핵심 기법: protograph-based EXIT(P-EXIT) 차트를 윈도우 복호에 적용, VN→CN 외재정보 I_Ev와 CN→VN I_Ec의 MI를 엣지별 추적.
  5. 식 의미: σ_ch^2 = 8R·Eb/N0로 채널 신뢰도 반영, MI가 1로 수렴하는 최소 Eb/N0를 복호 threshold (Eb/N0)*로 정의.
  6. 확장: serial(shuffled) 스케줄은 각 VN 업데이트 전 연결 CN의 최신 LLR를 먼저 요청(Table 2), flooding은 전 노드 동시 갱신.
  7. 구현 디테일: J(·)/J^-1(·)는 Gaussian approximation 다항식 근사, cumulative MI I_CMI와 평균 I_CMI_avg로 threshold 판정.
  8. 학습/최적화: 없음 (해석적 EXIT 반복 계산).
  9. 결과: W=8에서 threshold serial 0.674dB vs flooding 0.683dB; Eb/N0=0.7dB에서 iteration flooding 33→serial 19(W=8), 16→9(W=10), 약 45% 감소, 성능 손실 없음.
  10. 한계: 무한 codeword 가정 이론 분석뿐, HW 미설계, SC-LDPC 특화, NAND/실측 없음.

C. Prime ECC 관련 모듈 핀포인트

P-EXIT 이론 분석 도구대응 없음Prime ECC는 bit-exact 시뮬레이터, EXIT 이론 분석 모듈 없음

적용 가치: 낮음 — serial/shuffled 스케줄이 iteration을 줄인다는 방향성은 참고되나, 대상이 SC-LDPC(컨볼루션)+무한길이 EXIT 이론이라 Prime ECC의 고rate binary QC-LDPC block 디코더로 직접 이식할 구체 요소가 없다.
