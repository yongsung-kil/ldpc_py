B. 알고리즘 요약

  1. 코드: QC-MDPC(quasi-cyclic moderate-density parity-check), H=[H_0...H_{n0-1}] 각 r×r circulant, 예 (n,r,wc)=(9602,4801,45), n0=2 → rate 0.5, McEliece PKC 복호에 사용.
  2. 문제: QC-MDPC BF 복호는 non-zero 실패확률(DFR)을 가지며, PQC 보안상 DFR을 낮추는 것이 중요.
  3. 모델: 암호문 c=mG+e, 오류 w(e)≤t, 신드롬 s=Hc^⊺=He^⊺, 각 비트 NUPC f_j(s)=w(h_j∧s).
  4. 핵심기법: NUPC가 최대인 후보집합 I에서 각 후보 i를 tentative flip(s_i=h_i⊕s)한 뒤 상위 τ개 NUPC 합 β_i가 최대인 위치 ĩ를 선택(look-ahead tie-break).
  5. 의미: 실제 오류위치를 flip하면 미보정 오류위치 NUPC가 증가, 오류없는 위치를 flip하면 감소 → β_i가 올바른 flip 판별 지표.
  6. 확장: 복호 실패 시 재실행(Algorithm 3) - 관측된 최대 NUPC α̃의 상위 λ개 중 ρ개(ρ≪t)를 무작위 flip한 변형 암호문 c'=c+e'로 재복호(이중 루프 Iout,Iin).
  7. 트릭: τ는 τ0에서 iteration마다 1씩 감소, τ0≈t가 mis-selection 확률 최소; (λ,ρ)=(35,4)가 BLER 최소.
  8. 최적화 절차: Monte Carlo 시뮬로 τ0, (λ,ρ) 경험적 결정 (이론 최적화는 미래 과제).
  9. 결과: (n,r,wc)=(9602,4801,45)에서 LABF(1,1)이 weighted BF 수준, Iin∈{5,25}면 BF/SPA/MXT/WBF 중 최저 BLER; 다만 복잡도는 BF의 (c·E[|I|]+1)·Iout·Iin 배.
  10. 한계: HW 미설계, hard-decision BF, MDPC(고밀도)·암호 문맥, reaction/timing attack에 취약, 복잡도·latency 증가.

NUPC(신드롬 기반) 계산decoder.cpp C2V_Cal()신드롬/parity-check 개념은 유사하나 BF 특유의 NUPC tie-break은 min-sum CN 연산과 구조 상이

QC circulant H-matrix 로드ecc_top.cpp Load_PCM()QC 구조는 공통이나 MDPC(row weight 큼)라 NAND용 저밀도 QC-LDPC와 부호밀도 상이

적용 가치: 낮음 - post-quantum 암호(McEliece)용 QC-MDPC의 hard-decision bit-flipping 개량이라, NAND용 soft binary QC-LDPC min-sum 디코더/부호설계에 떼어 쓸 실질 요소가 없다(BF↔min-sum 알고리즘 계열이 다르고 MDPC는 고밀도).
