B. 알고리즘 요약

  1. 대상 부호는 protograph 기반 (3,6,720) time-variant QC SC-LDPC, lifting Z=112, periodicity 3, 약 rate-1/2 (Section II 예제).
  2. 문제: 슬라이딩윈도 디코더는 시작 종단만 활용해 full-block 대비 성능 손실이 있고, 고정 iteration(Iw) 낭비로 평균 iteration이 높음(윈도 15×10회=150 iter/VN).
  3. 채널/모델: BPSK over AWGN, 윈도 내부 디코더는 scaled Min-Sum + flooding 스케줄.
  4. 조기종료: 디코딩 윈도 앞쪽 Ws개 protograph 섹션의 CN syndrome만 XOR로 계산해 만족 시 윈도 전진(partial-syndrome rule). Ws>=3 필요, Ws=5가 full-check 성능 근접.
  5. 의미: LLR 기반 soft-bit indicator(LUT+Nt 실수 덧셈) 대신 XOR만으로 조기종료 → 연산 절감.
  6. 핵심기법(Zigzag): divergence(연속 미수렴 섹션) 끝에서 윈도 방향을 역전(backward)해 올바른 상태 정보를 divergence로 역전파. Forward→Backward→Forward 1회를 Z-round로 정의.
  7. 제어변수: 최대 Z-round ZR, Z-window 크기 ZW, 최대 iteration Iw. ZR>1은 수확체감.
  8. 부수: 유한 ZW보다 큰 divergence 관측 시 early codeword-failure detection → ARQ/HARQ 재전송으로 저SNR 평균 iteration·latency 절감.
  9. 결과: ZR=1, Iw=5가 슬라이딩윈도 Iw=90보다 0.25dB 우수하며 평균 iteration/VN도 더 적음. Full-block(55 iter)→제안(30 iter) @FER=1e-2.
  10. 코드계열: shortening 기반 SC-LDPC 계열이 puncturing 기반보다 고rate에서 최대 0.9dB, iteration·복잡도(0.3배) 우수.
  11. 한계: HW 미설계, 시뮬만, 무선 dynamic 채널 가정, SC-LDPC 전용 (block LDPC 미적용).
