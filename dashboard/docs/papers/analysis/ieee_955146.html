B. 알고리즘 요약

  1. 문제: 해석적 LDPC 부호는 전체의 극소 부분집합이라 대부분 랜덤 구성에 의존, 특히 짧은 길이·고rate에서 4-cycle 제거가 어려움.
  2. 핵심아이디어: 조합설계(combinatorial design)의 incidence matrix I(또는 전치 I^T)를 parity-check matrix H로 사용, λ=1이면 4-cycle 부재 보장.
  3. 설계용어: (v,b,ρ,γ,λ)-regular design, H=I^T이면 column weight γ, row weight ρ인 (γ,ρ)-regular 부호, block length n=b.
  4. 핵심기법: Kirkman triple system(KTS = resolvable Steiner triple system) 사용 — STS의 block들을 disjoint group으로 재배열해 그 일부 group만 열로 취해 H 구성.
  5. 핵심식(girth 하한): n ≥ 1 + γ(ρ-1) + ... — 4/6-cycle 회피에 필요한 최소 block length를 degree γ,ρ로 규정, 짧은 cycle 체계적 제거.
  6. 이점: KTS는 H 밀도가 n 증가 시 감소해 girth가 n과 함께 증가 가능(STS/EG/PG는 girth 상한 6에 고정), row weight ρ∈{1..(v-1)/2} 자유.
  7. column weight 3 고정, v≡3 (mod 6) 조건에서 임의 rate·길이 KTS 부호 생성(Fig.1 rate/blocklength 다양성).
  8. 최소거리: STS-LDPC는 MacKay-Davey 결과로 d≤10, anti-Pasch STS로 d≥6 가능, KTS 부호는 STS 상한 제약 없음.
  9. 결과: rate-1/2, rate-2/3(3,9)-regular, 고rate n=247(rate 0.84) 부호를 BP(sum-product) 디코딩 시뮬(max iter 50~500); 랜덤 구성이 4-cycle 못 없앤 n=247 대비 우수.
  10. 한계: 순수 부호 구성법(HW 미설계, QC/circulant 구조 없음), 최소거리 낮은 STS 계열, KTS 최소거리 미확정.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
조합설계 기반 H-matrix 구성ecc_top.cpp Load_PCM()약함 — H-matrix 로드는 있으나 Prime ECC는 QC(circulant) 고정, KTS incidence matrix는 QC 아님
4-cycle/girth 회피 부호 설계대응 없음Prime ECC는 특정 QC-LDPC 고정, girth 설계 재검증 부담 큼
sum-product(BP) 디코딩decoder.cpp LDPC_Decoder()약함 — Prime ECC는 min-sum 사용, full-tanh SP는 미대응

적용 가치: 낮음 — girth 보장 조합설계 부호는 학술적 가치는 있으나 QC-LDPC(circulant lifting) 구조가 아니어서 Prime ECC의 고정 QC H-matrix로 직접 이식 불가, min-sum HW와도 정합 안 됨.
