총평: LP 복호의 최소 pseudo-codeword를 대수적으로 특성화한 순수 수학 논문으로, NAND binary LDPC의 부호설계·min-sum 디코더·HW에 직접 이식할 실체가 없다.

B. 알고리즘 요약

  1. 대상: parity-check matrix H로 기술되는 binary linear code의 LP(linear-programming) 복호와 그 성능을 결정하는 pseudo-codeword 집합.
  2. 문제: LP 복호기가 all-zero codeword 결정영역을 특성화하는 것은 최소(minimal) pseudo-codeword이므로, 이들을 대수적으로 규명해야 함.
  3. 모델: fundamental cone K(H) (부등식 ωi≥0, ωi ≤ Σ_{i'∈Ij\i} ωi')의 edge에 놓인 벡터를 minimal pseudo-codeword로 정의.
  4. 핵심기법: H의 Z-nullspace 벡터에 절댓값 사상(Lemma 1)을 적용한 nullspace-type pseudo-codeword를 정의하고, det-vector/absdet-vector/perm-vector 개념 도입.
  5. 핵심 결과: 최소 pseudo-codeword의 support 크기 상계 |supp(ω)| ≤ m+1 (nullspace-type은 ≤ rankR(H)+1) 증명.
  6. 확장: nullspace-type 최소 pseudo-codeword는 오직 absdet-pseudo-codeword(또는 부분행렬의 그것)로만 나타남을 완전 특성화(Theorem 7).
  7. 특수 케이스: row degree ≤ 3인 H에서는 absdet-pseudo-codeword가 항상 최소임을 증명(Theorem 8).
  8. Non-nullspace-type: 두 개의 벡터로 기술 가능하다는 예시·추측 제시(미해결).
  9. 결과: Tanner graph G와 Forney-style factor graph G' 간 사상에서 perm-pseudo-codeword는 보존되나 absdet는 새 최소 pseudo-codeword를 생성할 수 있음(Theorem 11).
  10. 한계: 순수 대수 이론뿐, LP 복호 대상이며 유한길이 성능·HW·NAND 채널 관련 실험·설계 전무.
