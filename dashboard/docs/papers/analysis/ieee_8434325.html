B. 알고리즘 요약

  1. 문제: 유한길이 LDPC의 error floor는 Tanner 그래프의 trapping set(TS) 때문이며, 기존 exhaustive 탐색은 elementary TS(ETS)/짧은 블록에 국한 — non-elementary TS(NETS)의 효율적 exhaustive 탐색이 미해결.
  2. 핵심 관점: NETS를 ETS에서 시작해 변수노드를 하나씩 추가하는 embedded 그래프 계층으로 특성화; 확장은 dot(depth-one tree)·path·lollipop 중 b 증가가 느린 dot으로 한정.
  3. 핵심 정의: (a,b) TS는 크기 a, 홀수차 체크노드 b개; degree-1/2 체크만 가지면 ETS, leafless ETS(LETS)가 variable-regular error floor 주범.
  4. 핵심 결과 1: dot_m 확장(변수노드를 만족·불만족 체크 p+q개에 연결)으로 NETS 클래스 이동 (a+1, b+dv-2q)(Lemma 3), 이를 재귀 적용해 degree-3 체크 f개까지 NETS(N3~N3,3,3,3, N4, N4,3) 특성화(Prop.1~5, Cor.2~6).
  5. 핵심 식: variable-regular 그래프의 TS 크기 하한(Thm.1) — a ≥ k + T·Σ(dv-1)^i ...로 k(체크차수)·b·g·dv에 따른 최소 크기 규정.
  6. 탐색 범위: exhaustive 보장 최대 크기 amax를 Table II로 규정(예: dv=3,g=8이면 amax=11), 그 이상은 비-exhaustive(bmax=bmax+t) 탐색으로 확장.
  7. 응용: stopping set(SS)을 TS의 부분집합(체크차수≥2)으로 보고 ESS⊂LETS, NESS⊂NETS로 분해 → stopping distance smin 하한(L_SS1<L_SS2<L_SS3)·상한 도출(Algorithm 2,3).
  8. 복잡도: 고정 degree 분포·girth·탐색범위에서 NETS/SS 탐색 worst-case가 블록길이 n에 선형, (입력 simple cycle 주어지면) SS 평균복잡도는 n에 상수.
  9. 결과: regular 20편·irregular 8편(n 최대 16383, rate 최대 0.88)에서 smin 정확값 또는 상·하한을 수 초~수 분에 산출 — 기존 [9]가 수백 시간 걸리던 것을 분 단위로. harmful TS 클래스에 NETS 없음을 실증.
  10. 한계: MATLAB 오프라인 분석 도구(이론), 디코더/부호 구성/HW를 개선하지 않음; soft/hard decision 무관, 실측·throughput 없음.
