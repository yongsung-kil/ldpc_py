B. 알고리즘 요약 (10줄 내외)

  1. 시스템: 이진 primitive/extended BCH 부호 C[n,k](예 [256,239], [128,64~120]), BPSK-AWGN 채널, 6G/광통신 short-block 대상.
  2. 문제: BCH는 최소거리가 커 near-ML 성능 잠재력이 크나, 대수 HDD(BM)는 연판정 손실이 크고 기존 SDD(OSD/GRAND/GCD)는 복잡도·탐색수가 과다.
  3. 핵심 기법 1단: LLR λ로 flipping pattern tree(FPT) 또는 hardware-friendly ORB로 soft weight Γ(e)=Σeᵢ|λᵢ| 오름차순 TEP를 생성.
  4. 핵심 기법 2단: 각 TEP를 hard-decision z와 XOR한 후보에 대수 HDD(Berlekamp-Massey)를 수행해 codeword를 찾고 ML 후보를 출력.
  5. 핵심 아이디어: 2단에 bounded-distance BM을 붙이면 송신 codeword 순위 Ns가 단일단 FPT보다 앞당겨져 작은 list(ℓmax 수십~수백)로 near-ML 도달(Prop.1/2).
  6. 필터링: 만족 parity-check 식 수 n−k−wt(Hr^T) ≥ T인 후보만 BM 호출 → BM 호출 약 50% 감소, 성능 손실 미미(Chase-BM 대비 우수).
  7. 분석 도구: saddlepoint approximation으로 송신 codeword 순위 분포와 ML gap 상한 Pr{LN ≥ ℓmax}을 계산, ℓmax·T 파라미터 선정 기준 제시.
  8. 병렬성: 작은 ℓmax 덕에 TEP 단위 완전 병렬 BM 가능 → 저지연·고throughput(400ZR/800G-LR 지향); early-stopping은 병렬에선 불필요.
  9. 결과: [256,239]에서 ℓmax=512로 ML lower bound 접근, ORB-BM ℓmax=32가 ORBGRAND ℓmax=10^6을 능가; [256,191]에서 OSD-1 대비 FER=10^-6에서 0.6dB 이득.
  10. 한계: HW 미설계(future work), 복잡도는 ops 단위(gate count 없음), 대수부호 전용이라 LDPC/NAND와 무관.
