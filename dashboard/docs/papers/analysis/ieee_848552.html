B. 알고리즘 요약

  1. 대상은 OSMLD(one-step majority logic decodable) 코드 중 DSC(difference-set cyclic) 코드 3종: (73,45,10), (273,191,18), (1057,813,34), AWGN+BPSK 채널.
  2. 문제: OSMLD 코드는 각 비트당 orthogonal check-sum 수 J가 LDPC보다 많고(J≈√n) check-sum Hamming weight도 커서, 종래 iterative APP 복호는 iteration 간 상관으로 suboptimal.
  3. 핵심 기법: BP 복호를 확률이 아닌 likelihood ratio(LLR) 형태로 재정식화 - check-sum 가중치가 큰 OSMLD 코드에서 수치안정성 확보가 목적.
  4. 갱신은 두 규칙: parity check vector별 extrinsic 정보 L(z)를 계산하고(식 (2)), coordinate l에 orthogonal한 부분집합 Bl로부터 개별 a priori 값 qij를 자기 자신과 독립되게 산출(식 (3),(4)).
  5. 개별 a priori 값이 자기 비트와 독립이므로 APP 대비 통계적 종속에 의한 error propagation 감소가 핵심 의미.
  6. 종료조건: z·s^T = 0(syndrome 만족) 또는 최대 iteration(=50) 도달 시 hard decision 출력.
  7. HW 친화 트릭 없음 - trellis 기반 구현 불가로 APP보다 iteration당 연산량과 총 iteration이 모두 큼(부동소수 곱/합 카운트로만 복잡도 추정).
  8. 학습/최적화 절차 없음(순수 알고리즘).
  9. 결과: (273,191)에서 APP 대비 BP가 BER 기준 0.25dB, WER 0.3dB 이득; (1057,813)에서 BER 0.4dB·WER 0.5dB 이득. DSC가 동일 길이 LDPC 대비 273에서 최대 1dB, 1057에서 0.4dB 우수. LLR 스케일링 시 추가 0.1~0.2dB.
  10. 한계: BP 수렴에 최대 50 iteration 필요(APP는 8~15), HW 미설계, 코드 길이 증가 시 대수적 구조 코드가 나빠져 이득 감소.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
LLR 기반 BP 복호 이터레이션decoder.cpp LDPC_Decoder(), C2V_Cal()Prime ECC는 min-sum 근사 채택 - full-BP/LLR 갱신은 우리 min-sum과 상이(중복 아님, 이식 이점 낮음)
extrinsic 정보 계산decoder.cpp CNU_Update_New_Mag()OSMLD의 대가중 check-sum 연산은 Prime ECC의 저degree QC-LDPC와 구조 불일치
DSC/OSMLD 부호 구조 로드ecc_top.cpp Load_PCM()finite-geometry DSC 코드는 QC-LDPC(base+shift) 구조와 불일치 - 대응 사실상 없음

적용 가치: 낮음 - non-QC finite-geometry 코드에 full-BP를 적용한 20여 년 전 이론/시뮬 논문으로, Prime ECC의 고rate binary QC-LDPC + min-sum HW 파이프라인과 부호구조·복호알고리즘 모두 정합되지 않음.
