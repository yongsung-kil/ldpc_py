한계,주의QC-MDPC는 McEliece 공개키암호용 부호로 NAND LDPC ECC와 부호목적·decoder(bit-flipping 계열)가 상이, hard-decision 기반이며 latency는 반복 재디코딩으로 오히려 증가
추가확인BCLD의 test pattern 선택 로직이 LDPC min-sum decoder의 error-floor 대책(예: post-processing)으로 일반화 가능한지 확인 필요

총평: 포스트양자암호용 QC-MDPC bit-flipping 디코더의 BLER 개선 기법으로, NAND binary LDPC ECC와는 부호 종류·디코딩 패러다임(hard bit-flipping vs soft min-sum)이 달라 직접 이식성은 낮음.

B. 알고리즘 요약

  1. QC-MDPC McEliece PKC는 순환행렬 기반 parity-check matrix H로 암호화하며, 복호는 QC-MDPC 디코더(bit-flipping 계열)로 수행되고 실패확률(BLER)이 공격 취약점이 된다.
  2. 기존 MLABF-1(bit-flipping 변형)은 NUPC(α_j = 미충족 parity check 수)와 회귀선 기울기 기반 보조지표 β로 매 스텝 1비트씩 플립하는 반복 디코더.
  3. 본 논문은 Chase decoding 개념을 차용해 디코딩 전에 test pattern T(Hamming weight q)를 암호문에 미리 더해 여러 후보를 만드는 BCLD(Bi-evaluated Chase-like Decoding)를 제안.
  4. T의 0이 아닌 위치는 NUPC 상위 d개 값 그룹에서 β가 큰 후보 집합 I에서 무작위 q개 선택 - Algorithm 1 Calcβ로 가상 플립 후 syndrome 재계산.
  5. c' = c + T를 임의의 QC-MDPC 디코더 dec(·)(여기선 MLABF-1)로 복호, 실패 시 새 test pattern으로 재시도(최대 l회) - 핵심 흐름은 Algorithm 3.
  6. 변형 BCLD2는 원본 암호문 복호 실패 시에만 BCLD를 수행(가중치 w(c') 증가 방지 트릭).
  7. 부수 트릭: β 계산 시 τ(candidate 수)를 iteration마다 감소시켜 계산량 제한.
  8. 학습/최적화 절차 없음 - 파라미터(τ0, δ, σ, l, d, q)는 사전 실험값 고정.
  9. 결과: (n,r,w)=(9602,4801,45) QC-MDPC에서 BCLD+MLABF-1, BCLD2+MLABF-1이 MLABF-1 대비 BLER 대폭 감소(오차 수 t 작을수록 개선폭 확대), BCLD가 대체로 최저 BLER.
  10. 한계: 순수 시뮬레이션(BLER 곡선)뿐, HW 미설계, 최대 l회 반복 재디코딩으로 latency 증가, ADMM 등 최신 QC-MDPC 디코더와 비교 없음.
