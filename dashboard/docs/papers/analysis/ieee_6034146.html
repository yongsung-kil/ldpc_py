총평: LDPC 부호의 저무게 weight distribution을 확률적 codeword 탐색(modified Stern)+MLE로 실패확률과 함께 추정하는 오프라인 분석 도구 — 복호·HW 무관, Prime ECC 부호 검증 보조로만 간접 가치.

B. 알고리즘 요약

  1. 대상은 일반 binary (n,k) LDPC 부호의 weight distribution {A_w}(무게 w codeword 개수), 특히 ML 복호 성능 평가에 중요한 저무게(low-weight) 부분.
  2. 문제: 기존 error-impulse 계열(NNCS[6], modified EI[9])은 저무게 codeword를 "발견"만 할 뿐 특정 무게 codeword의 개수 A_w를 결정하는 스킴이 없음.
  3. 기반 도구 — modified Stern's algorithm[11]: Gaussian elimination으로 H'=[E_{n-k-δ} Z; X Y] 형태를 만들고, 정보집합 I_X,I_Y에서 각 p개, L에서 0, R_Z에서 ≤s개로 무게를 제약해 저무게 codeword c' 생성 (hash table로 Λ_{I_X|L}=Λ_{I_Y|L}+Λ_{R_Z|L} 매칭).
  4. 발견확률 모델: 무게 w codeword 1개를 파라미터 (p,l,s,δ)로 찾을 확률 π_{w,p,l,s,δ}(식 (8)), δ 빈도 평균 π̄_{w,p,l,s}(식 (9)).
  5. 핵심 정리 1: C에 무게 w codeword가 A_w개일 때 r 반복 중 B_w번 발견될 확률은 이항분포 Pr(B_w|A_w)=C(R,B_w)(A_w Π)^{B_w}(1-A_w Π)^{R-B_w}, Π=π̄/N̄ (식 (12)~(15)).
  6. 추정: 관측 B_w에 대해 Pr(B_w|A_w)를 최대화하는 Â_w를 무게분포로 선택(최대가능도, Fig.1).
  7. 실패확률: 정리 2/Corollary 1 — Bayes로 Pr(Â_w|B_w) 계산, ε_w=1-Pr(Â_w|B_w); distinct codeword 수 B_w 이하 확률은 0으로 두어 개선.
  8. 범위 추정: A_w를 [Â_w⁻,Â_w⁺] 구간으로 두었을 때의 실패확률 식 (24),(25).
  9. 결과(수치): MacKay (504,252)/(1008,504), Ramanujan-Margulis (4896,2474) 부호에서 저무게 무게분포를 매우 작은 실패확률(C1의 최소무게 <10⁻¹⁰⁰ 수준)로 결정; 무게 커지면 실패확률 상승.
  10. 한계: 순수 오프라인 부호 분석/최소거리·무게분포 추정 알고리즘, 복호기·HW·NAND 실측 없음, BSC/soft-read 등 채널 무관.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| weight distribution / 최소거리 추정 도구 | 대응 없음 | Prime ECC는 복호 시뮬레이터, 무게분포·최소거리 산출 기능 없음 |
| modified Stern 저무게 codeword 탐색 | 대응 없음 | 부호 오프라인 분석용, 복호 이터레이션(min-sum)과 무관 |
| H-matrix 기반 부호 성질 평가 | ecc_top.cpp Load_PCM() (간접) | 우리 QC-LDPC H-matrix의 최소거리/error-floor 사전점검 보조로만 개념적 연결 |

적용 가치: 낮음 — LDPC 부호의 저무게 weight distribution을 실패확률과 함께 추정하는 오프라인 분석 도구로, 복호·HW 요소가 없어 이식 대상 아님. 다만 Prime ECC QC-LDPC H-matrix의 최소거리/error-floor 사전 검증에 외부 보조 툴로 참고할 여지는 있음.
