B. 알고리즘 요약

  1. 대상은 CPM(circulant permutation matrix)/zero로 구성된 M×N base matrix B, lifting Z의 QC-LDPC(예: 5G LDPC, Z=112/384); row-layered min-sum 복호(Alg.1).
  2. 문제: layered 복호는 partial parallelism으로 각 레이어에 여러 행을 병렬처리하는데, PCM을 어떻게 분할하느냐가 HW 복잡도·throughput을 크게 좌우함.
  3. 첫 레이어 F에 대해 φ^{(l-1)S}_Z(F)가 각 레이어 PCM이 되도록 block cyclic shift 성질을 유지하며 α(H)를 분할.
  4. 핵심 최적화 P1: min ω(F) (레이어별 최대 열가중치), 제약은 φ shift들이 α(H)의 disjoint 분할을 이루는 것. S=1은 기존 [11] 상황에 해당.
  5. ω(F) 최소화가 곧 레이어 내 계산 로직 지연·구현 복잡도 감소로 직결 (Alg.1의 line 10-12 연산).
  6. 이론: block S-cyclic shift equivalence class(S-class) 정의, Lemma 1-4로 LS|Z일 때 해가 존재함을 보이고 Theorem 1로 최적해 구조 C_S 특성화.
  7. P1을 열가중치=1 단순화(P2)하면 MS-partite 그래프에서 MS-clique 찾기 문제와 등가(Theorem 2)임을 증명 (다항시간해 없음).
  8. 두 알고리즘: enumerative(Alg.2, O(MNZ²L^{MS-1}))와 greedy(Alg.3, O(M²SNZ²)); Theorem 3으로 열 일부만 계산해 ω(·)를 Z/LS배 가속.
  9. 결과: Theorem 4로 하한 ω_LB=⌈ω(H)/L⌉ 유도(조기종료용); 5G LDPC 5개 PCM에서 두 알고리즘 모두 대체로 ω_LB 달성 또는 +1, Ŝ>1이 최적인 신규 사례(PCM1 L=12) 발견.
  10. 한계: HW 미설계(RTL/gatecount/throughput 실측 없음), 복호 정정성능(BER/iteration)은 불변, 순수 PCM 분할 최적화 기법.

적용 가치: 중간 — 부호구조-무관한 layered PCM 분할 최적화로 병렬 layered HW 구현의 열가중치·라우팅 재사용에 참고 가치는 있으나, Prime ECC는 dual-update 스케줄+고정 H-matrix(z=32)라 정정성능 이득 없이 아키텍처 정합·재검증 부담이 있어 이식성 중.
