B. 알고리즘 요약

  1. 대상은 QC-LDPC(base matrix + circulant shift, z 확장)용 layered min-sum 유한워드길이 디코더로, C2V=7bit / APP=8bit / LLR=6bit 양자화.
  2. 문제: min-sum에서 first/second minima 탐색이 최대 병목이라 second-min만 근사(single-min)하면 복잡도는 줄지만 성능 손실이 큼.
  3. 기존 SAMS[11]는 워드길이 기반 오프셋 γ=((2^(q-1)-1)-m1)·σ/2로 em2=m1+γ를 추정하나 실제 m2와의 오차 d=em2-m2가 저중 SNR에서 성능을 악화.
  4. 핵심 관찰: second-min 추정오차 d는 미충족 parity-check 방정식 수 µ가 커질수록(=수렴 덜 됨) 커진다(Fig.3, Monte-Carlo).
  5. layered 스케줄에서 layer별 partial PCM Hi로 갱신된 codeword의 미충족 방정식 수 µ를 즉석 카운트해 수렴도 지표로 사용.
  6. 보정식 γ=((2^(q-1)-1)-m1)·σ/2 + β, β는 µ의 구간별 선형함수(코드별 Eq.13a/b, 14a/b로 하드코딩).
  7. 상·하한 적용: exMin-n[13] 그룹법으로 얻은 pseudo-second-min pm2=max{mG1,mG2}를 상한 mu로, 하한 ml=m1로 clamp하여 em2 안정화.
  8. 알고리즘(Alg.1): 그룹분할로 m1·pm2 산출 → µ로 β 결정 → γ 계산 → m1==pm2 또는 clamp 조건에 따라 em2 확정.
  9. 결과: SAMS[11] 대비 FER=10^-3에서 0.2~1dB 이득, NMS 대비 약 0.05dB 손실·평균 iteration 약 3.4% 증가에 그침.
  10. 한계: HW 미구현, AWGN/QPSK 시뮬만, β가 특정 무선 표준 부호(802.11ad/ax) 종속.
