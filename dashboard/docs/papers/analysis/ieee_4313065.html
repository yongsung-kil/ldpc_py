B. 알고리즘 요약

  1. 대상은 이진 대칭채널(BSC) 및 BI-AWGN 상에서 regular left-degree(차수 c) expander code(=특수 LDPC) 계열, rate r ≤ 1-m/n.
  2. 풀려는 문제: 일반 선형부호의 exact ML 디코딩은 NP-hard(Berlekamp-McEliece-van Tilborg)로 알려져 있으나, 저자는 채널의 무작위성을 고려한 average-case 복잡도 관점에서 다항시간 ML 디코딩이 가능한 부호족이 존재함을 증명.
  3. 핵심 가정: adversarial이 아닌 확률적 채널모델(BSC bit-flip 확률 p, 또는 BI-AWGN SNR)에서 Tanner graph G가 (αn, 3c/4)-expander라는 확장성(expansion) 조건 사용.
  4. 핵심 기법 1단: preprocessing(최소거리 사전계산) 허용 시, 단순 sequential bit-flipping(Sipser-Spielman)으로 얻은 해가 d_H(x', r) ≤ w_min/2이면 ML 인증(certificate) — 실패확률 Pe(n) ≤ 2^{-D(α/2‖p)n}(Kullback-Leibler 발산 D(x‖y))로 다항시간 ML 알고리즘 성립(Theorem 1, 2).
  5. 핵심 식의 의미: Pe(n)·2^{nR} → 0이면 실패 시 exhaustive search를 수행해도 기대복잡도가 다항시간에 머문다는 것이 다항시간 ML의 핵심 논리(식 2).
  6. 핵심 기법 2단(preprocessing 없이): LP decoder(Feldman)의 O(n^9) 복잡도를 O(n^2)로 줄인 새 ML certificate 알고리즘 제안 — bit-flipping 후 불일치 변수집합 U에 대해 source-sink max-flow(Ford-Fulkerson)를 구성해 flow값이 특정 용량합과 같으면 ML로 인증.
  7. 부수 트릭: max-flow 용량 파라미터 A = c/2+1부터 c까지 증가시키며 최대 c회 반복 시도(HW 친화적 근사가 아니라 알고리즘적 반복).
  8. 최적화 절차 없음(학습/DE/GA 아님) — 대신 rate region R_ML(p)을 유도해, p→0일 때 이 영역이 Shannon capacity에 수렴함을 증명(Lemma 8, 9).
  9. 결과(정성적): p가 충분히 작을 때(고 SNR) ML/BP간 error exponent 격차가 임의로 커짐(Lemma 5)을 보여, 고SNR에서 message-passing의 error-floor 현상을 제거할 잠재력을 시사; 수치 실험/시뮬레이션 없음.
  10. 한계: 저자 스스로 "이 알고리즘들은 그 자체로는 실용적이지 않다"고 명시(existence/복잡도 증명 목적); 동일 부호족이라도 expander 조건을 만족하지 못하는 일반 regular-left-degree LDPC는 여전히 NP-hard임을 별도로 증명(Section IV, 대조).
