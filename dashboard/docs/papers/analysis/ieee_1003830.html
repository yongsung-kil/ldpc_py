B. 알고리즘 요약

  1. 시스템: 자기기록용 부분응답(PR) 채널(dicode, EPR4)에 outer regular LDPC(column weight 3) 부호를 결합, AWGN 가정.
  2. 문제: 기존 LDPC-PR 시스템은 채널검출에 직렬 BCJR을 써서 지연이 커 LDPC의 저지연 장점을 훼손함.
  3. 모델: PR 채널을 상태천이 기계로 표현, 필요시 modulo-2 precoder f(D)를 채널과 결합.
  4. 기법1(bit-based): GT 그래프의 parity-check 노드를 "triangle" 함수노드로 대체, bit 확률 메시지를 sum-product 규칙으로 병렬 전달.
  5. dicode(2상태)는 그래프가 cycle-free라 16 iteration만으로 BCJR과 사실상 동일 성능.
  6. 기법2(state-based): 3상태 이상 채널(EPR4)에는 bit 대신 상태확률 벡터를 전달하는 window-APP 알고리즘 사용.
  7. 트릭: 고정 iteration W에서는 창(window) 밖 정보를 못 봐 SNR→∞에서 BER이 0이 아닌 상수로 수렴; matched precoder로 ambiguous 출력 제거해 이 하한 소거.
  8. 결합 스케줄: 채널검출기 d iter → GT 복호기 c iter를 1 turbo iteration으로 묶어 t회 반복, 총합 고정.
  9. 결과: 총 iteration 고정 시 c,d를 작게 t를 크게 할 때 최저 BER(dicode 총24). BCJR-GT 대비 EPR4에서 0.6dB 열세지만 지연 대폭 감소.
  10. 한계: 시뮬레이션만, HW 미설계, 자기기록 PR 채널 특화(NAND 무관).

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| GT(sum-product) LDPC 복호 루프 | decoder.cpp LDPC_Decoder(), C2V_Cal() | 논문은 표준 GT를 그대로 사용(개선 없음), Prime은 min-sum 기반 |
| PR 채널 검출기(triangle node) | 대응 없음 | NAND 채널 아님, Prime channel.cpp와 무관 |
| turbo iteration 스케줄(채널↔복호) | 대응 없음 | Prime은 채널검출-복호 결합 구조 없음 |
| precoder/ambiguous 출력 제거 | 대응 없음 | NAND에 부분응답 precoding 개념 없음 |

적용 가치: 낮음 — 자기기록 부분응답 채널 전용 검출기 설계로, NAND binary QC-LDPC 부호설계/디코더 개선에 떼어 쓸 요소가 없다.
