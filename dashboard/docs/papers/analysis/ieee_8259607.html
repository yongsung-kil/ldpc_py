B. 알고리즘 요약

  1. 대상: 중간길이(수백~수천 bit) LDPC, (n,k)=(256,129)/(512,257)/(1024,513), regular (4,8) 등, BPSK/AWGN. SPA 복호가 MLD 대비 BER 열위인 5G급 코드.
  2. 문제: SPA는 중간길이에서 MLD 대비 BER 열위이고, OSD(Fossorier)는 정확하나 조합탐색 비용이 큼.
  3. 기법 1(OSD 리뷰): SPA 출력 신뢰도 γ 정렬 후 k-MRIP(가장 신뢰 높은 k bit) 선택, Gaussian elimination으로 systematic화, l0까지 bit-flip 조합을 탐색해 C(x)=Σ r_i x_i 최대화하는 codeword 탐색.
  4. 핵심 관찰: k-MRIP는 오류가 적어(예 2.0dB에서 오류<2 확률 86.98%) 작은 l0로도 충분 → 탐색 축소 여지.
  5. 핵심 기법 2(제안): "coincidence rate" R(x) 도입 - hard-decision z와 OSD 결과 x의 중하위 n-k 구간 일치율. MLD와 일치하면 R(x)가 1에 근접.
  6. 정지조건: 각 loop에서 R(x) > c0이면 즉시 정지. c0는 오판 확률 최소화, argmax_c{p2,C(c) - p1,W(c)}로 결정.
  7. 부수: p2,C, p1,W를 시뮬 빈도 n2,C, n1,W로 근사해 c0를 SNR·loop별 테이블(Table II~IV, 약 0.80~0.89)로 산출.
  8. 최적화: 별도 학습 없음 - Monte-Carlo 빈도 통계로 c0 결정.
  9. 결과: BER는 Fossorier와 거의 동등하면서 stopping 파트 CPU time을 (256,129)에서 32~69배, (512,257)에서 78~198배 단축(전체는 SPA+stopping).
  10. 한계: HW 미설계(CPU 시뮬만), gate/throughput 없음, SNR별 c0 튜닝 필요, Gaussian elimination 기반 조합탐색이라 HW 병렬 구조와 이질적.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SPA(Sum-Product) 기본 복호decoder.cpp LDPC_Decoder()Prime ECC는 min-sum 근사라 full-tanh SPA와 상이, 접점 약함
OSD 조합탐색 후처리대응 없음reliability-based OSD/Gaussian elimination 후처리 없음
coincidence-rate 조기정지 조건partial_CRC.cpp partial_crc_HW_T4()조기종료라는 목적만 유사, 방식(CRC vs R(x) 임계)은 완전히 다름

적용 가치: 낮음 - full-SPA 위에 얹는 OSD 조합탐색 후처리로, min-sum 기반 고rate NAND QC-LDPC HW 디코더에 이식하기엔 복잡도·구조가 부적합하다.
