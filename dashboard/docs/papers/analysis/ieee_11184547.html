B. 알고리즘 요약

  1. 시스템: AWGN/BEC 상 globally-coupled LDPC 부호. 예제 rate 0.5~0.9, 길이 7680~23040, GF(q) 위 base matrix를 CPM dispersion으로 전개한 구조.
  2. 문제: 기존 CN-based GC-LDPC는 글로벌 CN이 parity bit를 추가해 rate loss가 나고 모든 VN degree가 올라가 threshold가 나빠짐.
  3. 핵심 아이디어: 글로벌 "VN"으로 local 부호를 tail-biting(TB) 결합 → parity bit 미추가로 rate loss 제거, local/global VN degree 분포를 독립 설계 가능.
  4. 구성법 1: SOB-based unwrapping — 작은 행렬 B(0)를 표준정규기저 스칼라곱으로 큰 base matrix Bgc로 전개, girth 하한 g(Bgc)≥g(B(0)) 보장(Thm 1).
  5. 식 의미: girth를 작은 행렬에서만 확보하면 큰 부호까지 상속 → 대형 부호 girth 설계 부담 경감.
  6. 구성법 2: masking — Bgc=V⊙Wgc, 순환행렬 Vcyc로 girth≥6 고정, PEG로 W(0) degree 분포 자유 설계(Thm 2).
  7. 인코딩: CCB/ATF-CCB — 큰 Hgc를 M개 동일 컴포넌트 부호로 분해, time-invariant면 단일 컴포넌트 인코더 재사용.
  8. 복호: MGR-CCB(merry-go-round) — section-wise block-cyclic성을 이용, 매 iteration마다 local/global LLR 메모리를 Nl/Ng만큼 순환 시프트하며 단일 컴포넌트 복호기로 전체 복호. 감쇠 MSA(µatte=0.725, 50 iter).
  9. 결과: CN-based GC-LDPC 대비 0.1~0.4 dB 이득, 5G-LDPC와 유사 성능. MGR-CCB가 CN unit·wire를 M배 절감(예: Cgc,0 4320→1320 CN, Cqc,1 대비 wire 75240→23280).
  10. 한계: HW(FPGA/ASIC) 미설계·시뮬만, 부호가 non-binary CPM 기반이라 binary QC-LDPC와 이질적, low-to-moderate rate 최적화는 미해결.
