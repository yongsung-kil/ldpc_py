B. 알고리즘 요약

  1. 대상: BPSK/AWGN 채널상의 (3,6)-regular binary LDPC (rate Rc=1/2, MacKay DB 3개 코드, 길이 다름), 목표는 LLR 대신 unsigned 정수만 처리하는 discrete message-passing 디코더.
  2. 문제: BP는 실수 LLR과 transcendent CN 연산이라 HW 복잡, min-sum 근사는 성능 손실 → 정수·LUT 기반으로 BP 근접 성능을 얻는 것이 목표.
  3. 핵심 도구: Information Bottleneck(IB) — 관측 Y를 압축 T로 매핑하되 relevant bit X와의 상호정보 I(T;X)를 최대화 (β→∞ deterministic mapping = LUT).
  4. 채널 양자화: sequential IB의 변형 Algorithm 1로 대칭 AWGN 출력을 |T|=2^q 레벨로 클러스터링, 경계만 최적화(선형복잡도)해 mutual-info 최대 양자화기 생성.
  5. CN 연산: 노드연산 t^c=f^c(y^c)을 |T|^{dc-1} LUT로 직접 만들면 폭발 → dc-2개 2-입력 partial operation으로 분할, 각 |T|^2 엔트리 LUT.
  6. VN 연산: CN과 동일 원리로 dv-1개 partial operation, 첫 입력은 채널 양자화값 y0^v; 최종 비트결정은 dv+1 메시지로 별도 partial operation 설계.
  7. 학습절차: discrete density evolution — 반복 i마다 VN↔CN 출력분포 p^(i)(x,t)를 교대 전달하며 각 iteration별 LUT를 오프라인 생성.
  8. 구현 트릭: 노드연산을 trellis로 표현, 상태 인덱스만 저장; 전체 LUT를 1D 벡터 wc/wv에 recursive indexing으로 저장.
  9. 설계 Eb/N0: I(X^v;T_out)가 마지막 iteration에서 1bit에 근접하도록 design Eb/N0(예 1.27dB, imax=50) 선택, mismatched 사용에도 강건.
  10. 결과: q=4bit(|T|=16, 총 LUT 43.75KB)로 R2(min-sum)를 능가(~0.4dB@1e-6), BP 대비 손실 <0.1dB; DSP 구현 시 ~30% throughput 향상(ref [31]). 한계: irregular 일반화·RTL HW는 future work.
