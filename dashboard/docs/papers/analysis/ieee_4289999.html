B. 알고리즘 요약 (10줄 내외)

  1. 대상은 일반 선형 블록코드의 parity-check matrix H(m×n)과 그에 대응하는 Tanner graph G(변수노드 n개, 체크노드 m개).
  2. 기존에는 girth(최단 사이클 길이) 4는 매트릭스에서 쉽게 찾지만, 4보다 큰 사이클은 매트릭스만으로 식별하기 어려운 문제를 다룸.
  3. H에 포함된 submatrix와 G의 subgraph 간 1:1 대응 관계를 기반 모델로 사용.
  4. 핵심 개념 "2k-cycle-matrix"를 정의: k×k GF(2) 행렬로 각 행·열에 정확히 두 개의 "1"이 있고, 진부분행렬은 이 조건을 동시에 만족하지 않는 행렬.
  5. 정리(Theorem 3.3): girth가 2k인 것은 (a) H에 포함된 최소 2k-cycle-matrix가 존재, (b) k개 행의 합(성분별 덧셈)에서 2 이상 성분이 k개 이상인 최소 k, (c) 열 버전 등과 모두 동치.
  6. 이 동치성을 이용해 girth 판정 알고리즘 제시: k=2부터 시작해 H의 k개 행 조합을 모두 검사, 합의 2-이상 성분 수가 k개 이상이면 girth=2k로 확정.
  7. 최단 사이클 개수 카운팅 알고리즘도 제시: girth에 해당하는 k개 행 조합마다 합의 2-이상 성분 개수 u에 대해 조합수 C(u,k)를 합산.
  8. 별도 학습/최적화 절차는 없음(순수 조합론적 증명·알고리즘).
  9. 결과는 이론적 정당성 증명뿐이며 수치 실험(BER, gate count 등)은 없음.
  10. 한계: 알고리즘 복잡도가 k개 행 조합 수에 지배되어 m이나 girth가 크면 비실용적이며, 코드 구성(H-matrix 설계) 검증 단계의 보조 도구일 뿐 디코더나 HW와는 무관.
