총평: BP 공통 적용 가능한 저비용 조기종료(LLR 부호변화 기반)로 iteration/latency 절감엔 유효하나, Prime ECC의 CRC 조기종료와 기능 중복.

B. 알고리즘 요약

  1. 대상: rateless codes(LT/Raptor)의 soft BP 복호, code rate 1/2, 데이터 패킷 K=4000, max iteration 100, BIAWGN.
  2. 문제: BP는 고정 iteration까지 돌지만 보통 그 전에 원본에 수렴 → 불필요 iteration이 latency·연산·전력 낭비.
  3. 기존 CSR-ETM: 매 iteration마다 판정 비트를 재인코딩해 입력과 비교(m̂_c ⊕ Σm̂_v), 만족 CN 비율 μ_CSR≥Γ_CSR로 수렴 판단 → 재인코딩 비용 큼.
  4. 핵심 기법 SAB-ETM: m_v 메시지의 부호비트만 관찰. 비트 판정은 m_v의 sign으로 결정되므로 sign 불변 = 판정 불변.
  5. 종료 규칙: 판정 비트가 연속 Γ_LC회 iteration 동안 안 바뀌면 수렴으로 보고 종료. Γ_LC 작을수록 avg iteration↓, 너무 작으면 조기중단으로 오류↑.
  6. 이점: CSR과 달리 재인코딩·입력비교 없음 → iteration당 XOR/비교 연산 대폭 감소(복잡도 표 I: 재인코딩 항 제거).
  7. 복잡도 분석: iteration당 addition/abs·sign·XOR/comparison을 CSR과 대조, VN degree-1 계수 λ1·CN degree 분포 ρ_dc로 표현.
  8. 파라미터: BER 무손실 경계는 SAB Γ_LC=3, CSR Γ_LC=5에서 성립.
  9. 결과: avg iteration이 CSR보다 소폭 낮고(표 II), 조기종료 연산시간은 CSR 대비 79~83% 감소(표 III, 예 Eb/N0=0.5dB에서 63.21ms→10.44ms). BER 열화 없음.
  10. 한계: HW 미설계·시뮬만, rateless/BIAWGN 전제, 정정능력 자체 향상은 아님(순수 조기종료).
