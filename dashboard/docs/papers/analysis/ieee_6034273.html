B. 알고리즘 요약

  1. 대상은 rate R=b/c의 (J,K)-regular QC-LDPC block code로, tailbiting된 convolutional code 형태로 표현하며 girth와 최소거리 dmin을 동시에 키우는 부호 구성이 목표.
  2. QC-LDPC는 girth(최단 cycle)만 커도 low-weight codeword가 있으면 error-floor가 생기므로, girth뿐 아니라 큰 dmin을 가진 부호를 구성하는 것이 문제.
  3. base matrix B를 다항식(monomial/binomial) 라벨링한 것이 parent convolutional code의 H(D)이고, dfree(parent free distance)가 block code의 dmin을 상한한다.
  4. 핵심 기법: Hamming (2^J−1, J) 부호의 parity-check 행렬 2개(P, 그 permutation Pp)를 쌓아 (2J×2K) zero/one base matrix B를 만드는 double-Hamming 구성 (식 (5)).
  5. 이 구성으로 base graph girth gB가 나오고, Theorem 2에 의해 라벨링 후 girth gfree ≥ 3·gB, 또한 2nd generalized Hamming distance d2로 g ≥ 2·d2까지 보장.
  6. J=4 확장: parity part P를 P1,P2로 분할한 rate 8/16 base matrix(식 (7))로 straight-forward하게 J≥3 일반화.
  7. dfree 상한은 식 (10) dfree = min Σ W(∆J,i) (부분열 집합의 다항식 판별식 weight)로 계산.
  8. 라벨링 탐색은 저자들의 기존 random-labeling/강화 알고리즘([16],[10])으로 목표 girth를 만족하는 monomial degree tuple을 찾음.
  9. 결과: girth 8/10에서 dmin 최대 32, girth 14인 (2112,528) 부호(기존 최단 2208보다 짧음), (18688,9344) J=4 girth 10 부호 등 신규 부호 다수.
  10. 한계: 복호 알고리즘·HW·BER 시뮬 전무하며 rate 1/4~1/2 저rate regular 부호에 국한 (NAND 고rate와 불일치).
