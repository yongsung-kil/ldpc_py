B. 알고리즘 요약

  1. 시스템: BPSK AWGN 통신, QC-LDPC (160,3,5)/(1280,3,5) 및 π-rotation (2000,3,6) 코드를 하드결정 후 비트플리핑 복호.
  2. 문제: BP(sum-product/min-sum)는 정정능력 좋으나 연산량이 커 저전력 임베디드 기기에 부적합; IRRWBF는 성능-복잡도 절충이 좋음.
  3. 기반 알고리즘 IRRWBF: 초기화·체크노드·변수노드·결정의 4단계로 분리, 신뢰도비 기반 가중 비트플리핑.
  4. 핵심 기법: i>=2에서 한 비트 znf가 뒤집히면 그와 연결된 Wc개 체크노드만 갱신(s_mf = 1 - s_mf)되므로 전체 재계산 대신 선택적 갱신만 수행.
  5. 식 (4): 갱신된 체크노드에 연결된 변수노드 오차항 En만 국소 갱신 → 재계산 대상이 WcWr 이하로 축소.
  6. 복잡도 이득 (7): Oc(org)-Oc(pro) ≈ 2N Wc (i-1), 즉 코드길이 N과 반복수 i에 비례하여 연산 감소.
  7. 구현 트릭: 패리티행렬을 Hr(행별)·Hc(열별) 인덱스 패킹한 스트림 기반 자료구조로 저장, 갱신을 독립 병렬 연산으로 표현.
  8. SIMD 병렬화: Intel Wireless MMX 2로 d개 데이터를 한 사이클에 처리 (식 12), 선택적 갱신이 SIMD 형태로 표현됨.
  9. 결과: 원본 대비 non-MMX 200~600%, MMX 500~1500% 속도 향상(반복 5~1000), 코드길이 증가 시 1000%+ 향상; PXA320(806MHz)에서 실측.
  10. 한계: 정정능력(BER) 개선 없음(기존 IRRWBF와 동일), 전용 HW 미설계, 범용 CPU/SIMD 전제.

C. Prime ECC 관련 모듈 핀포인트

비트플리핑 선택적 갱신 복호 루프decoder.cpp LDPC_Decoder()낮음 (Prime ECC는 min-sum 기반, 비트플리핑 알고리즘 아님)
체크노드 갱신(비트플리핑)대응 없음min-sum(CNU_Update_New_Mag())과 연산 성격 다름
H-matrix 인덱스 패킹(Hr/Hc)대응 없음SIMD 소프트웨어 자료구조로 HW pipeline과 무관
SIMD 병렬화(Wireless MMX)대응 없음GPP 명령어 확장, HW RTL 병렬(z=32)과 무관

적용 가치: 낮음 — 하드결정 비트플리핑을 범용 CPU SIMD로 가속하는 논문으로, NAND용 HW min-sum QC-LDPC 엔진(Prime ECC)에 이식할 알고리즘·구조가 없다.
