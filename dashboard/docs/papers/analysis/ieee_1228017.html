총평: 정수격자+Latin square 분할로 임의 rate/차수분포의 irregular 부호를 결정론적으로 설계하는 구성법 논문으로, NAND 고rate QC-LDPC와 무관하고 이식 가치 낮음.

B. 알고리즘 요약

  1. 목표: 임의 rate·차수분포의 좋은 irregular LDPC를 결정론적으로 설계 (무작위 생성 대안).
  2. 출발점: Vasic[2]의 정수격자(integer lattice) 기반 조합 LDPC. 사각격자 L={(x,y):0≤x≤k-1,0≤y≤m-1}, m 소수, 선형사상 l(x,y)=mx+y+1로 lattice point label 부여.
  3. 블록/라인: 기울기 s의 라인이 하나의 block, 각 클래스에 m개 평행선. point-block incidence 행렬 H(h_ij=1 iff i번째 점이 j번째 block에 포함)를 부호행렬로 사용.
  4. girth 조건: resolvability class 집합 B'가 girth-8 설계가 되도록 최대 cardinality 기울기집합 S를 탐색.
  5. 확장 기법: regular 부호의 열/행을 pseudo-random edge selection으로 분할하여 irregular화 — 단순 순차 분할보다 사이클(cycle) 수 더 감소.
  6. Step1: 기본 랜덤수열 C(i)=a·i-1 mod P (P는 d_c 초과 최소소수, a는 GF(P) 원시근), d_c 초과 정수 제거로 pruning.
  7. Step2~3: 순열패턴 LB_j(i)=(j·i) mod P 생성 후 pruning, 이를 C(i)와 결합해 j번째 Latin square 행렬 L_{j,q}(i) 구성.
  8. Step4: Latin square 행렬에 따라 열·행 분할 수행.
  9. 최적화: 정수격자 regular 부호를 제약으로 두고 GA[1](Gaussian Approximation)로 차수분포 최적화.
  10. 결과: (10,7)-LDPC 기반 rate-0.5 irregular 부호가 codeword 길이 7030(짧음)임에도 BER=1e-4에서 Shannon 한계로부터 0.9 dB.
  11. 한계: 디코더/HW 설계 없음, AWGN 대상, rate 0.5 단일 예제, 표 데이터 일부 손상.
