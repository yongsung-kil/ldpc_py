B. 알고리즘 요약

  1. 시스템: 실시간 스트리밍(제어용) 채널부호. 채널은 BEC(소거확률 ε), 코드는 rate Rc의 anytime code.
  2. 문제: 블록/컨볼루션 코드는 유한지연·유한메모리로 안정적 제어 불가 → 지연에 따라 오류가 지수적으로 감쇠하는 anytime 코드 필요.
  3. 모델: 시각 t에 메시지 s_t 생성, 인과적 인코더 E_t(s_1^t), 지연 d=t-i에 대해 Pe(i,d) ≤ β·e^{-αd} (α=anytime exponent) 만족.
  4. 핵심기법: (dv,dc) regular protograph L개를 spatial coupling. VN(position i)의 각 연결을 [i, i+γ-1] 범위 CN에 인과적으로 배치해 causal 스트리밍 인코더 확보.
  5. 커플링 분포: 균일이 아니라 Pr(k)=e^{-kλ}(1-e^{-λ}) 지수분포 사용(k=j-i). 가까운 블록에 연결 집중 → 소지연에서 빠른 오류개선.
  6. 확장: chain length L과 coupling length γ를 크게(이론상 γ=∞) 두어 지연 증가 시 신뢰도 향상 보장.
  7. 해석: density evolution으로 VN/CN 소거확률 갱신식(식3~5) 유도, M=∞ 가정하에 anytime 지수감쇠 특성을 점근적으로 증명.
  8. 유한길이 추정: [12]의 기법 적용, 실현 소거확률을 이항→가우시안 N(ε, ε(1-ε)/N)으로 근사·주변화하여 지연함수로서 BER 추정.
  9. 복호: adaptive window decoding(AWD). 복원 비트를 check식에서 제거하고 parity 갱신, Hactive만 사용 → 복잡도 O(Wav) (EWD의 O(Mt) 대비 상수 수렴, ε=0.35에서 Wav≈150).
  10. 한계: BEC/시뮬만, HW 미설계, AWGN 확장은 future work, delay exponent α도 미도출.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SC-LDPC 지수분포 커플링 부호구성대응 없음Prime ECC는 고정 blocklength QC-LDPC, 스트리밍 SC 구조 미대응
adaptive window decoding (BEC)대응 없음Prime ECC는 blockwise min-sum 복호, windowed streaming 복호 없음
density evolution 소거확률 갱신대응 없음이론 해석 도구, 코드 모듈과 무관

적용 가치: 낮음 — BEC 스트리밍/제어용 anytime SC-LDPC 구성으로 NAND 블록 binary QC-LDPC ECC의 부호설계·복호·HW 어디에도 이식 접점이 없다.
