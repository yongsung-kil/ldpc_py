총평: LDPC 인코딩 기법을 정리한 교과서적 리뷰 논문. Richardson-Urbanke 근사 하삼각 O(n+g²) 인코딩 등 이미 표준화된 기법 소개뿐으로, Prime ECC(dual-diagonal 고정)에 새로 이식할 요소 없음.

B. 알고리즘 요약

  1. 시스템: 일반 binary LDPC 부호의 인코딩 문제 - PCM H가 sparse여도 생성행렬 G 기반 인코딩은 O(n²)라 긴 부호에서 비현실적임을 지적.
  2. 문제: LDPC의 인코딩 복잡도·지연 절감; 랜덤성(성능) 유지와 선형시간 인코딩을 동시에 달성.
  3. 전통 인코딩: H=[C1|C2]에서 Gaussian 소거로 G=[(C1⁻¹C2)ᵀ|Ik] 도출, 전처리 O(n³)+실제 인코딩 O(n²), 열교환 기록으로 원부호 복원(Lemma 1,2).
  4. 하삼각 인코딩: MacKay가 제안한 PCM을 하삼각 형태로 제약해 선형시간 인코딩 가능하나, 제약이 Shannon 랜덤성 원칙을 깨 성능 저하 유발.
  5. 근사 하삼각(Richardson-Urbanke): H를 서브블록 A,B,C,D,E,T(T는 하삼각)로 행/열 치환, [[I,0],[-ET⁻¹,I]]를 곱해 gap g 도입.
  6. 핵심 식: Φ=(-ET⁻¹B+D)가 비특이면 p1ᵀ=-Φ⁻¹(-ET⁻¹A+C)sᵀ로 패리티 결정, 이후 p2는 식(5)로 산출.
  7. 구현 디테일: p1 계산을 sparse 곱·역치환 소단계로 분해해 O(n+g²), p2는 O(n)로 산출.
  8. 탐욕 알고리즘: diagonal extension으로 PCM을 근사 하삼각화하며 gap g를 최소화, sparsity를 보존(Richardson-Urbanke는 g≤0.017n 보장 → 실질 O(n)).
  9. 결과: 300×600 (rate 0.5, wc=3, wr=6) MacKay 랜덤 PCM에서 Gaussian 소거는 sparsity를 파괴하나 greedy 전처리는 sparsity 유지(분포도로 확인).
  10. 한계: 인코딩 알고리즘 리뷰·복잡도 분석뿐, HW 미설계, 디코더/정정능력 논의 없음, 신규 기여 없이 기존 표준 기법 요약.
