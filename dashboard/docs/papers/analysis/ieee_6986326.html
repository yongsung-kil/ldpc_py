총평: 정수 양자화 layered min-sum의 register overflow를 값싼 보정(subtractor/shift)으로 잡는 실용 아이디어로, 우리 정수 min-sum 파이프라인 안정화에 참고 가치 있으나 LTE 특화·성능은 순열화 방지 수준.

B. 알고리즘 요약

  1. 대상은 3GPP-LTE QC-LDPC(예 (756,3,9), (1008,3,9), sub-matrix Z=84, rate 1/2~2/3)로, layered(TDMP) 복호기를 정수 양자화로 구현한다.
  2. 문제: 유한 정밀도 정수 양자화 시 저장 유닛 제약으로 메시지가 threshold Z=2^(q-1)-1를 넘으면 overflow 되어 심각한 복호 오류가 누적된다.
  3. 채널/모델: BPSK over LTE(ETU/EPA/EVA), 초기값 y_n을 Δ=3.2/Z 균일 양자화로 Y_n으로 사상.
  4. 핵심 기법: TDMP를 offset Min-Sum으로 구현 — CN 갱신 λ_mn = ∏sign(ρ) · max(min|ρ|-β, 0), VN 갱신 γ = ρ + λ.
  5. overflow 분석: layer마다 Thre(γ)_Z = γ + ε로 오류 ε가 발생하고 식(8)~(11)처럼 다음 iteration prior에 전파·누적됨을 유도.
  6. 개선 1(PEES): γ̂는 threshold로 못 바꾸므로 λ 값을 λ_mod = λ + ε로 보정해 식(13)처럼 prior의 오류를 부분 상쇄 (np개 추가 add).
  7. 개선 2(PEES-Modify): α=1/2(shift로 구현)로 ρ_mod를 normalize, 첫 layer prior 오류(가장 영향 큼)를 register right-shift로 추가 제거 (mp개 추가 shift).
  8. HW: 기존 TDMP decoder에 summer(가산기)와 shift만 추가, PCUB(offset MSA CN 유닛) 재사용.
  9. 결과: overflow 제거로 floating-point 대비 열화 acceptable, PEES-Modify > PEES; (756,3,9)가 500MHz에서 254.5Mbps.
  10. 한계: 정정능력 향상이 아니라 정수화 열화 방지 수준, gatecount·ASIP 면적 수치 없음, iteration 감소 없음(N_iter=5 고정), LTE 채널 가정.
