총평: 위상잡음 채널의 채널추정·검출 기법으로 LDPC는 외부 SISO 모듈로만 쓰여 NAND binary LDPC ECC 이식 가치 없음.

B. 알고리즘 요약

  1. 시스템: MPSK(실험 8PSK) 심볼을 AWGN + 반송파 위상잡음(Wiener process θk=θk−1+∆k, σ∆=0.05) 채널로 전송, rate 0.75, length 4608 LDPC.
  2. 문제: 저가 up/down-converter의 강한 위상잡음이 정보율을 제한, PLL/파일럿 방식은 오버헤드 큼.
  3. 모델: joint posterior의 factor graph 위에서 code graph와 channel graph를 결합한 message passing(순방향 pf/역방향 pb/심볼 pd).
  4. 핵심 기법: 연속확률변수인 위상 메시지를 N개 Tikhonov 성분 혼합으로 근사(식 9,10), forward/backward 재귀에 대입하면 차수 NM으로 팽창.
  5. 핵심식: KL divergence DKL(f||g) 최소화로 혼합 축소(식 15,16) — 원 혼합의 정보를 최대 보존하며 복잡도 억제.
  6. 확장(canonical model): 고정 크기 축소 대신 심볼별 적응적 혼합 크기를 두고 평균 성분수 γ로 복잡도 측정.
  7. 축소 알고리즘: argmax(ak|zk|^{-1})로 lead 성분 선택 후 DKL≤µ인 성분을 CMVM(Circular Mean and Variance Matching)으로 하나로 병합.
  8. 파라미터 µ는 허용 왜곡 수준으로 결정, SNR/위상잡음 분산에 둔감하여 강건.
  9. 결과(Fig.2): 8PSK Wiener 위상잡음에서 기존 DP 대비 근접 BER, 반복 진행 시 LDPC soft-info 개선으로 평균 성분수 γ가 2.3→1로 감소(복잡도↓).
  10. 한계: HW 미설계·시뮬만, 위성 위상잡음 채널 특화, LDPC 코드/디코더 내부는 개선 대상 아님.
