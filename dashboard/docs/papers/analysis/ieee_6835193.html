B. 알고리즘 요약

  1. 대상: variable-regular LDPC(C1 (1008,504), C2 (8000,4000) dv=4,dc=8; C3 (816,408) dv=5,dc=10, 모두 girth g=6, rate 0.5)를 q=3bit 균일양자화 min-sum(LLR 도메인)으로 복호할 때의 error floor 추정.
  2. 문제: 기존 [5]의 modified cycle enumeration은 길이 g..g+2k 사이클 집합 Tk를 쓰는데, block length>1000·dv>3에서 |Tk|가 폭발(예 k:1→2에서 218k→6.3M)해 실용성 상실.
  3. 모델: all-zero 전송 가정, BPSK/AWGN, [-Cth,Cth] 양자화. 가장 신뢰벡터 R(모든 좌표가 Q=2^{q-1}-1)에 대한 Euclidean 거리 순으로 실패 입력벡터 탐색.
  4. 핵심 기법: 사이클 집합 Tk 대신 크기 a≤A, b(min)≤b≤B인 (a,b) elementary trapping set(ETS) 집합 TA,B로 에러위치를 선정 — 에러패턴 생성/추정식은 [5] 그대로 유지.
  5. 근거: ETS 대부분이 짧은 사이클의 layered superset(LSS)이라 [7]의 LSS 탐색(Algorithm 1 of [7])으로 사이클에서 한 변수노드씩 키워 guaranteed 하게 전부 열거, non-LSS는 소수라 개별 처리.
  6. 관측: 각 a마다 최소 b(min) 클래스 (a, b_min)만 포함하면 정확한 추정에 충분 → 집합을 T_{A,b_min}로 축소, 서브셋 ETS 제거로 크기 추가 감소(1130/2520/7286).
  7. 종료조건: 실패패턴 최소거리 dm에 대해 d^2 > dm^2 + β까지만 테스트(Algorithm 1), β≈10이면 충분.
  8. 결과: A=10이면 모든 유효 ETS 클래스 커버, T_{10,bmin} 기반 추정이 Monte Carlo와 근접. 테스트 입력벡터 수를 modified cycle enumeration 대비 C1 7배·C2 70배·C3 83배 절감. C언어 구현, 7/112/13시간 소요(Xeon 2.27GHz, 2GB).
  9. 부가 결론: absorbing set만으로는(전체 ETS의 극소수) error floor를 정확히 추정 못함 → error floor 영역의 지배 구조는 (absorbing이 아니라) ETS임을 확립.
  10. 한계: variable-regular·girth=6 한정, 부호/디코더 자체를 개선하지 않는 추정(분석) 기법, HW 미설계, block length↑에서도 수 시간 소요.
