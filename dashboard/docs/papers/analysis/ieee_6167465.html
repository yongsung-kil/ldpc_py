B. 알고리즘 요약

  1. 대상 채널은 (binary) Z-channel: 0→1 전이 오류만 확률 α로 발생하고 1→0은 불가능한 비대칭 채널로, Flash 메모리의 비대칭 오류 특성에서 착안.
  2. 기존 대칭 채널(BSC)용 LDPC는 Z-channel에서 최적이 아니므로, 코드워드 내 1의 비율(확률 파라미터 p)을 조정해 성능을 개선하려는 문제 설정.
  3. 채널모델: Pr(xi=0)=β, Pr(yi=1|xi=0)=α인 이산 무기억 Z-channel, 용량은 I(x,y)=H(β-αβ)-βH(α)로 계산.
  4. Construction 1(핵심 기법): 체계적 부호 C[n,k,2]에서 정보열의 무게(1의 개수)가 np 이상인 코드워드만 발췌(expurgate)해 C[n,k',2,p'] 생성, p'≥p.
  5. 핵심 식: k' = log2(Σ_{j=m}^{k} C(k,j)) ≈ kH(np/k) — 발췌 후 남는 코드북 크기(=새 부호율)를 이진 엔트로피로 근사.
  6. 확장 기법(Construction 2/3): 비이진 부호 C[n,k,q] (q=2^v-1)의 각 심볼을 all-zero를 제외한 v비트 이진열에 매핑해 1의 비율을 편향시키는 구성.
  7. 디코딩은 표준 sum-product(BP)에 채널 비대칭성을 반영한 LLR 초기화 LLR(yi=1)=log((1-β)/(αβ)), LLR(yi=0)=-∞ 를 사용(최대 50회 반복).
  8. 성능평가는 DVB-S.2 규격 n=64800 LDPC(rate 0.75)를 기준으로 Construction 1 적용 시 rate가 0.7635(p=0.5)~0.7473(p=0.52)로 변화.
  9. 결과: 저 SNR(α가 큰) 영역에서 발췌된 비대칭 부호가 동일 rate의 대칭 LDPC 대비 BER을 낮춤; 발췌로 코드북 크기는 대칭 대비 약 2×10^263배 크지만 부호율은 다소 감소.
  10. 한계: Construction 1만 실제 시뮬레이션 결과 제시(Construction 2/3은 확장판으로 유보), HW 설계 없음, 이상화된 단방향 Z-channel 가정이라 NAND의 실제 다중 레벨/양방향 오류 모델과는 거리가 있음.
