B. 알고리즘 요약

  1. 채널 모델은 y = r·x + n (r: fading gain, pdf p(r) 임의, n: 가우시안 노이즈, 분산 σ_n^2), receiver에 fading gain r에 대한 side information(SI) 없음을 가정.
  2. 문제: SI 없이 참 LLR은 복잡한 비선형 함수(예: Rayleigh 채널에서 erfc 포함 식)라 디코더 구현이 어려움 — 기존 연구는 r=E[r]을 쓴 선형근사 l=(2/σ_n^2)·a·y를 사용하나 최적이 아님.
  3. 핵심 가정: σ_n은 알고 r의 pdf만 아는 상황(예: 정규화 Rayleigh 채널) — capacity C는 LLR pdf p(l)의 함수 C=1-E[log2(1+e^{-l})].
  4. 핵심 기법: 선형근사 계수 a(또는 r_opt)를 채널 achievable rate C를 최대화하도록 선택하는 MCLA(Maximum-Capacity Linear-Approximation) 제안, r_opt = argmax_r C.
  5. 핵심 정리(Theorem 1): 고정된 σ_n, σ_r에 대해 C는 r에 대해 오목함수이며 유일한 최대값 r_opt가 존재 — 1차원 볼록최적화로 효율적으로 계산 가능.
  6. 확장: σ_n도 모르는 경우, 코드가 견딜 수 있는 최대 σ_n^*(binary search로 탐색)에서의 a_opt(σ_n^*)를 사용해 가장 넓은 수렴 범위를 확보.
  7. 부수 트릭: a_opt는 σ_n에 민감하지 않다는 관찰을 이용해 sub-optimal a 선택도 실질적 손실이 적음.
  8. 학습/최적화 절차: irregular LDPC 부호(가변노드 최대 차수 30)를 rate-maximization/threshold-maximization 기준으로 density evolution 기반 설계(11-bit 양자화, 최대 300 iteration).
  9. 결과: Rayleigh 채널에서 E[r] 사용 대비 MCLA가 0.75 bits/channel use에서 0.92dB, 0.5 bits에서 0.24dB 개선; 설계 부호(rate 0.5)의 decoding threshold는 no-SI 3.82dB, MCLA-unknown-σ 3.82dB(SI 대비 0.76dB 갭, 참 LLR 대비 0.02dB 손실만).
  10. 한계: 이론/시뮬레이션뿐 HW 설계 없음, Rayleigh/Rician fading 채널 전용 모델이라 NAND(무선/자기기록과 무관한 메모리리스 채널)에는 전제(fading gain 불확실성) 자체가 존재하지 않음.
