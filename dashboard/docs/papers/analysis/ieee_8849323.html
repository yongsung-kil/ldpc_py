B. 알고리즘 요약

  1. 대상은 시변/시불변 SC-LDPC convolutional code(SC-LDPC-CC), asymptotic rate R∞=(a-c)/a, syndrome former memory ms, 주기 T.
  2. 문제: 시변 SC-LDPC-CC는 성능 좋으나 파라미터가 매우 많고, 시불변 부호는 표현은 간결하나 girth가 약함.
  3. 부호는 다항식환 F2[D] 위 c×a 심볼릭 행렬 H(D)로 표현, weight matrix W가 unavoidable cycle을 결정.
  4. 핵심 정리 1: W가 finite c×a (dv,dc)-regular이면 시불변 부호의 girth는 ms→∞라도 유한 상한 g*(unavoidable cycle 길이)로 제한됨.
  5. g*는 W의 두 cycle이 공유 edge r개일 때 2(l1+l2-r) 등으로 계산(Lemma 2) — 메모리만 키워도 girth는 못 넘음.
  6. 확장: 주기 T>1인 시변 부호는 자유도를 조금 더 써서 g>12 달성 가능. W12(2×3 all-ones) 앙상블에서 T=2로 girth 20 도달.
  7. 조건: (2,a)-regular all-ones W에서 g>12의 필요충분조건은 T ≥ ⌈a/2⌉ (Lemma 7), c>2로 일반화(Corollary 2).
  8. 최적화: exhaustive search 및 guess-and-test로 exponent matrix P 탐색.
  9. 결과: T=2로 7개 정수만으로 girth 20 부호 설계(시불변 6정수·girth 12 대비), (3,4)/(3,5)/(3,6)-regular 예제 제시.
  10. 한계: HW·디코더 미설계, BER/error-floor 시뮬 없음, 블록부호가 아닌 convolutional 구조라 NAND 적용 경로 부재.
