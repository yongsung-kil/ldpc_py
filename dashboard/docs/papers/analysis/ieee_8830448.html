B. 알고리즘 요약 (10줄 내외)

  1. 시스템: Gaussian unsourced MAC, Ka active 기기가 각 B=100bit를 N=30000 채널사용에 전송, 목표 Pe<=0.05.
  2. 문제: 기기 식별 없이 동일 코드북을 써야 하는 unsourced MAC에서 기존 Ordentlich-Polyanskiy 방식은 SIC 불가로 sub-block 낭비가 커 스펙트럼 효율 저조.
  3. 모델: V개 sub-block으로 분할, sub-block당 최대 T개 신호를 합산 관측하는 real binary adder channel + AWGN.
  4. 핵심기법1: 메시지를 preamble Bpbit + coded Bcbit로 분할, preamble은 compressive sensing 행렬 A(63x512, BCH 기반)로 전송·복원.
  5. 식 의미: preamble 인덱스 wp로 permutation pi_tau(wp)를 선택해 동일 LDPC 코드워드를 사용자별로 재배열, 선형성을 깨 MAC 간섭을 탈상관.
  6. 핵심기법2: coded bit는 (SC)LDPC로 부호화, T-user용 joint BP 디코더가 MAC node h(u,y|sigma^2)를 추가해 최대 T개 메시지 동시복원.
  7. 구현디테일: sub-block 에너지로 Rj 추정, 가볍게 실린 sub-block부터 복호.
  8. 최적화: idealized SIC를 peeling(density evolution)로 분석, L(x)=beta*x+(1-beta)x^2 좌차수분포와 threshold alpha*_DE(T=2:0.5975) 도출.
  9. 결과: T={4,5}에서 4-fold ALOHA 대비 큰 이득, (3,6) LDPC 실측이 FBL 근사와 0.5dB 이내 일치.
  10. 한계: 완전 시뮬만, HW 미설계, 동기·페이딩 이상화된 무선 채널 가정.
