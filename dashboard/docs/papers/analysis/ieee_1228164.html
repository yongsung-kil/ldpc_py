B. 알고리즘 요약

  1. 대상은 (J,L) QC-LDPC 부호로, 패리티검사행렬 H가 J×L 블록의 circulant permutation matrix I(p_{j,l})로 구성되며 길이 N = pL.
  2. 풀려는 문제: circulant permutation 구성 QC-LDPC의 Tanner graph girth를 어디까지 키울 수 있는가 (girth가 클수록 짧은 cycle 감소로 복호 성능 유리).
  3. cycle 길이 2i를 H의 노드/permutation 시프트 순서열로 정식화하고 shift 차 Δl,j(l)=p_{j,l}-p_{j',l}를 정의.
  4. 핵심 결과(Theorem 1): Tanner graph girth ≥ 2(i+1)의 필요충분조건을 시프트 차의 합 Σ Δ ≠ 0 mod p 형태로 유도 (열/행 index 차 양쪽 버전).
  5. 이 조건의 의미: girth는 circulant shift 값들의 modular 합이 0이 되지 않도록 설계하면 보장 — 조건이 비교적 loose하여 girth 6/8/10/12 부호를 얻기 쉬움.
  6. Theorem 2·Corollary 1: g≥6의 필요조건과 p 하한 (p≥L 등), 하한이 L에만 의존하고 J에 무관.
  7. Theorem 3·Corollary 2: g≥8의 필요조건과 p>(J-1)(L-1) 하한.
  8. 핵심 상한(Theorem 4): 임의 (J,L) QC-LDPC는 g≤12 — Tanner[1] 결과를 일반화. 주어진 rate에서 최소거리를 늘리려면 J와 L을 동시에 키워야 함을 시사.
  9. 결과: 주어진 J,L에 대해 girth g를 만족하는 최소 p를 computer search로 결정; 수천 bit급 부호가 타 방식 LDPC와 최소한 동등 성능.
  10. 한계: 순수 이론 논문 — 구체 부호 스펙, 디코더, HW, BER 곡선 등 정량 결과 없음.
