B. 알고리즘 요약

  1. 대상은 rate-compatible QC-PBRL-LDPC(5G 표준 채택형)의 다중엣지 protograph로부터 지수행렬 B를 구성하는 문제.
  2. base matrix W가 커지면 Fossorier 식(Eq.1)으로 2k-cycle을 검사하는 탐색공간이 폭증 - 특히 irregular 다중엣지에서 지수행렬 구성이 난제.
  3. 핵심 기법 degree reduction method: 두 노드 사이 2ℓ(또는 2ℓ+1) 엣지를 절반으로 줄여 W'ij = ⌈Wij/2⌉인 저차수 base matrix W'를 먼저 만든다(Step 1).
  4. W'의 지수행렬 B'를 구성 - 각 열 첫 두 비영원소만 exhaustive search로 정하고, 나머지 행은 계수 ci(gcd(ci,N)=1)를 곱해 Bi'j = ci × br j로 유도(Step 2).
  5. B'로부터 B를 복원: Wij=2ℓ이면 Bij = {b, N−b} 형태로 대칭 확장(Step 3). 이때 새 파라미터가 추가되지 않음.
  6. 핵심 효과: 파라미터 수가 Σ Wi'j → (W0'j+W1'j)+m−2로 감소(Example 1에서 112→42 변수, 탐색공간 N^70배 축소).
  7. 4-cycle 회피 필요충분조건(Theorem 2)과 소형 trapping set(8-cycle-wc) 제거 필요조건(Theorem 3)을 Table I 대수식으로 제시.
  8. 수치 결과: [7]의 두 WHRC × 5 WIRC 케이스에 적용, girth 6 최소 lifting degree N=17/23/31 달성 - 기존 N=33보다 짧은 부호 길이.
  9. 성능곡선(Fig.1)은 sum-product 50 iteration으로 복호한 BER/FER (AWGN, Eb/No 1~3.5dB) - 별도 디코더 알고리즘 기여 없음.
  10. 한계: HW/디코더 미설계, 순수 부호구성 이론, non-binary·5G 특화이며 정정능력·error-floor 직접 개선 주장 없음.
