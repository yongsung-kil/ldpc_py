B. 알고리즘 요약

  1. 대상: Forney-style factor graph(FFG) 위 이진 알파벳 분배함수 Z(G) 추정, belief propagation과 Bethe 근사의 관계 규명.
  2. 문제: Bethe 분배함수 Z_B(G)가 일반적으로 참 Z(G)의 상·하한 어느 쪽도 보장 못 함 (비볼록 최적화, 다중 극점).
  3. 모델: 각 factor에 local 함수 g_a:{0,1}^∂a→R≥0, 이를 다변수 다항식 h_a(x_a)=Σ g_a(σ)x^σ로 인코딩.
  4. 핵심 기법(Thm 3.1): Bethe 분배함수를 다항식 최적화 Z_B(G)=max_β Π β^β(1-β)^(1-β) inf_{x>0} Π h_a(x_a)/x^β로 재정식화.
  5. 식 의미: max-entropy 프로그램의 쌍대(strong duality)로 Emax를 inf log h(x) - Σβ_i log x_i로 표현 (Lemma 4.2).
  6. 핵심 결과(Thm 3.2): local 다항식 h_a가 모두 real stable이면 Z_B(G) ≤ Z(G) (하한 보장); bipartite FFG 가정은 일반성 잃지 않음.
  7. 증명 구조: IPC(Iterated Positive Correlation) 조건 도입 → IPC이면 하한 성립(Lemma 5.1), real stability ⇒ IPC(Lemma 5.2).
  8. 핵심 보조정리: 이변수 multi-affine 다항식 h10·h01 ≤ h00·h11이면 하한 성립(Lemma 5.5), permanent가 특수 사례.
  9. 함의: real stable factor graph는 log-submodular이며, 이는 [37]의 log-supermodular 영역과 상보적; permanent 하한의 대안 증명 제공.
  10. 한계: 전면적으로 순수 이론(증명), 알고리즘 구현·HW·복호성능 실험 전무, LDPC는 응용 인용에 그침.
