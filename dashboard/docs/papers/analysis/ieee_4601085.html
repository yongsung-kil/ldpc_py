B. 알고리즘 요약

  1. 대상 문제: 길이 n binary linear code의 ML 복호를 fundamental polytope P 위 LP max <γ,x>로 완화한 Feldman의 LP decoder (γ=LLR 벡터).
  2. 기존 한계: 범용 LP solver는 이 LP의 구조(sparse PCM)를 못 살려 MPI 복호와 복잡도/속도 경쟁 불가.
  3. 제안: interior-point 계열 알고리즘 두 부류 — affine-scaling(§II)와 primal-dual interior point(§III) — 을 LP 복호에 적용.
  4. affine-scaling: feasible 내부점에서 시작, 삼각제약을 타원체로 근사하여 <c,x> 최소화 방향을 잡고 내부 유지하며 step. 단/장 step 변형.
  5. primal-dual: primal·dual 최적해를 동시에 추적, infeasible-interior-point 변형은 초기 infeasibility를 반복적으로 줄임. 다항시간 worst-case 경계 존재.
  6. 공통 병목: 매 iteration마다 positive-definite P에 대한 선형계 Pu=v를 반복적으로 근사 풀이(정확해 불필요).
  7. 효율화(§IV): P가 sparse 곱으로 표현되므로 conjugate-gradient(preconditioner 포함)가 유리.
  8. 대안: Pu=v를 additive/Gaussian factor graph로 표현해 min-sum(=Gaussian에서 sum-product)으로 근사 — LDPC용 factor graph와 위상 동일하게 구성.
  9. 부수 단순화(§V): degree-k check를 degree-3 check k-2개 + 보조 VN으로 분해, LP 부등식 적응적 추가.
  10. 한계: HW 미설계·정량 결과 없음, "초기 결과 고무적, 추가 연구 필요"로 마무리하는 개념 제안 단계.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
LP 복호 전체(interior-point)대응 없음Prime ECC는 min-sum MPI 복호, LP 복호 패러다임 자체가 없음
Pu=v 근사용 factor-graph min-sumdecoder.cpp LDPC_Decoder(), C2V_Cal()min-sum 엔진은 있으나 여기선 quadratic-cost 내부 solver 역할로 용도 상이
degree-k check → degree-3 분해대응 없음Prime ECC는 고정 QC-LDPC PCM 사용, check degree 재구성 안 함

적용 가치: 낮음 — LP 복호는 Prime ECC의 min-sum HW 구조와 근본적으로 다른 복호 패러다임이고 HW·정량 검증도 없어 이식 근거가 없다.
