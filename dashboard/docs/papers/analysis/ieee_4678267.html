총평: RU 인코딩의 serial forward-substitution을 순열행렬(T⁻¹=Tᵀ, Φ=I) 구성으로 제거해 선형·병렬 인코딩을 얻는 인코더 구성법이나, 부호성능 검증이 없고 Prime ECC는 dual-diagonal 효율 인코딩을 이미 보유해 이식 가치 낮음.

B. 알고리즘 요약

  1. 문제: LDPC를 G로 인코딩하면 O(n²); RU 알고리즘은 H를 하삼각화(6분할)해 O(n+g²)≈O(n)이지만 T⁻¹ 대체용 forward-substitution이 serial이라 인코딩 latency 큼.
  2. 목표: 부호 구성과 인코딩을 함께 설계(LEC-LDPC)하여 g 크기 무관하게 항상 O(n), 순열행렬 활용, 홀수 열가중치 대상.
  3. 핵심 성질: 순열행렬 P는 직교 → P⁻¹=Pᵀ; permutation·zero 블록으로 확장한 S도 S⁻¹=Sᵀ(Lemma 1), 그런 행렬들의 곱도 같은 집합 G에 속함(Lemma 2).
  4. 구성 핵심: T를 순열행렬로 두어 T⁻¹=Tᵀ(하삼각 전처리·forward-sub 불필요) → multithread 가능.
  5. Φ=I 강제: Φ=-ET⁻¹B+D=I가 되도록 E,B를 G의 확장행렬로, D를 식(8)(10) 형태(각 블록 Dij는 weight 0 또는 2)로 구성.
  6. 제약: D의 행/열 가중치가 짝수 → 열가중치 a=2k+1(홀수)만 지원; 제약조건 1/2로 EiᵀTBj가 I이거나 대각이 0이 되도록 E,B 배치(같은 위치에 1 없음).
  7. Hb 구성 절차: (Step1) T,Ei 순열행렬 랜덤 생성(조건2 만족) → (Step2) Bj를 식(11)로 → (Step3) Dij를 식(10)으로; 결과 Hb2는 ap×ap, 행/열 가중치 a.
  8. 간소 인코더: T⁻¹=Tᵀ, Φ=Φ⁻¹=I로 식(2)(3)이 p1ᵀ=(ETᵀA-C)sᵀ, p2ᵀ=-TᵀAsᵀ-TᵀBp1ᵀ가 되어 역행렬 단계 제거 → 인코더 5-stage(기존 6-stage 대비).
  9. 한계: BER/최소거리 등 부호 성능 검증 전무(순수 구성·이론), gate count·throughput 없음, rate/length 미명시.
