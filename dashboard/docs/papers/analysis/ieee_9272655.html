B. 알고리즘 요약

  1. 시스템: point-to-point FSO(자유공간광) 링크, IM/DD 방식, LDPC 부호+인터리버, 블록길이 10^5 bit, 100 iteration.
  2. 문제: 대기 난류로 인한 페이딩(G-G 분포) 하에서 LDPC threshold(BER이 급락하는 SNR)를 구해야 하나 AWGN용 가우시안 근사가 성립 안 함.
  3. 모델: 조도 페이딩 h를 gamma-gamma pdf로 모델, 수신 Y=HX+Ith(열잡음 AWGN), 난류 3단계(low/moderate/high).
  4. 핵심기법: density evolution 기반 threshold 계산 — 채널 LLR pdf P(l,x)가 비대칭·비가우시안이며 수치형으로만 존재.
  5. 핵심식: CN 업데이트 tanh(u/2)=∏tanh(vq/2), mean 재귀 mu(l)=Σρj φ^-1(...) (식 16/17)로 message mean이 발산하는 최소 xth가 threshold.
  6. 확장: CSI 미지 시 LLR pdf를 shifted-gamma로 근사(η,θ,γ), threshold가 CSI known 대비 상승.
  7. 트릭: 파라미터 f0(수치 결정)를 도입해 g(x,y)≥f0면 threshold 초과로 판정, 계산량 축소.
  8. 최적화 절차: divide-and-conquer — 구간 [yi,yf] 이분탐색으로 g(x,y) vs f0 비교하며 threshold 수렴.
  9. 결과: regular(3,6) 부호 threshold가 AWGN 1.16 dB 대비 high 난류 8.10 dB, CSI 미지 시 12.48 dB; MATLAB 시뮬로 검증.
  10. 한계: 순수 threshold 이론, HW 미설계, FSO 채널 특화, EXIT/graphical 검증만.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
BP/CN tanh 업데이트(sum-product)대응 없음Prime ECC는 min-sum 근사 사용, full-tanh Sum-Product는 미대응
FSO G-G 채널 LLR pdf대응 없음Prime ECC 채널은 AWGN/RBER/fixed로 FSO 난류 채널 무관
density-evolution threshold 계산대응 없음부호 threshold 이론일 뿐 디코더/HW 이식 요소 없음

적용 가치: 낮음 — FSO 광통신 특화 threshold 이론이라 NAND binary QC-LDPC 디코더/부호설계에 떼어 쓸 요소가 없음.
