B. 알고리즘 요약

  1. 시스템: 8PSK 변조, AWGN(협대역 가우시안) 채널, R=1/2·N=2048 QC-LDPC 부호, 최대 20 iteration.
  2. 문제: 고정밀 부동소수 sum-product는 HW 구현이 어려움 — 정수연산 min-sum으로 대체하되 초기 LLR 양자화가 필요.
  3. 모델: min-sum은 LLR 측도 sum-product의 CN 갱신을 u_ij = min|v_ik| · ∏ sgn(v_ik)(식5)로 근사, 보정계수 K=0.8로 VN 메시지 보정(식7, tanh 곡선을 기울기 0.8 직선으로 근사).
  4. 핵심기법: 8PSK 수신 위상 θR에 대한 초기메시지 u1=f(θR)가 π/8≤θR<9π/8 구간에서 선형임을 이용, 균일양자화로 룩업테이블화.
  5. 핵심식: Δθ = π/510 = 0.00616(식9) — 9비트(≤512레벨) 균일 스텝. u1 = round((θR-5π/8)/Δθ + 0.5)(식10).
  6. 확장: u3 = f(θR+π/2), u2는 주기 π로 구간 축소해 동일 방식 양자화; 심볼당 3비트 u_{3j-2}, u_{3j-1}, u_{3j}를 테이블로 직접 정수화(식11~13).
  7. 구현디테일: 초기메시지를 정수화하면 식(2)(5)에 의해 VN/CN 메시지도 정수 유지 — MMSE 기준 없이 반올림만으로 고정길이 정수연산.
  8. 학습/최적화: 없음 (해석적 테이블 설계).
  9. 결과: 9비트 양자화 min-sum이 float LLR sum-product 대비 약 0.57dB 열화, 디코딩 속도는 1.2~2dB 구간에서 약 9.5배 빠름(테이블 룩업 1회).
  10. 한계: 8PSK 변조 채널 특화 초기메시지 양자화, HW 미설계, gatecount/throughput 미제시, 정정능력 개선 아님.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| 초기 LLR 균일양자화 테이블(8PSK θR→정수) | channel.cpp Set_LLR_Th(), Set_R_Offset() | 개념적 유사(LLR 양자화)이나 8PSK 위상 종속이라 NAND read 양자화와 직접 대응 안 됨 |
| min-sum CN 갱신 + K=0.8 보정 | decoder.cpp CNU_Update_New_Mag(), C2V_Cal_New_Sgn() | Prime ECC가 이미 min-sum 보유 — 중복 기여 |
| iteration별/정수 양자화 | ecc_data.h PARAM_LLR, decoder.cpp Get_VNU_Table_Idx() | Prime ECC가 이미 적응형 LLR 테이블 보유 — 중복 |

적용 가치: 낮음 — min-sum과 LLR 양자화는 Prime ECC가 이미 보유하고, 이 논문의 핵심(8PSK 위상→초기 LLR 매핑)은 변조 특화라 NAND binary LDPC에 이식할 신규 요소가 없다.
