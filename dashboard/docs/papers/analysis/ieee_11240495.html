B. 알고리즘 요약

  1. 대상은 SC-LDPC(L,R,N,w) 앙상블의 windowed decoding(WD), 채널은 이진소거채널(BEC, 소거확률 ϵ); window size W, 윈도우당 반복수 T가 핵심 파라미터.
  2. 문제: WD가 성능-복잡도-지연을 절충하는 것으로 알려져 있으나, 윈도우당 반복수 T를 이론적으로 어떻게 설정해야 하는지에 대한 포괄적 결과가 없었음.
  3. 핵심 가정: 무한 길이 점근적(asymptotic) LDPC 앙상블에서 density evolution(DE)로 평균 오류확률을 추적, threshold saturation 현상(BP 임계값이 MAP 임계값에 근접) 전제.
  4. 핵심 기법: WD 하에서 위치 z의 오류확률이 T회 반복 후 위치 z-1의 초기값과 같아지는 파동형(wave-like) 전파를 증명(식 9, x_z^{(c+1,t)} ≥ x_z^{(c,t)} = x_z^{(c+1,t)}).
  5. 핵심 식: 전파속도 v=1/T의 상한을 potential function U(x;ϵ)(식 5)의 차분으로 표현한 정리 1(v ≤ A1, 식 11)과 DE를 돌리지 않고도 계산 가능한 정리 2의 상한(v ≤ wα·U(1;ϵ)/B1, 식 12).
  6. 확장: window 크기 W를 무한대로 보낼 때의 단순화된 상한(식 14, B2)도 제시.
  7. 부수 디테일: 증명에 Jensen 부등식, 평균값 정리, 삼각형 면적 근사(potential function의 2차 도함수 상한 D) 등 순수 수학적 기법 사용.
  8. 학습/최적화 절차 없음 — 전적으로 이론적 유도와 density evolution 수치 시뮬레이션(비 HW/비 실측)만 수행.
  9. 결과: SC-LDPC(x3,x6,N,w=4) 등 예시에서 전파속도 v가 채널 파라미터 ϵ 증가에 따라 감소, MAP 임계값에서 0이 됨을 확인; window 크기 12→18일 때 v가 0.11→0.1429로 증가(포화).
  10. 한계: BEC·점근적 앙상블 가정(유한길이·AWGN/실채널 미검증), HW 설계·gatecount·throughput 전혀 없음, 결론에서도 "향후 degree distribution 최적화 연구"를 제안하는 순수 이론 단계.
