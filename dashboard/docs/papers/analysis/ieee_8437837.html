B. 알고리즘 요약

  1. 대상: 랜덤 variable-regular/irregular binary LDPC 앙상블(degree 분포 λ(x),ρ(x)), 특정 부호·rate·length 없음(앙상블 점근).
  2. 문제: error-floor 유발 구조(TS/ABS/SS)의 개수 세기는 NP-hard, 기존 앙상블 점근 결과([7][8][9])는 유도가 번잡하고 클래스 단위·특정 TS 유형에 한정.
  3. 모델: a,b가 n에 무관한 상수인 local structure에 집중(실무상 최악 트래핑셋 크기는 블록길이에 안 커질 수 있음), configuration/perfect-matching 랜덤 그래프 모델.
  4. 핵심 정리(Theorem 1): 상수 변수노드로 유도된 부분구조 S의 기대 개수 E(X_S)=Θ(n^{|V(S)|-|E(S)|}), |V(S)|,|E(S)|는 S의 노드·에지 수.
  5. 의미: CS·M_{|E|}(η)/M_0(η) ∼ CS/η^{|E(S)|} 근사와 CS의 상·하한(∆^{2|E(S)|}·n^{|V(S)|} 등)으로 지수를 노드-에지 차로 확정.
  6. 사이클 연결(Lemma 1, Corollary 1): 연결그래프 S의 사이클 수가 0/1/≥2이면 |V|-|E|가 양/0/음 → 기대 개수 ∞/양의 상수/0로 수렴.
  7. 유형별 적용: ETS·LETS에서 |V(S)|-|E(S)|=a+(b-a·dv)/2(Prop 1) → E(N)=Θ(n^{a+(b-a·dv)/2}), b/a와 dv-2 비교로 거동 결정(Theorem 2/3).
  8. 세분화 통찰: 같은 (a,b) 클래스라도 비동형 구조별로 거동이 다를 수 있음(regular=consistent, irregular=inconsistent), LETS는 b/a=dv-2인 단일 사이클(길이 2a) 클래스만 비영(Corollary 2).
  9. 결과: 단일 사이클 구조의 평균 개수는 사이클 개수 근사식(7)로 추정, 짧은 블록에도 정확(수치결과는 [13]).
  10. 한계: 순수 앙상블 평균 이론(검증수준 이론), 특정 부호·디코더·양자화·HW 없음, 특정 코드 error-floor 개선 처방 아님.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
앙상블 트래핑셋 평균 개수 점근식대응 없음특정 부호가 아닌 앙상블 이론, 런타임 디코더/인코더 코드 대응 없음
트래핑셋/error-floor 구조 통찰대응 없음error-floor 대책 알고리즘이 아니라 개수 점근 분석뿐

적용 가치: 낮음 — 랜덤 LDPC 앙상블의 평균 개수 점근 이론이라 특정 QC-LDPC를 쓰는 Prime ECC의 부호설계·디코더·HW에 떼어 쓸 알고리즘이 없음.
