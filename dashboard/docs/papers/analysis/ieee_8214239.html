B. 알고리즘 요약

  1. 대상은 Aslam et al.[4]의 edge-based dynamic scheduling(BP 복호의 e-Flooding/edge-LBP)로, 실시간 신뢰도로 갱신할 edge를 선택하는 저복잡도 스케줄이다.
  2. 문제: 갱신 edge 선택을 좌우하는 check-node 신뢰도 임계값 T가 원논문에서 최적이 아니라는 점을 재현 중 발견했다.
  3. check node를 parity 불만족(Type-1), parity 만족이면서 Type-2/Type-3로 3분류하고, Type-2·Type-3 선택 확률식 p(Type-2), p(Type-3)을 평균 check degree d̄c와 e(신뢰도 관련량)로 표현한다(식 (1),(2)).
  4. 원논문은 p(Type-2)=p(Type-3)로 두어 T를 구했으나(식 (4)), 이는 최적이 아니다.
  5. 핵심: 두 확률의 비 γ = p(Type-2)/p(Type-3)를 새로 도입한다(식 (5)).
  6. 일반화된 임계값 T = ln( ... 1/d̄c ... ) 를 γ의 함수로 재유도한다(식 (6)); γ=1이 원논문 식 (4)의 특수해임을 보인다.
  7. γ<1 조건에서 더 좋은 T가 얻어짐을 주장한다.
  8. 검증: regular LDPC (1008,504) PEG 구성(dc=6)과 irregular (2112,1056) IEEE 802.16e 부호, 최대 iteration 100으로 시뮬레이션.
  9. 결과: (1008,504)는 γ≤10⁻¹에서 성능 안정, γ=10⁻¹이 γ=1 대비 약 2dB 이득(BER=10⁻⁵); (2112,1056)은 γ=10⁻³이 최적으로 약 2.1dB 이득. 총 갱신 edge수 Esum=Ia×Ea는 작은 γ에서도 γ=1과 비슷(복잡도 유사).
  10. 한계: HW 미설계, 시뮬만, min-sum 아닌 SPA 기반, γ 최적값이 부호마다 달라 별도 튜닝 필요.
