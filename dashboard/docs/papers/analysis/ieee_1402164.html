B. 알고리즘 요약

  1. 대상: DMS U={0..Q-1}(Q=2^m)의 fixed-rate near-lossless source compression, 선형 syndrome 인코더 s=Hu(rate R=(n-k)/n·m), 채널통계 미지의 universal 복호.
  2. 문제: Csiszár 최소엔트로피 복호 û=argmin H(Pu)는 ML과 동일 error exponent를 얻지만 일반적으로 NP-hard라 이론에만 존재.
  3. 모델: coset Co(H,s)={u:Hu=s} 위에서 empirical type Pu의 엔트로피 최소화; 채널/소스 통계 사전지식 불필요(universal).
  4. 핵심 기법 1: 이산문제를 indicator I_ik로 연속화해 polytope B_{i,p} 위 strictly concave 함수(엔트로피) 최소화로 변환 → 최적해가 vertex에 존재.
  5. 핵심 식: method of types |P_n(U)| ≤ (n+1)^|U| — distinct type 수가 n에 다항. 이것이 지수적 coset을 다항 복잡도로 다루는 열쇠.
  6. 핵심 기법 2: B_{i,p}를 type 공간 B_p로 polytope projection(vertex/halfspace 수에 선형인 최신 알고리즘) 후 다항 개 vertex만 순회, ML-certificate 유사 ME-certificate 확보.
  7. 구현 디테일: LDPC(low-density H)면 Feldman식 relaxed polytope B̃_{i,p}=∩_j B̃^j로 check당 Q^{δ_j-1} 구성만 표현 → H(B̃_{i,p})=O(n), 투영 vertex도 다항(Lemma 3.1).
  8. 최적화: binary case는 concave min을 LP-MIN/LP-MAX 두 LP로 환원, expander code로 min-max distance(min(w_H(u),w_H(1⊕u))) 양호하게 설계 → provably good error exponent; bit-flipping 반복 알고리즘으로도 대체 가능.
  9. 결과: LDPC 상 다항복잡도 근사복호 구성, all-ones가 coset에 있으면 오류확률 1/2가 됨을 min-max distance 0으로 포착(부호설계 지침).
  10. 한계: HW 미설계·시뮬 없음(순수 이론), source-coding/Slepian-Wolf가 주무대이며 채널통계 미지가 전제, non-binary F_2^m 중심.
