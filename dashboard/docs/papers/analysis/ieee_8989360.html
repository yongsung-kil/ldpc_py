총평: windowed decoding 속도 개선용 SC-LDPC 구성법으로 흥미롭지만 SC 구조 자체가 Prime ECC(고정 binary block QC-LDPC)와 이질적이라 이식성 하.

B. 알고리즘 요약

  1. 시스템: random (dv, dc, ν, L, M) SC-LDPC ensemble, rate ≈ 1/2, dc=2dv, SP당 M=8000 VN, L=100.
  2. 문제: SC-LDPC의 threshold saturation은 w→∞, L→∞를 요구해 실용적이지 않고, windowed decoding(WD) 복잡도·rate-loss가 smoothing w에 거의 선형 증가.
  3. 모델: BEC density evolution으로 asymptotic 분석, smoothing 분포 ν=(ν0,...,ν_{w-1}) (Σνi=1)로 각 edge가 인접 w개 SP에 non-uniform 연결.
  4. 핵심기법1: non-uniform coupling ν 최적화로 decoding wave 전파속도 v(ε)를 최대화 → WD 복잡도 O(W_D·I·L·M·dv) 감소, degree는 regular 유지.
  5. 핵심식: DE 식 (1)로 SP별 erasure 확률 프로파일 갱신, wave 속도 v≈D/T_D (식 2)로 추정.
  6. 핵심기법2: cost function C(1)=T̄20 - WP(T̄20)·L/2 (또는 저비용 대체 C(2)=T̃10 기반)를 최소화 → wave 속도 최대화.
  7. 구현디테일: w>3에서 탐색공간이 커 differential evolution(NP=100D, 1000 iteration)으로 ν 탐색, C(2)는 DE 1회 실행으로 근사.
  8. 최적화: DE로 유효 ν(수렴 보장) 벡터 진화, w=2는 line-search로 α 탐색.
  9. 결과: w=8에서 uniform 대비 약 0.1 dB 이득(capacity 근접), 최적 ν는 첫 항 ν1과 마지막 항 ν_w만 지배적이고 나머지는 무시가능.
  10. 한계: HW 미설계, BI-AWGN 시뮬만, w>2에서 오히려 rate-loss 증가, optical 등 고속통신 WD 가정.
