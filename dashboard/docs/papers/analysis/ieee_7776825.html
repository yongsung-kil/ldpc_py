B. 알고리즘 요약

  1. 대상: (dv,dc)-regular(대표 (3,6), rate 0.5) 및 irregular LDPC, 채널은 BEC/BSC, 메시지 알파벳 {±1,?}.
  2. 문제: 나노스케일 제조 공정변이로 인해 디코더 회로의 배선 자체가 누락(영구=단선, 일시적=타이밍 오류)될 수 있는데, 기존 결함내성 이론은 배선은 완벽하다 가정하고 연산소자 오류만 다룸.
  3. 모델: 각 edge를 확률 α로 제거(영구=복호 전 1회, 일시적=매 iteration), 끊긴 배선의 floating 전압은 구분 가능하므로 **erasure ?**로 모델링.
  4. 핵심기법1(DE 확장): correctly-wired DE(Richardson-Urbanke)를 missing connection에 확장, concentration(Azuma)·cycle-free 수렴 정리로 정당화. 영구/일시적 결함의 P̄e가 girth 증가 시 점근적으로 동일함을 증명(Thm.4).
  5. 핵심식(peeling/BEC): x_{l+1}=ελ(α+(1-α)(1-ρ[(1-x_l)(1-α)])) — 배선존재확률 (1-α)가 erasure 전파식에 곱해져 들어감.
  6. 핵심기법2(Gallager A/B on BSC): ? 입력 시 CN은 ? 출력, VN은 majority(b*=⌈(dv+1)/2⌉)로 결정하도록 자연스럽게 수정, degree-1 노드 tie-breaker로 채널값 우선.
  7. 유용성 개념: P̄e(∞)<ε이면 디코더가 유용. missing connection 디코더는 오류를 전파하지 않아 채널보다 항상 나쁘지 않음(연산노이즈 디코더와 대조).
  8. 주요 발견: 임계 ε*(η,α)는 α 증가에 따라 매끄럽게 저하(robust). Gallager B에선 오히려 임계가 일시 상승하는 stochastic facilitation 관측(구조적 오류가 성능에 도움).
  9. 결과: 유한길이(n=498,1002,1998, α=0.02) 시뮬이 점근 DE와 부합, error-tolerant 제조 수율 분석에서 α까지 허용해 유효수율을 선형 증가(waste 절감).
  10. 한계: HW 미설계, hard-decision(peeling/Gallager A·B) 전용 이론, Pe를 0으로 못 만들고 η-reliable에 그침, 성능개선이 아닌 결함내성 특성화.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| peeling/Gallager A·B 하드결정 복호 | decoder.cpp LDPC_Decoder() | 낮음: Prime은 min-sum(soft) 기반, Gallager류 하드결정 알고리즘 미사용 |
| missing connection→erasure 모델·DE 분석 | 대응 없음 | 배선결함 내성 이론일 뿐, Prime의 어느 모듈도 배선결함/erasure를 모델링하지 않음 |
| 결함내성 수율 분석 | 대응 없음 | 제조 수율 관점, HW/시뮬 모델과 무관 |

적용 가치: 낮음 — 나노스케일 배선 결함 내성을 다루는 정보이론 논문으로, min-sum·binary QC-LDPC 기반 Prime ECC와 디코더 알고리즘(하드결정 Gallager/peeling), 목적(성능개선이 아닌 결함내성/수율)이 모두 달라 이식할 요소가 없다.
