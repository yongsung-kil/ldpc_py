B. 알고리즘 요약

  1. 시스템: 직렬 입력→deserializer→B프레임 FIFO 버퍼→단일 LDPC 복호기 구조. 예제 부호는 CCSDS AR4JA protograph LDPC (n=8192, k=4096), rate 1/2, AWGN, Eb/N0=1.35dB.
  2. 문제: 고정 iteration Imax 복호기는 속도가 가장 어려운 프레임에 의해 결정되나, variable-iteration 복호기는 codeword 조건 만족 시 조기종료해 평균 Iavg(예 22.5)만 쓴다.
  3. 모델: 프레임 도착이 결정적(Iarr 간격), 서비스시간이 iteration 분포 P(I)인 D/G/1 큐로 모델링. 시간 단위는 iteration으로 측정해 기술의존성 제거.
  4. 핵심 기법: Dvp(Imax,B) = preemptive buffer control — 버퍼가 차면 새 프레임을 버리지 않고 현재 복호 중인(logjam) 프레임을 축출해 공간 확보.
  5. 핵심 식: Ii+ 랜덤워크 Ii+1+ = min[max(Iarr, Ii+ + Iarr - Ii), (B+1)Iarr] — 흡수벽 Iarr와 (B+1)Iarr 사이. 모든 프레임이 최소 Iarr iteration 보장.
  6. 단조성: 버퍼를 1프레임 늘리면 상단 흡수벽만 (B+2)Iarr로 상승 → 모든 프레임이 이전보다 같거나 많은 iteration을 (필요 시) 받음 Ii+(B) ≤ Ii+(B+1) ≤ Ii+(B)+Iarr.
  7. 구현 디테일: 실전은 무한 iteration 대신 Imax=200 캡을 둔 Dvp(200,B) 사용, 최적 캡은 BIarr와 (B+1)Iarr 중간 부근.
  8. 최적화: P(I) tail을 실험적으로 측정(10^8 codeword)하고 랜덤워크를 수치적으로 정상분포까지 전개해 WER 계산.
  9. 결과: B=1이면 무버퍼 대비 약 2배 빠른 입력율에서 동일 WER, B=2~3이면 near-optimal, Iarr ≥ Iavg(B+2)/(B+1)에서 B+1배 처리율. rate 0.5~0.875에서도 유사.
  10. 한계: 부호·복호 알고리즘 자체 개선이 아니라 조기종료 분포를 활용한 처리율·버퍼 시스템 설계이며, 상수레이트 스트리밍 채널을 가정.
