총평: BEC 지우기 채널 전용 guessing 개선으로 NAND soft-decision LDPC와 채널 모델이 달라 이식 부적합.

B. 알고리즘 요약

  1. 대상: regular (3,6) half-rate LDPC (rate=0.5), 길이 1000, 2000, BEC(이진 지우기 채널)에서 복호.
  2. 문제: BP는 짧은 사이클/유한 길이 때문에 이론 threshold 0.429에 못 미쳐 지운 비트를 다 못 푼다 (stuck).
  3. 채널 모델: BEC — 비트가 확률 ε로 지워지고 나머지는 오류 없이 수신 (연판정 LLR 개념 없음).
  4. 핵심 기법: BP가 멈추면 변수노드 값을 추측하는 기존 guessing 대신, 체크노드 집합 {c0..ck}를 선택해 그에 연결된 변수노드에 가정을 건다.
  5. 핵심 식: N' = Σ max(b_ij), 경우의 수 2^(N'-k) — 독립 선형방정식 k개가 해공간을 2^-k로 줄이므로 가정 경우의 수가 절반씩 감소.
  6. 의미: 체크노드 하나를 가정에 포함시킬 때마다 이진 방정식 1개가 추가되어 탐색 공간이 반감 (degree-2 체크노드 예시 Table 1).
  7. 확장: 최대 경우의 수를 2로 설정 (x=1 상당)해 복잡도 억제.
  8. 학습/최적화: 없음 (구조적 방정식 선택만).
  9. 결과: 길이 2000, 채널 threshold 0.43에서 BP 후 잔여 지우기 확률 0.7 → 제안 기법 후 0.23; 실제 threshold를 0.43으로 개선(이론 0.429 상회 서술).
  10. 한계: BEC 전용, HW 미설계, 시뮬만, 복잡도/gate/throughput 수치 없음.
