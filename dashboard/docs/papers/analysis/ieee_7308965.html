B. 알고리즘 요약

  1. 문제: unreliable HW로 만든 메모리에서, 저장된 LDPC codeword를 주기적으로 refresh 디코딩해 열화를 상쇄하는 Taylor-Kuznetsov 메모리 전체 신뢰성을 이론 분석.
  2. 채널/열화 모델: 시각 t→t+1 사이 메모리 열화를 BSC(α)로 모델링(대칭·memoryless), regular LDPC (dv=3, dc=4/5/6) 사용.
  3. Refresh 디코더: 저복잡도 faulty One-Step Majority Logic(OS-MAJ) — CN은 XOR sum f⊕, VN은 majority voting fmaj. 매 구간 1회만 수행.
  4. Faulty 모델: f̃⊕ = f⊕ ⊕ e⊕ (e⊕~Bern(p⊕)), f̃maj = fmaj ⊕ emaj (emaj~Bern(pmaj)). 기존 [1,2,5]와 달리 majority 게이트도 faulty로 확장.
  5. 디코더 오류확률: all-zero 가정하에 noisy CN 확률 p̃γ = 1/2 - 1/2(1-2p⊕)(1-α)^(dc-1), 최종 Pe,ν(α)=pη(1-pmaj)+(1-pη)pmaj.
  6. 핵심 재귀식: 열화수열 βν(t)을 βν(1)=α, βν(t)=(1-α)Pe,ν(βν(t-1))+α(1-Pe,ν(βν(t-1)))로 정의 (BSC(α)∘BSC(Pe) 연쇄).
  7. 수열 성질(Prop 2): Pe,ν가 α·p⊕·pmaj에 단조증가 → βν(t)도 t·α·노이즈에 증가. (단, noisy Min-Sum/PGDBF는 노이즈가 성능을 개선할 수 있어 이 가정 불성립.)
  8. Fixed-point 분석: β=(1-α)Pe(β)+α(1-Pe(β)) 해 = Pe(β)곡선과 직선 y=(β-α)/(1-2α)의 교점. β=1/2은 항상 (나쁜) fixed point.
  9. 신뢰성/문턱: bounded redundancy + stability(1/2 외 fixed point 존재) + admissibility(max B ≤ Gallager B 문턱)로 신뢰성 정의, degradation threshold ᾱ를 정의해 reliability region 도출.
  10. 결과/한계: p⊕/pmaj 커질수록 region 축소, p⊕=pmaj=10^-2면 어떤 α에도 신뢰불가. k=400 Monte-Carlo(T=200)로 검증. HW 미설계·이론 분석, refresh는 Gallager A/B로 확장 가능하다고만 언급.

C. Prime ECC 관련 모듈 핀포인트

|---|---|---|
| OS-MAJ (majority-logic) refresh 디코더 | 대응 없음 | 우리는 min-sum message passing, majority-logic 디코더는 미보유·이질적 |
| faulty gate(BSC) 열화 모델 / 신뢰성 문턱 | 대응 없음 | HW fault-tolerance 이론, NAND soft-read/RBER 채널 모델과 목적 상이 |
| regular LDPC (dv=3, dc=4~6) | ecc_top.cpp Load_PCM() | 저rate regular 코드로 고rate QC-LDPC와 구조 불일치 |
