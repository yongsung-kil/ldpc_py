B. 알고리즘 요약

  1. 대상은 (3,3s)-regular binary LDPC로, rate (s-1)/s (s=2~6) 고rate·짧은 길이(34~1788 bit) 부호.
  2. 문제: girth가 작으면 짧은 사이클로 message-passing 복호 성능이 나빠짐 → girth 6/8을 보장하는 쉬운 구성법 필요.
  3. 모델: Z_n 위 어파인 순열 F: r ↦ a_F·r + b_F mod n (a_F는 n과 서로소)로 n×n 어파인 순열행렬 P(F) 정의.
  4. 각 블록 X_i = P(F_i) + P(G_i) + P(H_i) (세 순열의 합)은 행·열 무게 3인 (3,3)-regular 블록.
  5. PCM은 Z = [X_1 X_2 ... X_s]^T로 쌓아 (3,3s)-regular PCM 완성 → 코드 C.
  6. 사이클 조건(Prop II.1): 그래프의 2m-cycle은 {F,G,H}의 swapping sequence 존재와 동치, 합동식 Σ(b_{2k+1}-b_{2k})=0 mod n로 판정.
  7. girth 6: n=p 소수, F=identity, a_G=a_H=1로 두고 b_G,b_H를 귀납적으로 배제집합 밖에서 선택.
  8. girth 8: n=pq (p 소수, q=3), a_F=a_G=a_H≡1 mod p, mod 3 조건 부과로 girth 8 달성.
  9. Prop II.2: p 소수일 때 m·x - k·y - (m-k)·z ≢ 0 mod p (x,y,z는 b들의 치환)이면 2M 이하 사이클은 balanced sequence에서만 발생 → 작은 사이클 없음 보증.
  10. 한계: 구성·girth 이론뿐, 복호 알고리즘/BER 시뮬/HW 설계/양자화 전무 (2페이지 ISIT 요약).

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
어파인 순열행렬 기반 PCM 구성ecc_top.cpp Load_PCM()우리는 QC-LDPC(circulant shift) 고정, 어파인 순열 구성은 다른 계열이라 재검증 부담 큼
girth 6/8 보증 조건대응 없음우리 부호는 이미 특정 H-matrix 고정, 구성법 교체 대상 아님
복호/양자화/HW대응 없음논문에 복호·HW 요소 자체 없음

적용 가치: 낮음 — 순수 girth 최적화 구성 이론이고 복호·성능·HW가 전무하며, 우리 코드의 QC-LDPC circulant 구조와도 계열이 달라 이식 실익이 없다.
