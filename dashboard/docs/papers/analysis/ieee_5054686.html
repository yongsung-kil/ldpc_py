B. 알고리즘 요약

  1. 이진 LDPC 부호(길이 1000, 코드율 0.05~0.5)를 BPSK 변조 후 AWGN 채널(Y = X + Z, Z ~ N(0, σ_t^2))로 전송하는 상황을 가정, σ_t^2가 시간에 따라 변화(time-varying).
  2. 표준 BP는 노이즈 파워 σ^2를 정확히 알아야 최선의 성능을 내는데, 미지/시변 채널에서는 SNR mismatch(특히 과소추정 시 취약)로 성능이 저하되는 문제를 해결하고자 함.
  3. 채널모델은 AWGN, 노이즈 분산이 시간에 따라 선형 증가하는 시나리오(σ: 0.5→4, step 0.0035)로 실험.
  4. 핵심 기법은 factor graph를 3개 영역으로 분할하여 Region 1(노이즈 파워 변수 σ_i 노드)에는 파티클 필터 기반 BP, Region 2/3(코드 비트 x_i 노드)에는 표준 BP를 적용하는 하이브리드 구조.
  5. Region 1의 각 변수노드는 N_p개 파티클 {σ_i^(k)}로 표현되며, 매 반복마다 (2) importance weight 계산(=BP belief) → (3) systematic resampling(누적합 C(k)와 균등수 U(k) 비교로 파티클 복제/제거) → (4) random walk(N(0, σ_r^2) 가우시안 잡음 추가로 파티클 분산) → (5) 가중치 균등화(1/N_p)의 사이클을 반복.
  6. 확장 기법으로 factor node 갱신식 f_a(σ_i^(k+1), σ_i^(k)) = e^{-(σ_i^(k+1)-σ_i^(k))^2/λ}를 정의해 인접 노이즈 파티클 간 정보를 전달(식 (8)).
  7. 부수 트릭으로 Region 3의 factor node는 초기 메시지를 가우시안 우도 f(x_i) = (1/√(2πσ̂)) e^{-(y_i-x_i)^2/2σ̂^2}로 설정, 이후 각 파티클 값 σ_a^k로 갱신(식 (9)(10)).
  8. 별도 학습 절차 없음(파티클 필터 자체가 순차 몬테카를로 추정 절차이며, 실험 파라미터는 파티클수 20, iteration 400, σ_r^2=0.005, λ=0.01로 설정).
  9. 결과: 시변 AWGN에서 노이즈 파워를 실시간에 가깝게 정확히 추정(Fig.6, Fig.7), regular/irregular LDPC 모두에서 표준 BP 대비 error probability가 코드율 0.05~0.5 전 구간에서 개선(Fig.8, Fig.9). 구체적 iteration 감소/gate count 수치는 본문에 없음.
  10. 한계: 순수 소프트웨어 시뮬레이션(부동소수점 sum-product + 파티클 필터로 연산량 큼), HW 설계·복잡도·throughput 언급 전무, 정적(non-time-varying) NAND read 채널 특성과의 정합성 불명.

C. Prime ECC 관련 모듈 핀포인트

BP(sum-product) 기반 디코딩 반복 루프decoder.cpp LDPC_Decoder()Prime ECC는 min-sum 기반이라 sum-product 자체는 이미 다른 근사로 대체되어 있어 직접 대응 약함
노이즈 파워(σ²) 실시간 추정 및 LLR 갱신channel.cpp Set_R_Offset(), Set_LLR_Th()NAND read 채널의 soft-info threshold 적응 개념과 유사하나, 파티클 필터의 시변 채널 추정은 NAND의 read-retry/adaptive read 방식과는 메커니즘이 다름
irregular LDPC 부호 profile(변수노드 degree 분포)대응 없음Prime ECC는 고정 QC-LDPC(N_b=129, VN degree 17) 구조로 irregular 부호 설계 자체는 별도 이슈

적용 가치: 낮음 — sum-product+particle filter 조합은 연산 오버헤드가 크고 HW 미설계이며, Prime ECC의 min-sum 기반 고정 QC-LDPC 구조와 정합성이 낮음.
