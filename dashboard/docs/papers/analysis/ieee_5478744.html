총평: LDPC convolutional code의 girth/cycle 해석을 위한 순수 이론 도구로, block QC-LDPC 기반 NAND ECC에 직접 이식할 대상이 아니다.

B. 알고리즘 요약

  1. 대상은 circulant(순환) 행렬 기반 QC-LDPC block code에서 파생된 시불변 LDPC convolutional code(LDPCcc), rate R=1-j/k (예제 1/3), 규칙적 (j,k) 부호.
  2. 문제: LDPCcc의 girth/cycle 구조가 복호 성능을 좌우하나, 시간영역 semi-infinite 행렬에서 직접 세기 어렵다.
  3. 부호구성: GF(m)(m 소수)에서 두 원소 a,b의 곱셈적 위수로 P_{s,t}=b^s a^t mod m 행렬을 만들고 각 성분을 shifted identity로 치환해 H_BC 생성.
  4. LDPCcc는 다항식 행렬 H(D)로 표현 — 각 monomial D^l이 circulant의 좌측 shift 위치 l을 인코딩(monomial matrix).
  5. 핵심 아이디어: 시간영역 syndrome former H^T의 cycle을 다항식 행렬에서 "닫힌 경로"로 표현.
  6. 경로는 수평 이동(delay 0)과 수직 이동(delay = s_kl - s_il, 부호 있음)의 교대로 구성.
  7. cycle 판정식: 경로 상 모든 delay 합 Σ Δ(s,s')=0이면 길이 2L의 cycle (필요충분).
  8. 공통인자 D^l을 열에서 제거하면 syndrome former memory m_s가 줄어 HW 구현에 유리(예: m_s=5→3).
  9. Algorithm 1: 각 monomial을 시작점으로 재귀적으로 두 edge(수평+수직)씩 확장하며 APS(누적 power 합)로 cycle을 세는 greedy counter, 길이 12까지 실용적.
  10. 결과: prime m별 6/8/10/12-cycle 개수 표(Table I) — m_s 증가 시 short cycle 수 감소, girth 개선. HW/시뮬 없음(순수 이론).
