총평: 소수체 기반 대수적 QC-LDPC 구성법으로 error-floor 억제와 빠른 수렴을 보이는 code-design 논문이며, H-matrix 구조가 Prime ECC와 다르지만 부호 설계 아이디어(4-cycle-free 대수적 구성)는 참고할 만함.

B. 알고리즘 요약 (10줄 내외)

  1. 대상은 regular binary QC-LDPC 코드(예: (16213,14124) rate 0.8712, (31903,29814) rate 0.9345, (2407,2078) rate 0.8633, (2656,1328) rate 0.5, (4380,4091) rate 0.9340, (5256,2629) rate 0.5002), AWGN 채널, BPSK, decoding은 SPA(Sum-Product) 최대 50 iteration.
  2. 기존 base matrix + dispersing/masking 구성법은 4-cycle-free를 보장하지만 무작위(MacKay)식 구성 대비 error-floor 발생 문제를 겪는데, 본 논문은 이를 개선할 대수적 구성법 2종을 제안.
  3. 핵심 가정: 소수체 GF(p)의 곱셈군은 순환군(cyclic)이며, 원소 i를 p-tuple location-vector v(i)(cyclic shift)로 임베딩해 additive p-fold matrix dispersion으로 p×p CPM(circulant permutation matrix)을 얻음.
  4. 구성법1(§II): 순환군의 생성원(generator) 집합 {l1,...,l_K}(K=(p-1)∏(1-1/p_i), Euler 공식)로 (K+1)×(K+1) base matrix W(1)=[l_i l_j mod p]를 만들고, W(1)이 additive row constraint 1·2를 만족함을 증명(Lemma 1)해 RC-constraint(4-cycle-free) 보장.
  5. W(1)을 additive p-fold dispersion하여 H(1) 배열 생성 후 γ×ρ 부분배열을 취하면 length ρp, rate ≥(ρ-γ)/ρ인 QC-LDPC 코드; 최소거리 ≥γ+1(γ 홀수) 또는 γ+2(짝수).
  6. 구성법2(§III): 두 생성원 l_μ, l_ν의 곱으로 p×p base matrix W(2)=[l_μi·l_νj mod p]를 구성(Lemma 2로 constraint 증명), girth ≥6까지 보장하는 확장.
  7. masking 기법(M = Z⊗H(γ,ρ), Z는 0/1 마스킹 행렬)을 병용해 파리티체크 행렬을 더 희소화하고 rate 0.5 근처 코드도 구성 가능.
  8. 별도 학습/최적화 절차 없음(순수 대수적 구성, Euler 공식과 순환군 이론 기반).
  9. 결과: (16213,14124) rate 0.8712 코드는 BER 5×10^-7에서 MacKay 코드와 유사하나 저BER 영역서 error-floor 없이 우세; (31903,29814) rate 0.9345 코드는 BER 10^-6에서 Shannon limit 대비 0.665dB; (4380,4091)은 iteration 50→5로 줄여도 BER 10^-6서 0.36dB 열화에 그쳐 빠른 수렴 입증.
  10. 한계: 모두 소프트 SPA 디코더 시뮬레이션(하드웨어 미설계, gatecount/throughput 실측 없음)이며 부호 파라미터(rate/length)가 예제마다 달라 단일 대표값으로 확정 불가.
