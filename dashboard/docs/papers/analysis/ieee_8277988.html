총평: 2D-ISI 채널의 GBP 검출-복호 통합(turbo)을 위한 region graph 수렴 조건 이론이 핵심. SC-LDPC를 부호로 쓰지만 기여는 GBP/factor-graph 검출기 쪽이라 NAND용 binary QC-LDPC MinSum 디코더 이식성은 낮음.

B. 알고리즘 요약

  1. 시스템: N×N 이진 입력 Xi,j∈{+1,-1}이 2D-ISI 채널(주변 4방향 심볼 간섭 J, AWGN σ2)을 통과, M×N^2 패리티검사행렬 H로 부호화된 (3,6,16) SC-LDPC 사용.
  2. 문제: 2D-ISI factor graph는 짧은 사이클이 많아 BP 성능 저하, 기존 GBP 연구는 검출/복호를 분리하거나 그 사이에 hard-decision을 삽입해 최적 성능과 격차.
  3. 목표: soft-message만 주고받는 GBP 검출기+복호기 full-joint(turbo equalization) 실현.
  4. GBP 프레임워크: region graph GR, counting number c(R), 부모/자식 메시지 n_{R→P}, m_{R→C} 갱신(식 2~5), β(R)=1/(2-1/q(R)), q(R)=(1-c(R))/p(R).
  5. 핵심 발견(Theorem 2): 어떤 region R에서 β(R)<1이면 갱신식 (19) 분모에 δ-함수가 등장해 0으로 나눗셈 발생 → GBP fixed point가 존재하지 않아 full-joint 불가.
  6. 수렴 필요조건(Theorem 3): 모든 R에 대해 β(R)≥1 즉 c(R)≥1-p(R) (식 20)가 성립해야 메시지 수렴.
  7. 진단: 문헌의 대표 region graph(Shental GS1∪S2∪S3)는 β(S1)=1/2<1로 조건 위반(Example 2), 대부분 기존 region graph가 조건 불만족.
  8. 제안: region family S̃=S1∪S2 (S3 제거)로 구성하면 c(S1)=-3=1-p(S1)가 되어 조건 (20) 만족(Theorem 4).
  9. 결과: J=0.5 2D-ISI에서 제안 joint 검출-복호가 기존 분리 방식(Matcha [2]) 대비 FER 1 dB 개선, 최대 region이 S3(8 VN)→S2(5 VN)로 축소되어 연산복잡도 O(1024 N^2)→O(128 N^2)로 감소.
  10. 한계: 2D-ISI(자기기록/TDMR) 채널 전용, GBP region-graph 이론 중심, HW 미설계, region 크기 2^nV(R) 지수적 연산.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| GBP region-graph 검출-복호 turbo | 대응 없음 | Prime ECC는 BP(MinSum) 복호 단독, GBP/turbo equalization 미보유 |
| 2D-ISI 채널 모델 | 대응 없음 | channel.cpp는 AWGN/RBER/fixed-error, 2D 심볼간섭 채널 아님 |
| SC-LDPC (3,6,16) 부호 | 대응 없음 | 고정 binary QC-LDPC(ecc_top.cpp Load_PCM)와 부호 구조 상이 |
| MinSum CN/VN 연산 | decoder.cpp CNU_Update_New_Mag() 등 | 논문은 GBP full-marginal 연산이라 min-sum과 알고리즘 계열 다름 |

적용 가치: 낮음 — 2D-ISI 검출-복호 통합용 GBP region-graph 수렴 이론으로, NAND용 binary QC-LDPC MinSum 디코더·AWGN/soft-read 채널과 알고리즘·채널·부호 구조가 모두 달라 이식할 요소가 없음.
