총평: QAM BICM의 sub-channel 신뢰도 편차를 겨냥한 bit-mapping 설계라 NAND 변조 없는 binary QC-LDPC에 메커니즘이 직결되지 않으며, "불신 노드에 신뢰 엣지 보장" 발상 정도만 페이지 UEP로 재해석 가능한 참고 가치.

B. 알고리즘 요약

  1. 시스템은 (dc,dv) regular LDPC + M-QAM(64/256) Gray labeling BICM, AWGN 채널, length N=10752 EG-LDPC(rate 1/4·1/2·2/3, dv=3, dc=4/6/9), SP 복호(최대 50 iter).
  2. 문제: 고차 QAM은 변조 레벨별 최소 유클리드 거리 차로 sub-channel별 상호정보 불균형(UEP)이 생겨, 단순 consecutive-bit(CB) 매핑이 비최적.
  3. 모델: 긴 인터리버 하에 M-ary 변조를 m=log2 M개 병렬 독립 sub-channel로 보고, 각 sub-channel 상호정보 I(b_k;y)로 신뢰도 분류.
  4. 핵심 기법: Tanner 그래프에 VN↔sub-channel을 잇는 bit-mapping graph(2층 이분그래프)를 추가하고, bit-mapping 설계를 edge growth로 정식화한 PEG 알고리즘.
  5. sub-channel을 최저 상호정보 그룹 L과 나머지 H로 나누고, L에 붙은 VN을 unreliable로 정의 — 성능은 최악 sub-channel이 지배하므로 이들에 reliable edge를 붙이는 게 설계 목표.
  6. 핵심 개념: unreliable depth profile(UDP D_k) — BFS로 각 VN에서 가장 가까운 불신 VN까지 깊이를 재 신뢰도 순위화, reliable edge 수 상한 γ=|H|·dv/(|L|·(dc-1)).
  7. L 배치: UDP 최대 VN 그룹에서 unmatched VN 수를 최소화하도록 엣지를 하나씩 추가(Algorithm 1·2).
  8. H 배치: unmatched number profile(N_k)로 unmatched 불신 VN이 많이 걸린 VN을 파악, 상호정보 큰 sub-channel을 그런 VN에 우선 연결.
  9. 결과: consecutive 대비 unmatched VN 수 대폭 감소, BER 10^-5에서 64-QAM 0.22 dB / 256-QAM 0.44 dB 개선(γ<1인 rate-2/3 64-QAM은 개선 미미).
  10. 한계: HW 미설계(시뮬만), AWGN+QAM 변조 전제, SP 복호, γ<1이면 효과 제한.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
VN↔sub-channel bit-mapping / UEP 배치대응 없음Prime ECC는 변조 없는 NAND binary; QAM sub-channel 계층 자체가 부재
SP 반복복호 extrinsic 개선decoder.cpp LDPC_Decoder(), C2V_Cal()우리는 min-sum(SP tanh 아님); reliable-edge 발상은 원거리 유사이나 직접 대응 아님
sub-channel LLR/신뢰도 입력channel.cpp Set_LLR_Th(), Set_R_Offset()페이지별(MSB/CSB/LSB) UEP LLR로 개념 재해석 시 접점 가능성만 있음

적용 가치: 낮음 — QAM 변조 sub-channel의 UEP를 전제로 한 bit-mapping 설계라, 변조가 없는 NAND binary QC-LDPC min-sum 엔진에 메커니즘이 직결되지 않는다. "불신 VN에 신뢰 엣지 보장" 발상만 NAND 다중페이지 신뢰도 배치로 재해석할 여지가 있다.
