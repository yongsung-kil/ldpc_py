B. 알고리즘 요약

  1. 시스템: m×m chess-board Lm의 흑백 coloring을 cycle graph 인접행렬로 보고, incidence 행렬 H를 cycle 부호(column-weight 2) 패리티체크로 사용. rate R = 1 - m/b.
  2. 문제: 고정 girth에서 최소길이·고rate를 갖는 regular cycle 부호와 이를 확장한 column-weight-3 LDPC 부호를 결정적으로 구성하는 것.
  3. 핵심 개념: broken diagonal pair Lm(p) (main diagonal에 평행한 두 pandiagonal의 흑백 교대 배치, (0,p)부터 시작).
  4. 핵심 기법 1단: (m,t)-vector v=(v1,...,vt) (홀수 성분)로 Lm(v)=∪Lm(vi) coloring을 정의, incidence 행렬 Hm(v)가 regularity t의 cycle 부호가 됨.
  5. girth 조건(Theorem 1): 모든 {k1,k2}∩{k3,k4}=∅에 대해 (vk1+vk2)-(vk3+vk4) ∉ {0,±m}이면 g(Hm(v))=12.
  6. 확장(2단): 각 Lm(vi)에 새 점 m+i-1을 추가(Bi)해 Mm(v)를 만들면 column-weight-3, girth-6 LDPC 부호가 됨(추가 행 수 최소 t).
  7. 구현 이점: Hm(v)는 m과 v만으로 결정되어 패리티체크 행렬 저장 복잡도(디코더 메모리)를 크게 절감.
  8. 최적화 절차: 알고리즘이 주어진 t에 대해 girth-12를 만족하는 최소 m을 백트래킹 탐색(step 2~8)해 Table I의 (m,t)-vector 생성.
  9. 결과: t=q+1(q 소수거듭제곱)에서 최소길이 n=mt/2가 Gallager bound 달성, t=7,15,16도 기존 최소; QC 변형은 girth ≥36(cw2)/18(cw3) 리프팅 가능, 시뮬에서 PEG/RA/ARJA/AR4A/integer-lattice 대비 우수.
  10. 한계: HW 미설계, AWGN 시뮬만, 우위 비교의 다수가 non-binary 부호이고 column-weight 2/3의 저밀도 저rate 구조라 고rate binary NAND ECC와 거리가 있음.
