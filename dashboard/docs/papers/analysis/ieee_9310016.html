B. 알고리즘 요약

  1. 대상은 information bottleneck(IB) 프레임워크(X→Y→T 마르코프 체인)에서 관측 변수 Y를 압축 표현 T로 매핑하는 문제, 통신 응용 예시는 복소 AWGN 채널 + 8-PSK 변조 출력 양자화(|Y|=65,536 그리드 → |T|=16 또는 256 양자화 레벨).
  2. 풀려는 문제: 기존 IB 알고리즘(KL-means)은 큰 lookup table(|Y| 크기)로 매핑을 저장하는데, 이를 소수 파라미터 θ로 표현하는 압축 규칙(parametrized compression mapping)이 필요하나 비미분 연산(min, 정렬, 그래프 탐색)이 포함돼 표준 gradient 최적화가 불가능.
  3. 핵심 가정: 결정론적 매핑 t=f_θ(y), p(x,y)를 안다고 가정, 적합도(fitness)는 보존된 relevant mutual information I(X;T).
  4. 핵심 기법 1: 거리최소화 매핑 t=fθ(y)=argmin_t d(y,θt) (식 2), 거리 d는 Euclidean(식3) 또는 저비용 Manhattan(식4).
  5. 근사최근접탐색(approximate nearest neighbor search, 식5): 이웃그래프를 탐욕적으로 순회해 거리계산 횟수를 n_entry + n_neighbor·l_path_max로 |T|와 무관하게 제한, 큰 |T|에서도 저복잡도 유지.
  6. 확장: 두 매핑 클래스(거리최소화/근사최근접) 모두 유전 알고리즘(population n_pop=200, n_gen=2000, crossover, elitism, mutation p_mut=10⁻⁴)으로 θ를 최적화, 적합도는 I(X;T) 자체.
  7. 부수 트릭: genotype을 r_m=10bit 해상도 이진 문자열로 인코딩해 crossover/mutation 적용, black-box 최적화라 매핑 내부 연산 형태에 무관.
  8. 학습 절차: 유전 알고리즘 반복(선택→crossover→mutation)으로 세대별 개체군 진화, KL-means를 벤치마크로 비교.
  9. 결과: |T|=16에서 KL-means(65,536 파라미터, I(X;T)≈1.389bit) 대비 제안 기법은 단 32개 파라미터로 I(X;T)≈1.383bit(Euclidean)/1.373bit(Manhattan) 달성; |T|=256에서는 513개 파라미터로 KL-means와 거의 동일 성능.
  10. 한계: LDPC 디코딩 자체는 실험하지 않음(서론에서 관련 응용으로만 언급), 채널 출력 양자화 예시 하나로만 검증, HW 구현/합성 없음.
