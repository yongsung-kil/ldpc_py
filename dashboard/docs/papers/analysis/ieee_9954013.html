한계,주의OSD/SLVA 계열은 short block code(n=128급) 대상 ML 근접 복호로 QC-LDPC 반복복호와 알고리즘 계통이 다름
추가확인LDPC를 대상으로 쓰긴 하나 n=128 short code 전제 — NAND 4KB급 고rate QC-LDPC로의 확장성/복잡도 검토 필요

총평: short block code용 OSD 조기종료 기법으로, NAND 고전 binary QC-LDPC의 min-sum 반복복호 파이프라인과 계통이 달라 이식 가치 낮음.

B. 알고리즘 요약

  1. 대상은 이진 선형블록부호 C[n,k](예: LDPC C1[128,64], eBCH C2[128,64]/[32,16]), BPSK+AWGN, LLR r_i = 2y_i/σ².
  2. 문제: 원조 OSD의 order-t 재처리는 시간복잡도 O(k^t)로 커, 성능손실 없이 복잡도를 줄이려 함.
  3. LC-OSD는 MRI(most reliable independent) k비트가 아니라 (k+δ)개 most-reliable dependent 비트를 재처리(δ≥0).
  4. HΠ를 Gaussian elimination해 H=[I | P1; O | P2] 형태로 만들고, e=(eL,eR)로 분해(eL 길이 n-k-δ, eR 길이 k+δ).
  5. 제약식 P2 eR^T = P2 zR^T, eL^T = zL^T + P1 zR^T + P1 eR^T 로 eR만 정하면 eL·e가 유일 결정.
  6. soft-weight Γ(e)=⟨e,|r|⟩=Γ(eL)+Γ(eR); SLVA로 P2 trellis 위에서 Γ(eR) 비감소 순으로 test error pattern 탐색.
  7. Trivial 기준: Γ(e_opt^(j)) ≤ Γ(eR^(j))이면 ML임을 보장하며 종료(Prop.1,2).
  8. Ideal 기준: Γ(e_opt^(j)) ≤ Γ(eL_true)+Γ(eR^(j)) (실사용 불가) → Γ(eL)을 기대값으로 대체.
  9. DAI: E{Γ(eL)|r}=Σ (1+exp(|r_i|))^{-1}|r_i| 사용; SAI: 이를 적분근사한 상수 τ로 Γ(e_opt)≤τ+Γ(eR^(j)) 종료.
  10. 결과: 원조 OSD 대비 평균 탐색수·복호시간 대폭 감소, 성능손실 미미(SNR↑일수록 복잡도↓). HW 미설계, n=128급 short code 시뮬만.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SLVA trellis 기반 test error pattern 탐색대응 없음Prime ECC는 min-sum 반복 message passing이며 OSD/Viterbi trellis 탐색 구조 부재
조기종료 기준(trivial/DAI/SAI)partial_CRC.cpp partial_crc_HW_T4(), full_CRC.cpp조기종료라는 목적은 공유하나 CRC 기반 vs soft-weight 기반으로 기법이 완전히 다름
soft-weight `Γ(e)=⟨e,r⟩` / LLRchannel.cpp Set_LLR_Th()LLR 개념만 공유, 반복복호 LLR 테이블과 무관

적용 가치: 낮음 — OSD/SLVA 계열 short-block ML 근접 복호로, min-sum 반복복호 기반 NAND QC-LDPC 엔진과 알고리즘 계통이 달라 떼어 쓸 부분이 없다.
