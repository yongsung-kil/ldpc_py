B. 알고리즘 요약

  1. 대상은 r0 × n0 개의 p × p circulant 블록 배열로 표현되는 QC-LDPC 부호(polynomial H(x) ∈ F2[x]/(x^p+1)), rate ≥ 1 − r0/n0.
  2. 문제: H에서 Gauss-Jordan으로 얻는 G는 조밀·비구조화라 인코딩 비용이 크며, 기존 sparse-G 구성법들은 특정 부호족(array/CPM/difference)에만 적용됨.
  3. 핵심 개념: unavoidable codeword U^(l)(x)의 각 블록을 부분행렬 H_{L\i}(x)의 permanent로 정의(식 5), 이 weight가 dmin 상한을 줌(식 6).
  4. 핵심 기법 1: G를 그림1처럼 대각선 블록 G_i(각 r0+1개 circulant)로 구성, G_i^(j)(x) = perm(H_{Lj\i}(x))(식 7)로 계산 → 구조화·sparse G.
  5. rank 결손 처리: r0*p − rank(H)개의 additional row(2p ones, a(j0,j0+1))를 삽입해 부족한 rank 보충.
  6. 핵심 정리: p가 소수이고 p−1이 2의 order이면(Theorem 1), circulant Q는 weight 홀수일 때 full rank p, 짝수일 때 p−1.
  7. Case study: fully-connected monomial code는 unavoidable codeword weight가 항상 짝수라 각 G_i가 rank 결손 → additional row로 보정.
  8. 확장(Theorem 2): U(x)/(x+1)로 공통인수 x+1을 제거한 reduced unavoidable codeword로 G의 rank를 추가 증대.
  9. 결과: p=61, row-column 제약(길이-4 사이클 없음) 부호에서 N=10000 codeword weight를 통계 분석, r0 증가 시 weight가 binomial(짝수 지지) 분포로 수렴.
  10. 한계: 순수 부호구성·최소거리 이론이며 HW·디코더·시뮬레이션 BER 없음, dmin은 상한만 논의.
