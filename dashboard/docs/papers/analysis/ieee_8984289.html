B. 알고리즘 요약

  1. 시스템: circulant-permutation 기반 1D spatially-coupled (SC) LDPC 코드 여러 개(L2개)를 연결해 multi-dimensional SC(MD-SC) 코드를 구성. AWGN 채널, 4-bit quantized min-sum, 15 iteration으로 시뮬.
  2. 문제: 기존 MD-SC 구성법은 무작위 연결이거나 특정 토폴로지(loop, triangle)에 한정되어 girth·최소거리 등 특정 사이클 특성을 목표로 최적화하지 못함.
  3. 핵심 모델: 각 constituent SC 코드의 parity-check matrix H_SC를 보조행렬 A_1,...,A_{d-1}로 재배치(relocation)하여 MD-SC 코드 H_MSCD를 구성 (coupling depth d, coupling length L2).
  4. 핵심 기법: 문제 CPM(짧은 사이클-k에 가장 많이 관여하는 circulant permutation matrix)을 식별해 다른 constituent 코드의 같은 위치로 재배치. 재배치 후 L2개 사이클-k 인스턴스가 τ = gcd(L2, ΔOk)개의 길이 L2k/τ 사이클로 합쳐짐(Theorem 2).
  5. 핵심 식: ΔOk = (-Σ(-1)^u M(C_iu,ju))_L2 — 재배치 매핑 M에 따른 누적 위상차이로, 이 값이 0에 가까울수록(=gcd가 작을수록) 더 긴 사이클로 합쳐져 error-floor에 유리.
  6. 확장: score voting 알고리즘(Algorithm 1)으로 각 CPM의 재배치 옵션(A_1...A_{d-1} 또는 유지)에 점수 부여, tree-based greedy 탐색(Algorithm 2)으로 순차적 재배치 solution 확정 후 trimming.
  7. 구현 디테일: 재배치는 middle replica 기준으로 랭킹, 동일 재배치를 모든 replica에 동일 적용해 저지연 windowed decoding 구조를 보존.
  8. 최적화 절차: greedy tree expansion + trimming(각 iteration마다 active cycle-k 최소화 solution만 유지), 최대 재배치 밀도 T까지 반복.
  9. 결과: girth-6 코드에서 depth 5가 depth 2 대비 1.5 orders BER 개선, MD-SC-Code 2/3는 1D 대비 사이클-6이 각각 90%/99% 감소, BER 4~6 orders 개선. 무작위 재배치 대비 65% 적은 사이클-6.
  10. 한계: HW 미설계, AWGN 채널 시뮬뿐(Flash/자기기록 채널은 미래연구로 언급), 특정 QC/SC-LDPC H-matrix 구조에 강하게 종속된 구성법이라 범용 이식 어려움.
