B. 알고리즘 요약

  1. 대상: J×L 배열의 z×z circulant로 구성된 binary irregular QC-LDPC (R=1-J/L), 실험은 J=30,L=45,z=45,N=2025,R=1/3.
  2. 문제: 표준(802.16e/11n)의 block dual-diagonal(BDD) 패리티부는 degree-2 VN이 과다해 최소거리가 작고 error-floor가 높음, 특히 저rate에서 심각.
  3. 핵심기법: 패리티부 Pp의 대각에만 weight-2 circulant(binomial x^0+x^{s_i})를 n2개 배치한 새 BDD 구조로 degree-2/3 VN 비율을 n2 조절로 유연화.
  4. 핵심식: rate-R에서 degree-2 VN 비율 (1-R)(1-n2/J) - n2를 키우면 저rate에서도 degree-2를 줄여 큰 최소거리·좋은 threshold 확보.
  5. 효율 인코딩: 하삼각 T(x)와 φ(x)=(1+x^{s1})...(1+x^{sJ})+1를 유도, φ를 circulant permutation(φ(x)=x^k)으로 만들어 φ^-1 존재 보장.
  6. 시프트값 설계: Theorem 1,2로 S={2^0,2^0,2^1,...,2^{n2-2} mod z} 형태가 φ를 permutation으로 만들고 각 weight-2 circulant 내 length-4 cycle 회피(z 짝수면 s_i≠z/2).
  7. girth 최적화: protograph의 dumbbell D(2,2;y_i) 기반 inevitable cycle 길이 min{8+4y_i}(Theorem 3)를 키우도록 2의 위치 r_i·S 순서를 전수탐색.
  8. 메시지부 Hm은 circulant permutation만, 열무게≥3, SGGM(stepwise greedy girth-maximizing) 알고리즘으로 구성.
  9. 결과: BP 복호(AWGN, 최대 100 iter)에서 threshold 1.225(vs 기존 1.004), 제안(Prop1/2)이 기존(Conv1/2) 대비 error-floor 영역 FER/BER 개선.
  10. 한계: HW/합성/throughput 없음, 저rate(1/3) 단일 예제 시뮬, gatecount·latency 정보 없음.
