B. 알고리즘 요약

  1. 문제: 랜덤 LDPC는 waterfall은 좋지만 error-floor·인코딩 복잡도 문제, 구조적 LDPC는 이를 완화하나 AWGN/BEC 양쪽 동시 우수 부호가 드묾.
  2. 채널·목표: BPSK/AWGN(SPA, 최대 100 iter)과 BEC(erasure 복호) 양쪽에서 동시에 잘 동작하는 regular/irregular LDPC를 대수적으로 구성.
  3. 핵심 기법 1단: m차원 Euclidean geometry EG(m,q)의 connecting line들을 parallel bundle로 분해(geometry-decomposition)하여 n x n permutation 행렬들의 n x q 배열 A를 얻음.
  4. 성질: A는 RC-constraint(두 행/열이 1을 최대 1개 공유) 만족 → Tanner graph의 length-4 cycle 제거, girth>=6 보장.
  5. 부호 생성: A의 γ x ρ 부분배열 H(γ,ρ)의 null space가 (γ,ρ)-regular LDPC. 길이 N=ρn, rate>=(ρ-γ)/ρ, 최소거리>=γ+1(odd)/γ+2(even).
  6. 성질의 의미: 큰 column weight γ → 큰 최소거리 + 큰 minimal stopping set(>=γ) → AWGN error-floor와 BEC 성능을 동시에 하한 보증.
  7. 핵심 기법 2단(masking): base matrix H의 일부 permutation 블록을 masking matrix Z(γ,ρ)(binary)로 0으로 치환 → M=Z⊗H. degree분포를 임의(irregular)로 조절, 밀도 낮춰 short cycle 추가 감소.
  8. Masking matrix 설계: primitive γ-tuple 또는 distance-3 Hamming codeword로 circulant 생성 → 원하는 v(X)/c(X) degree분포에 근사.
  9. 결과: (1024,781) rate0.763는 AWGN error-floor<10^-12(추정<10^-25), Shannon 2dB 이내; (8192,*) 3종은 error-floor 없이 Shannon 1.1~1.5dB; (16128,8064) rate1/2 irregular는 BER 10^-6에서 Shannon 0.83dB, error-floor 없음(turbo 대비 우수).
  10. 한계: 순수 부호구성(HW/디코더 아키텍처 없음), soft-read/양자화 논의 없음, degree분포는 채널별 재설계 필요(AWGN 최적≠BEC 최적).
