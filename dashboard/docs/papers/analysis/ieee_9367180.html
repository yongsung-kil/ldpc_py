B. 알고리즘 요약

  1. 대상은 MET-LDPC(multi-edge type) 부호 앙상블, 매우 낮은 code rate(0.02, 0.1, 1/3), CV-QKD·M2M 등 저rate 응용, BI-AWGN 채널.
  2. 문제: 저rate에서 threshold 개선을 위해 degree-1 변수노드가 유용하나([14]), 이들이 small-weight codeword를 유발해 high error floor로 이어짐 — 기존 t-value 조건[10]은 degree-1 노드가 없는 앙상블만 다룸.
  3. 핵심 모델: 앙상블을 node-perspective 다항식 ν(r,x), μ(x)로 기술, small-weight codeword의 지수 성장률 γ(w)와 임계 t값 집합 T로 error floor를 특성화.
  4. 핵심 기법: variable/check/edge 클래스를 degree-1 관련 부분집합 V1,V2,V1c2, C1,C1c, E1,E2,E1c2로 분할하고, w→0에서 u_j, s_j의 수렴 극한을 Lemma 1~3으로 유도.
  5. 핵심 식: 확장된 t-value 조건은 det(I - tΛ'(t)P)=0(식 30)의 해집합 T의 infimum이 1보다 커야 함 — 기존 식(5)를 특수경우로 포함.
  6. 통찰: g2,2=g3,2=0이면 small-weight 분포는 irregular LDPC 부분만으로 결정(LT 부분 무관), degree-2 노드 비율 ν3가 t-value 조건을 희생시키므로 신중 설계 필요.
  7. 설계 절차: [8]의 differential evolution 기반 threshold 최적화에 t-value 조건을 제약으로 추가, 기존 앙상블은 g3,2/d2,2 튜닝으로 조건 충족(SCE μ3Δg3,2=ν2Δd2,2).
  8. 유효성: ARJA(dmin 선형성장, t>1) vs ARA(dmin 소멸, t<1) 등 다른 부호에도 조건 적용 가능 확인.
  9. 결과: 길이 10^4, 2×10^4, message len 256(PEG)에서 t-value 만족 앙상블(Mod.Ref.1/C1/C2)이 미만족 대비 low-error-rate 영역 대폭 개선(BER 10^-7, WER 10^-6까지 floor 없음), waterfall·복잡도(dmax/gmax/edge density)는 동등 이하.
  10. 한계: HW 미설계, floating-point 시뮬만, 초저rate 전용, NAND read/양자화·gate count 등 HW 지표 전무.

small-weight codeword로 error-floor 제어대응 없음앙상블 이론 층, Prime ECC 부호설계(고rate 고정 H)와 rate·구조 상이
H-matrix/부호구조 로드ecc_top.cpp Load_PCM()로드 지점은 있으나 초저rate MET 구조 자체가 비호환

적용 가치: 낮음 — 초저rate(CV-QKD/M2M) MET-LDPC 앙상블의 error floor 제어 이론으로, NAND 고rate binary QC-LDPC(Prime ECC 3.1)와 rate 영역·부호구조·채널 모두 상이해 이식 불가.
