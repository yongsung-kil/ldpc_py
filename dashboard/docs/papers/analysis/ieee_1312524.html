B. 알고리즘 요약

  1. 대상은 turbo-structured LDPC(TS-LDPC), regular column weight j≥2, rate ρ=1−j/k, 예제 (6666,3,6) rate 0.5, AWGN 채널.
  2. 문제: cyclic/QC-LDPC는 j≥3에서 girth≤6으로 제한(Tanner) → 장블록에서 성능 저하; 큰 girth를 체계적으로 얻으려는 구조 필요.
  3. Tanner graph를 두 height-balanced 트리(TU leaf=bit, TL leaf=check, 각 h tier)를 interleaver I로 turbo처럼 결합해 구성.
  4. auxiliary node 도입으로 1-to-q 매핑을 표준 1-to-1 interleaver로 변환, cycle을 type-I(aux 4개)와 type-II(4개 초과)로 분류.
  5. type-I: p-q-alternate-decimal 인덱싱 후 digit-wise reversal πd로 연결 → type-I cycle 길이 ≥2h 보장(Theorem 1), tier h 늘리면 girth 확대.
  6. type-II: grouping & shifting, 그룹간 shift Sy,z를 (j−1)(k−1)개 자유 파라미터로 조정; Theorem 3의 Si,m+Sj,n=Si,n+Sj,m 위반 조건으로 type-II 4-cycle 제거.
  7. Theorem 4로 shift matrix S의 closed-path와 연속 0 자릿수 조건을 이용해 임의 길이 type-II cycle까지 제거, 목표 girth g−2까지 단주기 배제.
  8. 복호: turbo-like decoding algorithm(TLDA) - TU/TL을 번갈아 sum-product로 복호하고 APP를 interleaver 통해 교환하는 반복.
  9. 결과: (6666,3,6) girth-10 코드가 4-cycle-free 랜덤 코드 대비 BER 10^-5에서 0.12dB 우수(dmin≥10), TLDA가 sum-product 대비 iteration 약 50% 감소.
  10. 한계: HW 미설계, rate 0.5 단일 예제 시뮬만, QC-circulant 구조가 아니라 turbo-tree 전용 구조.
