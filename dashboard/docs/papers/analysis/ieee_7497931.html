총평: 아날로그 회로(analog VLSI) 디코더의 설계 복잡도(wire/gate 수) 절감을 위한 LDPC 부호 구성법으로, digital binary LDPC ECC 이식 관점에서는 관련성이 매우 낮음.

B. 알고리즘 요약

  1. 대상은 CMOS 아날로그 회로로 구현되는 연속시간(continuous-time) LDPC BP 디코더이며, parallel flood 전략을 사용해 회로 복잡도가 블록길이에 선형 비례한다.
  2. 문제: 블록길이가 길어질수록 아날로그 디코더의 wire/gate 매핑 복잡도가 과도하게 커져 실용화가 어렵다.
  3. 채널 모델은 AWGN + BPSK, BP(sum-product) 알고리즘으로 디코딩한다.
  4. 핵심 기법: factor graph를 e개(1≤e≤mb)의 부분그래프 Si(Ci,Vi,Ei)로 나누고 이들이 서로 동형(isomorphic)이 되도록 H행렬을 설계, 동일한 아날로그 building block을 반복 배선하여 디코더를 구성한다.
  5. H행렬은 4개의 mb×mb 순열행렬 A,B,C,D를 기반으로 한 4개 서브행렬(HA~HD)과 dual-diagonal 패턴의 Hp로 구성되며(식 1,2), 부분그래프의 인접행렬(식 8)이 서로 congruent해야 동형성이 보장된다.
  6. 확장인자 e로 동일 basic matrix(15×15 또는 31×31)에서 블록길이가 다른 여러 코드(120~496)를 동일 building block으로 생성 가능하다.
  7. 순열 서브행렬 내부는 "optimization vector" Ei(식 5,6)를 이용해 행을 재배열, 각 부분행렬이 식(4) 조건(union이 전체, 교집합이 공집합)을 만족하도록 구성한다.
  8. 별도의 학습/최적화 절차는 없으며 π-rotation LDPC 코드(mb=15, 31)를 기반 예제로 사용한다.
  9. 결과: 제안 코드는 (120,60) 기준 gate 135개/connection 300개로 기존 방식(510개/1440개) 대비 대폭 절감했고, CCSDS 131.1-O-1 표준 대비 BER 성능도 우수했다.
  10. 한계: 순수 시뮬레이션(BER curve)만 제시되었고 실제 아날로그 HW(레이아웃/합성) 결과는 없으며, 확장인자 e가 mb/2 초과 시 성능 저하가 발생해 적용 범위가 제한적이다.
