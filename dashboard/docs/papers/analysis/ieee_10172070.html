B. 알고리즘 요약

  1. 시스템/부호: (dv,dc)=(3,6) regular LDPC-BC를 building block으로 coupling length L, width ω=2로 결합한 protograph SC-LDPC, 대표 rate 0.45, 총길이 N=80000.
  2. 문제: 작은 L에서 종단(virtual CN 추가)에 의한 rate loss가 크고 BP threshold와 capacity 간 gap이 큼.
  3. 채널/모델: BEC(erasure ϵ)에서 protograph DE로 threshold 분석, AWGN에서 유한길이 BER 검증.
  4. 핵심 기법 1(종단): single-side open C1 — ω>1일 때 한쪽 끝의 T=ω-1개 CN 제거로 rate loss 반감(식(2)), double-side open C2는 rate loss를 완전 제거하되 threshold 저하.
  5. 핵심 식: R(C1)=1-(L+ω-T)bc/(Lbv), T=ω-1로 rate loss 최소화하면 coupling width 증가가 더 이상 rate loss를 늘리지 않음.
  6. 핵심 기법 2(self-connection): non-closure end의 저차 CN과 체인 내 VN(거리 ⌊L/3⌋ 등) 사이에 max CN degree dc 제한하에 edge 추가 → 신뢰정보가 여러 방향에서 전파, R(Ct)=R(St) 유지.
  7. 확장: single-chain을 sub-chain으로 연결한 multi-chain M1(두 C1 연결)로 threshold 추가 개선, connect position은 DE로 최적화.
  8. 이론: Proposition 1/Corollary 1로 ϵ*(C1)≤ϵ*(S1),ϵ*(M1), L→∞에서 C0와 동일 threshold(threshold saturation, MAP threshold로 수렴)임을 증명.
  9. 결과: BEC에서 L=9일 때 S1/M1 threshold 0.4987/0.5132(기존 0.4917 대비), AWGN BER 1e-5에서 M1이 C0(3,6,20,2)/L(3,6,20,2) 대비 약 0.20/0.17 dB 개선, Iavg도 M1이 최저 수준.
  10. 한계: HW 미설계·시뮬/이론뿐, gate count/throughput 없음, SC-LDPC 체인 구조 전용.
