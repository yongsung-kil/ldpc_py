B. 알고리즘 요약

  1. 시스템: 고속 통신/자기기록용 SISO LDPC 복호기, 예제는 2D-TPC/SPC(32,31)^2 (n=1024, k=961, d=4, rate 0.9384), 8bit 정밀도.
  2. 문제: SISO LDPC 검출기의 상호연결 복잡도·메모리 요구가 커서 고속 병렬 구현이 어려움.
  3. 핵심 구조가정: VPFCC (Variable-node Partition with Full Check-node Connectivity) - 변수노드를 파티션 PV={Vq}로 나눠 각 Vq가 (P1) 모든 체크노드에 연결되고 (P2) 같은 Vq 내 두 변수노드가 체크노드를 공유하지 않는 속성.
  4. 대상부호: VPFCC를 만족하는 부호(특히 2D-TPC/SPC(N,N-1)^2 곱부호), 파티션 Vi는 N x N 변수노드 배열의 modular-diagonal Dk로 구성.
  5. 복호: SPA로 M(vi->cj)=AprLLR + sum M(ck->vi), M(cj->vi)=phi^-1(sum phi(M(vk->cj))), phi(x)=ln tanh(x/2); BCV(check)는 연산비중이 커 min 근사 M* = min|M| * prod(sign)(min-sum)도 제시.
  6. 아키텍처: BVC(변수->체크)는 병렬, BCV(체크->변수)는 recursive로 복잡도 최소화, BApoLLR는 사후 LLR 계산.
  7. 핵심 트릭: VPFCC 파티션으로 클록당 N개 변수노드만 갱신 - 메시지 M(vi->cj)/M(cj->vi)를 저장하지 않고 on-demand 계산·소비 → 메모리·MUX 상호연결 대폭 절감.
  8. 병렬도: full-parallel의 N^2개 대신 N개 BVC 블록만 구현, MUX로 파티션별 BVC-BCV 연결; iteration은 HW를 반복 인스턴스화(unroll)해 처리.
  9. 결과: Virtex5 XC5VLX330 FPGA 합성, 2D-TPC/SPC(32,31)^2 기준 registers 16,952(8.18%)/LUT 14,402(6.95%) 사용. (throughput·클록수 미보고)
  10. 한계: 이득은 VPFCC 구조 속성에 종속 - 일반 QC-LDPC엔 직접 적용 불가; 정정성능 개선 주장 없음(정확 SPA 유지가 목적), throughput 수치 없음.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
SPA/SISO 복호 전체decoder.cpp LDPC_Decoder(), C2V_Cal()Prime은 min-sum, 논문은 full-tanh SPA(+min-sum 근사) - 계열 일부만 겹침
BCV check node min-sum 근사decoder.cpp CNU_Update_New_Mag(), C2V_Cal_New_Sgn()min-sum 부분만 중복, 이미 보유
BVC/BApoLLR VN·사후LLR 처리decoder.cpp VN_Cal_HD()표준 VN 처리, 신규성 없음
VPFCC 파티션 기반 on-demand 메모리·라우팅 절감대응 없음Prime은 QC z=32 구조·GT 사용, VPFCC 파티션 트릭은 TPC/SPC 종속이라 이식 불가

적용 가치: 낮음 - 메모리·라우팅 절감이라는 방향은 NAND LDPC 병목과 맞닿지만, 절감 기법이 VPFCC/TPC-SPC 구조 속성에 종속돼 고정 QC-LDPC에 그대로 옮길 수 없음.
