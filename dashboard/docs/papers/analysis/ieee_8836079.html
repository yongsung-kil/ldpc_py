B. 알고리즘 요약

  1. 시스템: bi-AWGN + BPSK, sum-product 반복복호(최대 100 iter), 짧은/중간 길이 고rate LDPC 부호설계가 대상. 예제 부호 rate 0.65~0.93, length 243~2121.
  2. 문제: 랜덤·대수적 구성법이 short/medium-length 고rate LDPC에서 BER 성능이 불충분, girth가 작으면 반복복호 성능 저하.
  3. 모델: parity-check matrix의 각 열을 집합 Li(비영 원소 support)로 표현, 열 간 관계를 matroid M=(E,I) 집합 문제로 변환.
  4. 핵심기법: girth 결정 충분조건을 matroid로 정식화 — |Li∩Lj|≥2면 girth 4(Theorem 1), 두 조건 만족 시 girth≥8(Theorem 2), 일반화하여 t1개 조건 동시 만족 시 girth≥2(t1+2)(Theorem 3).
  5. 핵심식 의미: 집합 교집합 cardinality 조건 |∪(Li∩Lj)|<t가 특정 길이 cycle 부재를 보장(귀류법), 즉 girth 하한을 집합 조건으로 환원.
  6. 구성 형태: H=[I|H2] (systematic, generator 쉽게 획득), 열가중 Wc=4 또는 Wc=6 고정한 H2만 girth 조건 하에 구성.
  7. 구현 디테일: H2의 최대 열 수는 Theorem 4의 상한 cH2 ≤ floor((r-1)/(Wc-1))·(r/Wc)로 대략 결정(실제는 상한 도달 어려움).
  8. 최적화: Algorithm 1 — r개 원소에서 Wc-원소 집합 나열 후 Condition 1·2(Theorem 2)를 만족하는 열만 순차 선택, girth≥8 보장. 구성 복잡도 O(r⁴)~O(r⁶).
  9. 결과: BER=10⁻⁴에서 [16] 대비 ~0.25 dB, [17] 대비 ~0.7 dB, BER=10⁻⁷에서 [18] 대비 ~0.25 dB 이득(길이 유사, rate는 약간 낮음). length-4·6 cycle 회피.
  10. 한계: HW 미설계, 구성법·시뮬만, girth-8까지만 회피(향후 girth-8 이상 목표), QC 구조 명시 없음.
