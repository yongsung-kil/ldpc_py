B. 알고리즘 요약

  1. 대상은 QC-LDPC(Hb base matrix + scale factor z로 확장) rate-compatible 부호, WiMax rate-1/2 base(24×12), block 576/864/1152, sum-product 복호(최대 100 iter).
  2. 문제: 확장 행렬마다 puncturing 패턴을 저장하면 비효율이고, 기존 greedy를 base matrix에 적용하면 랜덤 선택으로 k-SR 노드 수가 들쭉날쭉·suboptimal(확장 시 증폭)하다.
  3. 핵심 개념: punctured node가 이웃 check로 k iteration 만에 복구되면 k-SR, 그 복구에 쓰인 check는 k-SE; recovery delay가 짧을수록 복구 정보 신뢰도↑.
  4. 핵심 기법: base matrix Hb에서 ILP 최적화로 최대 recovery delay K 제약 하 punctured 노드 수를 최대화, 목적함수 G=Gp+Gr+Gv+Gc로 (1) punctured 노드 최대(Gp), (2) 빠른 복구(Gr=ΣΣ k·Sk,n), (3)~(4) VN/CN degree 최소화를 Cp≫Cr≫Cv≫Cc 우선순위로 처리.
  5. 제약식: 초기화(11), 복구(12), 이웃복구 요구(13), k-SE 이웃 요구(14), 전노드 복구 요구(15) — variable Pn/Sk,n/Ck,m/rk,n 이진.
  6. cut 2개(식16/17)로 "check 내 유일 미복구 노드는 반드시 k+1-SE/SR"을 강제해 최적성 유지하며 solve 시간 단축.
  7. 설계 절차: K=1부터 시작해 forced puncture F=P로 ILP를 풀고, 해를 recovery delay·degree 오름차순 정렬해 p에 append, K 증가 반복 → base sequence p.
  8. block-size 확장: p의 원소 a를 za,...,z(a+1)-1로 치환해 임의 z에 대한 puncturing 패턴 생성(패턴 저장 불필요).
  9. 결과: WiMax base에서 8개 1-SR 노드 달성(greedy[7]은 4~7), rate 3/4에서 greedy 대비 성능 우세(2/3은 동등), recovery delay가 낮아 복호시간 단축; rate 0.92까지 도달 가능.
  10. 한계: 확장행렬 직접 greedy 대비 성능은 다소 열위(scalability 위한 trade-off), HW 미설계·시뮬만, 통신(WiMax) 타깃.

적용 가치: 중간 — QC-LDPC base matrix 대상이라 구조적으로는 Prime ECC와 정합되나, rate-compatible 다중 rate/가변 block-size가 목적이어서 고정 고rate·고정 z=32의 NAND ECC에는 직접 필요성이 낮다. puncturing 복구지연 최소화 개념만 참고 가치.
