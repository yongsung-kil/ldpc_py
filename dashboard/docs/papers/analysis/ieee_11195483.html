총평: girth-g QC-LDPC 최소 blocklength를 Hermite Normal Form으로 대수적으로 산출하는 부호 구성 이론이며, 실험적 디코더 검증은 없지만 짧은 cycle(trapping set 유발 요인) 회피를 통한 error-floor 개선 잠재력이 있어 부호설계 단계에서 참고할 이식성 중 가치를 가짐.

B. 알고리즘 요약

  1. 대상은 protograph 기반 QC-LDPC 부호(regular/irregular)로, biadjacency 행렬 B를 N-fold lifting하여 blocklength n_v·N을 갖는 parity-check 행렬 H를 구성.
  2. 풀려는 문제는 주어진 protograph에서 목표 girth g를 만족하는 최소 lifting factor N_min(즉 최소 blocklength)을 대수적으로 찾는 것으로, 기존 연구는 all-one protograph의 g>4에서만 정확한 식이 있고 나머지는 컴퓨터 탐색에 의존했던 한계를 해결.
  3. 핵심 가정은 그래프의 girth g 미만 길이 k에서 k-cycle과 TBC(tailless backtrackless closed) walk가 일치한다는 성질(선행연구 [19]에서 증명)에 기반.
  4. 핵심 기법: TBC walk의 permutation shift s = Σ(-1)^i·s_{i+1} mod N(Lemma 4)을 변수로 하는 계수행렬 M(각 행=하나의 permutation shift, 각 열=circulant shift 변수)을 구성하고, 이 M의 Hermite Normal Form H = UM(U는 unimodular)을 계산.
  5. 핵심 식의 의미: H의 피벗(대각 leading coefficient) 곱이 목표 girth를 만족시키는 lifting factor N과 일치함을 관찰(예제 다수로 검증) → girth 조건을 만족하는 순열이동 값들을 Hv=0 (mod N) 후방대입으로 직접 산출해 무작위/전수탐색 없이 부호를 구성.
  6. 확장: fully-connected(all-one) protograph뿐 아니라 irregular protograph(rate-1/2 AR4JA)에도 적용 가능함을 예시(계수행렬이 rank-deficient해도 피벗 곱이 여전히 N과 일치하는 경우 존재).
  7. 부수 기법: TBC walk를 무작위로 효율 생성하는 Algorithm 1(B_{k/2}(H) 거듭제곱 기반) 제시, equivalence(기준점 변경/방향 반전)로 중복 walk 제거.
  8. 최적화 절차 없음(탐색적 그리드/ML 아님) — 순수 대수적(선형대수, 모듈러 산술) 유도.
  9. 결과: 3×4 all-one protograph에서 girth 8을 만족하는 최소 lifting factor N=9(blocklength 36)를 산출(기존 컴퓨터 탐색 결과와 일치), 계수 6개 대신 자유변수 1개(j3)로 해공간 축소.
  10. 한계: N_min과 피벗곱의 일치는 Conjecture(§VIII)로 엄밀 증명 없이 관찰적 근거, 소규모 예제(길이 36~수백)만 시연, 디코더 성능/HW/시뮬레이션 검증 전무하고 순수 부호구성 이론.
