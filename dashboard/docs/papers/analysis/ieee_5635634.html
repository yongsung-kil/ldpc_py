총평: prime field 기반 girth≥6 regular QC-LDPC 구성법으로 error-floor(BER 10^-7까지 무바닥)를 보증하나, HW·디코더 개선 없고 범용 부호라 고정 부호 사용하는 Prime ECC엔 이식 가치 낮음.

B. 알고리즘 요약

  1. 시스템: binary regular QC-LDPC, H는 p×p circulant permutation matrix I(p_ij) 블록으로 구성, 예시 rate 0.78~0.84, 길이 1369~3768.
  2. 문제: 짧은 cycle(특히 4-cycle)이 성능을 떨어뜨려 error-floor 유발 → girth≥6 보장하며 다양한 길이/rate를 쉽게 얻는 구성법 필요.
  3. 핵심가정: 소수 p에 대한 prime field (Z_p,+,×) 연산 사용.
  4. 핵심기법1: χ(α)=(0,α,2α,...,(p-1)α)를 행으로 쌓은 (p-1)×p 행렬 H(각 행이 Z_p의 순열, 두 행은 최대 1위치만 동일), 각 원소 h_ij를 circulant perm σ(h_ij)로 치환해 이진 (p²-p)×p² 행렬 생성.
  5. 핵심식/보증: Fossorier 조건(Theorem 1)으로 4-cycle 존재조건이 (i−l)(k−j)=0 mod p가 되어 i≠l,j≠k에서 모순 → Theorem 2로 4-cycle 부재(girth≥6) 증명.
  6. 파라미터화: H의 좌상단 γ×ρ 부분행렬로 (γ,ρ) regular 부호 정의 → 길이 ρp, rate 1−γ/ρ 자유 선택.
  7. 트릭: QC 구조라 shift-register로 인코딩, 복잡도 부호길이에 선형.
  8. 실험: field 특성(p=37,61,71 등), (γ,ρ) 값 변화 영향 분석 — p나 γ,ρ 증가가 항상 성능향상 아님(신중 선택 필요).
  9. 결과: SPA max iter 10에서 BER 10^-7까지 error-floor 없음, best code가 Shannon 한계 대비 약 2.0~2.2dB.
  10. 한계: AWGN 시뮬만, HW 미설계, regular·중저rate 범용 부호.
