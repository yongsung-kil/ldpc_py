총평: (5,k) regular LDPC의 순수 구성법(full-rank+저인코딩복잡도) 논문. 고rate QC-LDPC 고정된 Prime ECC에 떼어 쓸 여지 거의 없음.

B. 알고리즘 요약

  1. 목표: rank-deficiency 없고 non-singular parity·girth≥6 을 만족하는 유한길이 (5,k) regular LDPC를 QC 구조(right cyclic shift)로 구성.
  2. 기존 문제: Gallager/algebraic/QC regular LDPC는 H에 최소 (j-1)개 종속행이 존재해 full-rank 부호 획득이 어렵고 인코딩 복잡도가 O(N²)로 높음.
  3. 1단계(parity part): base×(base+4) 크기의 five-diagonal base matrix를 만들고 열 위치를 mod(base+1)/mod base로 재배치해 base×base 근사 하삼각 (5,5) regular base matrix로 축약, 확장인자 L로 lifting.
  4. lifting 시 각 1을 결정론적 RCS((x·y)modL 등 Table I의 7가지 식)로 순환 이동시켜 4-cycle 제거, 하삼각 유지를 위해 특정 1은 identity로 고정.
  5. 2단계(information part): 전부 1인 ji×ki base matrix를 Z=(base·L)/ji 확장인자로 random RCS lifting 하여 Hi 생성, [Hi|Hp]로 결합(4-cycle 회피).
  6. 3단계: [Hi|Hp]를 추가 확장인자 L1로 identity 확장(RCS 없음)해 최종 H=[Hinf|Hpar] 완성.
  7. rate 가변: 행 수 고정하고 Hinf의 열 수(ki)만 바꿔 R=(Z·ki·L1)/N으로 다양한 rate 획득.
  8. 인코딩: Richardson-Urbanke 방법으로 gap g=2·L·L1을 갖는 approximate 하삼각 형태 이용, p1/p2를 식(12)~(14)로 계산.
  9. 결과: (5,16) R=0.69 N=3840은 Shannon limit에서 2.38 dB(BER 1e-6), 인코딩 복잡도 O(1.104N); (5,17) R=0.706 N=4080은 2.33 dB, O(1.098N) (SPA 50 iter, AWGN/BPSK MATLAB).
  10. 한계: HW 미설계, 시뮬만, error-floor/정정능력 분석 없음, 성능이 최신 부호 대비 평범.
