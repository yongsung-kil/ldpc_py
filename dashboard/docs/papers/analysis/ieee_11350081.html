B. 알고리즘 요약

  1. 대상은 GF(4) 상의 2-generator quasi-cyclic 부호(index 2, 길이 2n)이며, classical binary LDPC가 아닌 양자 오류정정부호(QECC) [[n,k,d]]2 구성이 목표.
  2. 기존 연구는 quasi-cyclic 부호의 정확한 dual distance 계산이 어려워 좋은 파라미터의 양자부호 구성이 제한적이었음(선행연구 한계).
  3. 핵심 모델: 생성다항식 g1(x), g2(x)와 보조다항식 ν(x)로 정의되는 quasi-cyclic 부호 C4(g1,g2,ν)가 Hermitian 내적 하에서 dual-containing 조건을 만족하도록 구성.
  4. 핵심 기법: Lemma 3.4의 조건(g2^⊥h(x) | g1(x)이고 g1^⊥h(x) | g2(x))을 만족하는 g1,g2,ν를 선택해 dual-containing quasi-cyclic 부호 C=[2n,2n-deg(g1)-deg(g2)]4를 구성.
  5. Theorem 3.7: Hermitian construction(Lemma 2.1)을 적용하면 quaternary dual-containing 부호로부터 이진 양자부호 [[2n, 2n-2deg(g1)-2deg(g2), d]]2가 유도된다는 것이 핵심 식.
  6. 확장: Propagation rules(Proposition 2.2)로 하나의 quantum code에서 파라미터를 한 단계씩 변형한 파생 코드들을 추가로 생성(예: [[N,K-1,d]], [[N+1,K,d]] 등).
  7. 부수 디테일: 계수다항식은 항의 지수를 나열하는 축약 표기(예: 120231)로 표현, 4-cyclotomic coset 계산으로 defining set을 결정.
  8. 최적화 절차: Magma 소프트웨어를 이용한 ν(x) 전수탐색(exhaustive search)으로 최소거리 d를 최대화하는 파라미터를 찾음(학습이 아닌 대수적 전수탐색).
  9. 결과: 새 양자부호 3종 [[42,10,9]], [[74,36,9]], [[78,40,9]] 및 propagation으로 파생된 24종, 총 27종이 Grassl 코드표의 기존 최소거리(대부분 d=8)를 d=9로 개선.
  10. 한계: 순수 이론/전수탐색 결과이며 시뮬레이션·HW·디코더 구현 전혀 없음, 코드 길이가 42~80으로 매우 짧아 NAND 실용 규모(수천~수만 bit)와 무관, non-binary(GF(4)) 기반 구성이라 binary LDPC로의 직접 변환 경로 불명.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
GF(4) quasi-cyclic 부호 구성(Hermitian dual-containing)대응 없음non-binary(GF(4)) 양자부호 구성으로 Prime ECC의 binary QC-LDPC와 부호체계 자체가 다름
Magma 전수탐색 기반 최소거리 최적화대응 없음부호설계 방법론이지만 quantum code 전용이며 ecc_top.cpp Load_PCM()이 다루는 classical QC-LDPC H-matrix 설계와 목적이 다름
propagation rules에 의한 파생 코드 생성대응 없음양자부호 파라미터 변형 규칙으로 classical LDPC 설계 절차에 대응 없음

적용 가치: 낮음 — 양자 오류정정부호(non-binary GF(4) quasi-cyclic) 구성 이론이며 NAND classical binary LDPC ECC의 부호설계·디코더·HW 어느 레이어와도 접점이 없음.
