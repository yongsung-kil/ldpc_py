B. 알고리즘 요약

  1. 대상: parity-check H 288x576, 길이 n=576 LDPC, AWGN+BPSK 채널.
  2. 문제: LP relaxation의 constraint 수가 부호길이에 지수적이라 대규모 LP를 효율적으로 풀 알고리즘 필요.
  3. 모델: Feldman LP relaxation — codeword polytope를 완화한 Q를 auxiliary 변수 t_{j,V}로 (6)~(9) 정의, 목적 min γ^T f.
  4. 핵심 기법1(표준형): primal min c^T x, x+s=e, dual max b^T y - e^T w 구성, KKT 조건 (14)를 non-negative 제약 하 풀이 대상으로 삼음.
  5. 핵심 식: normal equation A D A^T Δy = ... (17) — Cholesky 분해로 search direction 계산(연산 병목).
  6. 핵심 기법2(P-C): Mehrotra predictor-corrector로 방향을 Δψ_p + Δψ_c로 분해, KKT를 두 번 풀어 반복수 축소.
  7. 부수 트릭(MCP): centering parameter η에 상한을 두고 종단에서 상대오차와 동차되게 조정 (24) → 수렴 가속; backtracking line search로 step size 제한.
  8. 학습 절차 없음(수치 최적화 반복).
  9. 결과: (288,576) 부호에서 IPDIP가 P-C/Newton보다 반복수·시간 적음(SNR 2dB 부근), MS 대비 BER 우수(그림).
  10. 한계: HW 미설계, 부호 구조 상세 미제시, Cholesky 기반 부동소수 연산으로 임베디드 ECC 부적합.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
IPDIP/interior-point LP solver대응 없음Prime ECC는 min-sum message-passing, LP·행렬분해 solver 없음
KKT/normal equation(Cholesky)대응 없음부동소수 선형대수 연산, HW 파이프라인 무관
LP relaxation polytope 이론대응 없음부호설계·error-floor 구조가 아니라 최적화 formulation

적용 가치: 낮음 — interior-point LP 디코더는 Prime ECC의 min-sum HW 구조와 정합점이 없어 이식 경로가 없다.
