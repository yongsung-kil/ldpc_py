총평: cyclic LDPC의 sparse H를 이용한 burst-error(신드롬 zero-span 기반) 단일오류정정 이론 논문으로, NAND용 binary QC-LDPC의 반복 soft decoding/HW 이식과는 목적·채널모델이 달라 활용가치 낮음.

B. 알고리즘 요약

  1. 대상은 cyclic LDPC 코드(단일 circulant 패리티검사행렬 H)이며, AWGN/erasure 채널의 반복복호(SPA)에 쓰이는 것과 동일한 H를 burst-error 채널에도 재사용하는 것이 목표.
  2. 기존 Fire code 계열은 error-trapping 기반 순차(sequential) 디코딩이라 고속 병렬 구현(홀로그래픽 메모리, optical bus 등)에 부적합 — 이를 조합논리(combinatorial logic) 기반으로 구현 가능한 단순 병렬 디코더로 대체하려는 문제의식.
  3. 채널모델은 단일 error burst(길이 l, 시작위치 b)가 순환적으로 연속된 위치에 발생한다고 가정 (AWGN/erasure와 무관한 별도 burst 채널).
  4. 핵심 개념은 H의 각 행/열이 갖는 "zero-span"(두 1 사이의 연속 0 구간) 중 유일한 최대길이 zero-span 위치를 이용해 신드롬 s = r*H^T로부터 burst 시작위치·길이를 직접 판독.
  5. RC-constraint(두 행/열이 1을 공유하는 위치가 최대 1개)가 zero-span의 유일성을 보장하는 핵심 전제 — 이 조건이 깨지면 burst 정정 불가.
  6. 정정 가능한 최대 burst 길이 t를 "신드롬이 유일한 최대길이 zero-span을 가지며 그 길이가 n-J(J=행/열 무게)와 같아지는 최대 정수"로 정의하고, t ≤ floor(J-1)/2 상한(Proposition 1)을 증명.
  7. 나머지 오류 비트값은 신드롬을 이용한 재귀식(식 (1)(2))으로 최대 d회 덧셈만으로 계산 — 조합논리 구현에 적합한 저복잡도 구조.
  8. 별도 학습/최적화 절차 없음. 대신 Euclidean geometry EG(2,s), projective geometry PG(2,s) 기하학적 구성으로 RC-constraint를 만족하는 circulant H를 생성.
  9. 결과: 구성한 finite-geometry LDPC 코드들의 실제 burst-correction limit(Reiger 상한 기준)이 최적 error-trapping 디코더의 한계에 매우 근접함을 수치 예시(Table I)로 제시. 단, 제안 디코더의 실제 정정능력 t는 그 한계보다 상당히 낮을 수 있음.
  10. 한계: 순수 이론/조합적 분석뿐이며 HW 구현·시뮬레이션 결과 없음. 대상 채널이 단일 burst-erasure/error에 한정되어 NAND의 random bit-flip 다중오류 정정 시나리오와는 근본적으로 다름.
