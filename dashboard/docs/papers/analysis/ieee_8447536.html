총평: LDPC가 아닌 짧은 cyclic/BCH용 ABP 변형(EPTA)으로, 매 iteration H 재구성·float 신뢰도 연산 전제라 Prime ECC의 sparse QC-LDPC min-sum 파이프라인과 이질적이어서 이식성 하.

B. 알고리즘 요약

  1. 대상: 짧은 binary cyclic code (예제 (7,3), (15,11)), BCH (31,21); BPSK/AWGN, R≈0.68 (15,11).
  2. 문제: BP는 sparse·4-cycle-free Tanner 그래프를 요구하나 짧은 BCH/cyclic code는 4-cycle 불가피, HD B-M은 t=(d_min-1)/2까지만 정정.
  3. 모델: 수신벡터 y에서 거리척도 d(y_j,q_w)로 M×n soft reliability matrix β 산출.
  4. 핵심 기법(EPTA): 매 iteration에서 β의 열별 최대신뢰도로 신뢰도 벡터 L을 오름차순 정렬, least/most reliable로 분할해 systematic H를 RREF 후 신뢰도 index l로 열 재정렬 → 변환행렬 H_T.
  5. 핵심 의미: ABP처럼 unreliable submatrix를 sparse화하되 Gaussian elimination 대신 reorder로 대체해 message-update 복잡도 절감.
  6. 확장: MDS(RS)용 H_T=H·U^{-1} (PTA)를 non-MDS cyclic까지 일반화, U 비가역 실패를 U·R concatenation+RREF로 회피.
  7. 구현 디테일: HD로 r 산출→각 H_T 행과 dot product로 PCE 계산, 연산자 δ(=0.05 채택)로 참여 bit의 β를 reward/penalize, 음수 원소 발생 시 종료.
  8. 학습/최적화: 없음 (δ만 실험적으로 0.001/0.05/0.9 비교).
  9. 결과: (15,11)에서 EPTA가 B-M·BP 능가, ABP와 유사 BER; (31,21)은 저SNR에서 ABP 초과·고SNR 동등. EPTA reorder는 O(n^2) vs ABP/PTA O(n^3).
  10. 한계: HW 미설계, 짧은 부호·float 신뢰도 연산, dense H 매 iteration 재계산, LDPC 아님.
