B. 알고리즘 요약

  1. 대상은 BSC 상의 regular (J,L) LDPC, hard-decision BF 복호. 예제: (1008,504)(3,6), (40000,20000)(3,6), (1680,1176)(3,10), (4000,2000)(4,8), (273,191)(17,17) PG.
  2. 문제: Gallager 결정론적 BF는 짧은 cycle이 만드는 주기적 오류패턴에 갇혀(trap) waterfall 성능·수렴이 나쁘다.
  3. 모델: unsatisfied check sum 수가 ⌈J/2⌉에 가까운 비트는 신뢰도가 낮다는 관찰을 이용.
  4. 핵심 기법: 임계 b(≥J-1) 초과 비트를 자동 flip 대신 확률 p<1로 flip. cycle 내부의 잘못된 메시지 전파를 늦춰 오류 확산을 줄임.
  5. 핵심 식: cycle-free 수렴식 p_{i+1}=p0−p0F+(pi)(1−(1−p)pi)+(1−p0)F−(pi)(p+(1−p)pi) — p를 반복마다 키우면 static point(비영 수렴점)를 회피.
  6. 확장: 복호 후 codeword가 아니면 unsatisfied 비트를 모두 flip하고 p를 리셋하는 reinitialization + 동일 수신열의 parallel 복호(다수결/최근접 Hamming) 로 error-floor 완화.
  7. 구현 디테일: p는 초기값(예 0.1)에서 시작해 비트값 변화가 없을 때 0.1씩 증가, p=1 도달 시 갱신규칙이 정지조건이 됨.
  8. 최적화: tree-like 코드 수렴식으로 최소 초기 p·최대 증분을 도출하되 유한길이에서는 하향 조정 필요.
  9. 결과: (1008,504)(3,6)에서 Algorithm A 대비 waterfall >1dB, (3,10)은 1.9dB 이득; 평균 반복수도 감소(특히 (4,8)에서 Algorithm B 대비 log-scale 대폭 감소).
  10. 한계: error-floor는 확률적 BF만으로 개선 불가, J≥4·irregular에서는 이득 급감, HW 미설계·throughput/gate 정보 없음.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| 확률적 BF flip 결정 (반복별 p 증가) | decoder.cpp LDPC_Decoder() 이터레이션 루프 | HD 경로에 확률적 flip 스케줄 삽입 가능하나 우리 기본은 min-sum |
| unsatisfied check sum 카운트 기반 VN 갱신 | decoder.cpp VN_Cal_HD() | HD 복호 시 flip 판정부에 대응 |
| parallel+reinitialization error-floor 완화 | decoder.cpp LDPC_Decoder() (재초기화 루프) | 반복 후 실패 시 재시도 로직으로 이식 가능, 다만 latency 증가 |
| BF 자체 (min-sum 아님) | 대응 없음 | Prime ECC는 min-sum 기반이라 BF 알고리즘 직접 대응 없음 |

적용 가치: 낮음 — hard-decision BF는 우리 min-sum(2SD/3SD) 대비 성능이 낮고 논문 이득도 J=3·waterfall에 국한되어, NAND 고rate QC-LDPC 실이식 가치는 제한적.
