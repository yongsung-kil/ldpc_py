B. 알고리즘 요약

  1. 대상은 highly irregular bipartite graph 기반 LDPC 코드로, degree sequence pair (λ(x), ρ(x))와 무작위 연결로 특성화. AWGN/BEC/BSC 채널.
  2. 문제: 규칙적(예: (3,6)-regular) LDPC는 용량과 격차가 크고, 어떤 degree 분포가 threshold를 용량에 최대한 근접시키는지 미해결.
  3. 핵심 도구: density evolution(DE) - 무한 길이 코드에서 variable node가 방출하는 메시지 분포 Pℓ의 iteration별 진화를 추적(all-one codeword 가정, LLR 형태).
  4. consistency 조건: 분포 f가 f(x)=f(-x)e^x를 만족(Gaussian이면 σ²=2μ). Theorem 1 - 대칭 채널에서 BP 메시지 분포 Pℓ은 매 iteration consistent함.
  5. 의미: consistency로 메시지 분포를 1-파라미터로 축약해 DE 계산의 속도·정확도를 크게 개선.
  6. stability 조건: Theorem 2 - 초기 분포의 moment generating function g(s)로 r=-log(inf g(s)) 정의, λ'(0)ρ'(1) > e^r이면 오류확률이 0에서 유계, < e^r이면 (충분히 작은 초기오류에서) 0으로 수렴 - threshold를 bound/결정하는 가장 강력한 도구.
  7. 부수: 채널별 e^r 값 명시(BEC/BSC/AWGN).
  8. 최적화 절차: degree sequence pair (λ,ρ)를 최적화해 다양한 rate·채널에서 용량 근접 threshold를 갖는 앙상블 도출.
  9. 결과: rate 1/2 AWGN에서 threshold가 용량 0.06dB 이내; 길이 10^6 코드가 BER 10^-6에서 용량 0.13dB 이내로 당대 최고 turbo code 능가.
  10. 한계: 점근(무한 길이) 이론 - 유한길이·QC 구조·HW 미고려, 순수 부호설계/threshold 분석.
