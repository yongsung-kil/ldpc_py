B. 알고리즘 요약

  1. LDPC 부호의 Tanner 그래프(이분그래프)에서 short cycle 수와 girth가 waterfall/error-floor 성능을 좌우한다는 배경에서, 주어진 차수열(degree sequence)로 short cycle을 최소화하거나 girth를 최대화하는 문제의 계산복잡도를 다룸.
  2. 기존 PEG(progressive-edge-growth) 알고리즘은 양쪽 노드의 차수열을 엄격히 강제하면 girth가 작아지는 한계가 있음.
  3. 정수 α, β, γ와 차수열 (π, π′)가 주어졌을 때 4-cycle ≤ α, 6-cycle ≤ β, 8-cycle ≤ γ인 단순 이분그래프 존재 여부(Min-Short-Cycles 문제)는 3-Partition 문제로부터의 2단계 다항시간 환원으로 NP-완전임을 증명(Theorem 1, 2).
  4. 반대로 주어진 차수열 π에 대해 girth≥6인 이분그래프 존재 여부는 loopless linear hypergraph의 차수열 특성화(Erdős–Gallai형 조건, Theorem 3)와의 대응을 통해 다항시간에 판정 가능(Theorem 4).
  5. 2-switch (ab,cd)→(bc,ad): 두 에지를 지우고 두 에지를 추가해 노드 차수를 보존하는 연산. 동일 차수열을 갖는 임의의 두 단순 이분그래프는 2-switch들의 열로 서로 변환 가능함을 증명(Lemma 1).
  6. Algorithm 1: 최대거리 노드쌍 u,v와 최소길이 cycle을 찾아 2-switch를 반복 적용, girth 하한 η(m,λ,μ)/2를 보장하는 준다항시간(quasi-polynomial, O(m^{log m+c})) 알고리즘 제시(Theorem 5).
  7. Moore bound 일반화 기반 girth 하한식 η(m,λ,μ) 유도(Lemma 2, Appendix), 그래프 크기에 따라 girth가 로그 스케일로 증가함을 보임.
  8. 국소최적 탈출을 위해 무작위 2-switch(Step 6, 7)를 추가로 적용해 girth를 추가 개선.
  9. 예제: n=4000, m=2000, dv=3, dc=6 조건에서 제안 알고리즘은 g=10 달성(PEG는 차수 강제 시 g=6); Heawood graph(3-regular, n=m=7, g=6, cage) 재구성에도 성공(PEG는 g=4에 그침).
  10. 한계: 알고리즘/이론 결과만 제시되며 실제 부호의 BER, error-floor 시뮬레이션, HW 구현은 전혀 다루지 않음. QC-LDPC 등 구조적 제약 하에서의 적용은 향후 과제로 남김.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
Tanner 그래프 girth/short-cycle 최소화 이론대응 없음Prime ECC는 특정 QC-LDPC PCM이 고정된 시뮬레이터로, H-matrix 설계 단계 자체가 ecc_top.cpp Load_PCM()에 국한되나 본 논문은 그 이전 단계(그래프 이론적 존재성/복잡도)만 다룸
2-switching 기반 girth 개선 알고리즘ecc_top.cpp Load_PCM() (H-matrix 구조 결정 단계, 간접)새 부호를 설계할 때 참고 가능하나 QC 구조(base+circulant shift) 제약을 고려하지 않아 직접 적용 난이도 높음
PEG 알고리즘과의 비교대응 없음Prime ECC는 이미 고정된 H-matrix를 사용하므로 PEG류 구성법 자체가 적용될 지점 없음

적용 가치: 낮음 — 순수 그래프이론/복잡도 결과로 QC-LDPC 특유의 circulant 제약이나 실제 디코더 성능과 무관하며, Prime ECC 3.1의 어떤 모듈에도 직접 대응되지 않음.
