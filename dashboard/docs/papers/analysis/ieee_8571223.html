B. 알고리즘 요약

  1. 대상: (J,L)-regular Tanner QC-LDPC 부호, PCM은 p×p CPM 배열, shift는 p_{j,l}=α^{jL+lJ} mod p, p는 소수·p≡1(mod JL).
  2. 문제: Tanner (3,5)/(3,7)/(3,11)/(5,7) 외 일반 (J,L)의 girth 분포가 미규명이고, p가 소수라 가용 부호가 부족해 실용 rate 확보가 어려움.
  3. 핵심 조건: 길이 2i 사이클 존재의 충분필요조건 Σ(p_{jm,lm}-p_{jm+1,lm})=0 (mod p)(Theorem 1)로 girth를 판별.
  4. Algorithm 1: p=JL+1..U 범위에서 소수마다 primitive (JL)-th root α로 exponent matrix 구성 후 식(3)으로 girth k를 계산, 복잡도 약 O(J^i L^i), i≤6.
  5. girth 분포 법칙: J=2는 L짝수→girth 8, L홀수→대부분 12; J=3,5는 L이 소수면 대부분 12; J=4,6은 최대 girth 8.
  6. 두 conjecture 제시: J|L이면 girth 8(J=2)/6(J≥3); J,L이 서로 다른 소수면 p≥p0에서 girth 12 달성.
  7. 부호 도출 1: column selection — J×L exponent matrix에서 s×t submatrix(대개 첫 s행)를 골라 large girth·최소 shortest-cycle 기준으로 t열 선택.
  8. 부호 도출 2: masking — s×t masking matrix M으로 CPM 일부를 ZM으로 치환해 girth↑·short cycle↓, GF(q) 원소 치환 시 비바이너리 부호 생성.
  9. 결과: (3,6)-regular (1086,545) 코드가 랜덤 선택 대비 error-floor 개선, PaG 부호와 유사 성능이나 10 vs 50 iter 격차 약 0.45dB@1e-7; 비바이너리 예제들은 0.05~0.25dB coding gain.
  10. 한계: HW 미설계, 성능 검증은 대부분 rate 0.5 비바이너리 코드, high-rate binary NAND ECC급 부호에 대한 직접 결과 없음.
