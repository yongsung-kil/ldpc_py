총평: 랜덤 게이트 오류(또는 의도적 랜덤 주입)로 small trapping set을 깨 error-floor를 개선하는 아이디어는 흥미로우나, Gallager B 특화 + 막대한 iteration 비용으로 NAND용 min-sum ECC 직접 이식은 어려움.

B. 알고리즘 요약

  1. 대상: (γ,ρ)-regular binary QC-LDPC (Tanner (155,64), QC N=305/755, Margulis (2640,1320); 대부분 (3,5)-regular, girth 8)를 BSC(α)에서 복호.
  2. 문제: unreliable 로직 게이트가 만드는 계산 노이즈를 보통 해악으로 보지만, 유한길이 코드의 error-floor에서는 오히려 이득이 될 수 있음을 주장.
  3. 디코더: hard-decision Gallager B — CN은 (ρ-1)-input XOR, VN은 (γ-1)-input majority(MAJ). 게이트 고장을 "wire" BSC 모델로: MAJ 실패확률 εMAJ, XOR 실패확률 εXOR로 메시지가 flip.
  4. 핵심 관찰: error-floor 실패의 주원인인 small trapping set을, 랜덤 게이트 오류가 깨뜨려 원래 못 고치던 error pattern을 정정.
  5. 분석 도구: (5,3) trapping set을 2^|T| 상태 Markov chain으로 모델링, CN→VN 메시지 dynamics로 수렴 추적.
  6. Markov 결과: εXOR=0.001이면 상태 1↔2 진동(수렴 실패), 0.01이면 10 iter에, 0.1이면 4 iter에 zero codeword로 수렴 — perfect decoder(ε=0)는 attractor basin에 갇힘.
  7. 채널 vs 게이트 관계: α≫εXOR,εMAJ면 이득 제한, α≪εXOR,εMAJ면 게이트 오류가 오히려 채널오류 정정 방해 → 적정 노이즈 구간 존재. MAJ 고장이 XOR 고장보다 더 해로움.
  8. 개선 트릭: 초기 L1(예 10) iteration은 무고장으로 두고 이후에만 probabilism 적용 → perfect Gallager B를 전 α 구간에서 능가. stochastic XOR/MAJ 게이트로 의도적 랜덤 주입도 가능.
  9. 결과: Tanner (155,64)가 최적 노이즈에서 trapping-set-free LS(155,64) 수준(perfect decoder 대비 1 order↑)에 근접; N=755은 2 orders 개선. 단 큰 L(≥1000) 필요.
  10. 한계: HW 미설계·시뮬만, 이득에 매우 큰 iteration 필요(latency↑), 긴 코드는 mis-correction(오수렴) 비율 무시 못 함, faulty Gallager B = Taylor 메모리 등가.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| Gallager B (XOR/MAJ hard-decision) 복호 | 대응 없음 | 우리는 min-sum message passing, Gallager B/bit-flipping류 미보유 |
| 랜덤 게이트오류로 trapping set 파괴(error-floor) | decoder.cpp LDPC_Decoder() | 아이디어(랜덤 perturbation으로 error-floor 탈출)만 개념 이식 가능, 알고리즘은 재설계 필요 |
| QC-LDPC/Margulis trapping set 구조 | ecc_top.cpp Load_PCM() | trapping-set 관점 코드평가에 참고, 우리 고정 H-matrix와 직접 대응은 아님 |

적용 가치: 낮음 — "랜덤 perturbation으로 trapping set을 깨 error-floor 개선"이라는 통찰은 참고할 만하나, Gallager B 특화 + 이득에 필요한 막대한 iteration(latency)으로 NAND용 min-sum ECC에 직접 이식 가치는 낮음.
