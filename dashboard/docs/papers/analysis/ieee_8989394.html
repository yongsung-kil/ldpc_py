B. 알고리즘 요약

  1. 대상은 LDPC의 Tanner 그래프 같은 (dv, dc) bi-regular 이분그래프에서 girth g보다 짧은(k<2g) k-cycle 개수 Nk를 세는 문제다.
  2. 기존 방법1: directed edge matrix Ae의 스펙트럼 {ηi}로 Nk = Σ ηi^k/(2k) (Theorem 1) — 일반 그래프 적용 가능하나 복잡도 O(|E|^3).
  3. 기존 방법2: adjacency spectrum {λi}+차수분포로 계산 — O(|V|^3)로 저렴하나 k≥g+6에서 재귀식이 매우 번잡.
  4. 본 논문 목표: {λi}에서 {ηi}를 직접 유도해 방법1 정확도 + 방법2 복잡도(O(|V|^3))를 동시에 얻는다.
  5. 보조행렬 A(|V|^2×|V|^2, 식(2))를 정의하고 Ae가 그 부분블록임을 보임(Lemma 1: 나머지 고윳값은 0).
  6. 핵심식: A의 음이 아닌 고윳값 λ에 대해 ξ^2 + (-λ^2 + q1 + q2)ξ + q1q2 = 0 (식(8), q1=dv-1, q2=dc-1)의 두 해가 A^2의 고윳값이 됨(Lemma 2).
  7. Lemma 3~4로 A^2(=Ae^2) 고윳값 ξ에서 Ae의 고윳값 ±√ξ를 복원.
  8. Theorem 2: {λi}로부터 Ae의 전체 스펙트럼을 3단계로 구성 — (1)음의 λ마다 식(8) 두 해, (2)±√(-q1), ±√(-q2) (multiplicity는 Rank(A) 기반), (3)±1 (multiplicity |E|-|V|+1).
  9. 결과: 완전 이분그래프 Km,n 예제로 N4=(m-1)(n-1)mn/4, N6 등 기존 문헌과 일치 검증. 복잡도가 O(|E|^3)에서 O(|V|^3)로 감소.
  10. 한계: 순수 이론(증명은 [9]로 미룸), bi-regular 전용, HW/시뮬 없음, 부호설계·복호성능에 직접 개입하지 않음.
