B. 알고리즘 요약

  1. 시스템: 길이 nE=1944, rate RE=1/2의 LDPC 부호워드에 마커 부호를 매 d(=27,57) 비트마다 삽입한 연접부호, 이진 IDS(삽입/삭제/치환) 채널.
  2. 문제: BCH/RS/LDPC는 삽입·삭제 오류를 못 잡고, 기존 마커 코딩은 마커 패턴을 결정론적으로 고정해 미스싱크에 취약.
  3. 채널 모델: 삽입확률 Pi, 삭제확률 Pd, 전송확률 Pt=1-Pi-Pd, 치환확률 Ps, 최대삽입길이 lI.
  4. 핵심 기법: 각 마커의 첫 비트·끝 비트를 이웃 LDPC 부호워드 δ비트에 따라 조건부 반전(적응 마커). δ=마커의 shift resistance.
  5. shift resistance δj: 마커를 자기 자신과 자리이동해 비교, 일치하지 않는 최소 이동량으로 정의(예: (1,1,1)→1, (1,0,1)→2).
  6. 마커 집합 확장: W = W1∪W2∪W3∪W4 (첫/끝 비트 반전 조합)으로 미스싱크 확률 저감.
  7. 복호: forward-backward(FB) 알고리즘으로 그리드 상 동기화 경로의 심볼별 우도 P(r|ct=x) 계산, 마커 종속 구간은 α,β를 δ비트 결합 계산(식 4~7).
  8. FB 출력 LLR을 LDPC 복호기의 soft 입력으로 전달(연접 구조).
  9. 결과: Pi=Pd=0.01, Ps=0.01, rate 0.44에서 기존 BER 9.29e-4 → 제안 2.67e-4. nS=4는 adaptive2, nS=3은 adaptive1이 우수.
  10. 한계: HW 미설계, 시뮬만, BPM/IDS 채널 특화. 최적 base marker 결정과 FB 복잡도 저감은 향후 과제.
