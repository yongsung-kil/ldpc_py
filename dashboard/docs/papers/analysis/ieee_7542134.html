B. 알고리즘 요약

  1. 시스템: 100~400Gbps OTN용 soft-decision LDPC FEC, 30000~60000bit 랜덤구조 비정규 LDPC, OH 6.7%~33.3% (rate 0.667~0.933).
  2. 문제: 기존 NMSA(normalized min-sum)는 OTN급 초고처리량·초저전력 요구를 만족시키기 어려움 (면적/에너지 과다).
  3. 채널모델: BPSK + AWGN, BER 목표 10⁻¹⁵ (error floor 회피가 핵심 요구).
  4. 핵심기법: Adaptive Degeneration(AD) 알고리즘 - IDB(improved differential binary)의 개선판. VN 메시지 b_{v→c}는 M_v의 부호비트 1개만 생성해 전체 이웃 CN에 전송 (min-sum 대비 극단적 단순화).
  5. 핵심식: M_v 갱신 시 CN 메시지 합(±1)에 스케일 s를 곱하고 degeneration factor δ를 가감; trapping set 판정은 |cws/s - cu| < δ/s (cws=옳게 만족된 CN 수, cu=불만족 CN 수).
  6. 확장: δ를 상태적응형으로 조절 - 정체(u0=max(u)) & 임계 이하(u0<Tu) & 반복여유(i<im-ℓ) 3조건 동시 만족 시 큰 γ1, 아니면 작은 γ0 사용.
  7. 구현디테일: q=5bit 고정소수점 양자화(1부호+3정수+1소수), s=0.25, γ1=ℓ=3, Tu=64, im=49로 400Gbps 클록 맞춤. RU(Richardson-Urbanke) 인코딩으로 G행렬 대비 100~500배 복잡도 절감.
  8. 최적화: γ1, ℓ, Tu는 브루트포스 탐색 및 시뮬레이션 기반 경험적 결정 (DE/GA 아님).
  9. 결과: (60000,45000) 부호에서 NCG 11.2dB@33.3%OH, 28nm FD-SOI ASIC 합성 400Gbps @ <3pJ/bit, FPGA 실측(3600,3000) 프로토타입으로 BER<10⁻¹⁵까지 error floor 없음 확인.
  10. 한계: NMSA 대비 NCG는 0.55~수 dB 낮음(코딩게인 손실을 감수하는 트레이드오프), 무작위 구조 부호라 FPGA 부분병렬 구현 불가(완전병렬만 가능), non-QC 구조로 라우팅 복잡.

C. Prime ECC 관련 모듈 핀포인트

논문 요소Prime ECC 모듈관련성
AD(IDB 변형) binary message-passing 디코딩대응 없음Prime ECC는 min-sum 기반이며 1비트 sign-only 메시지 패싱 방식과 근본적으로 다른 알고리즘
상태적응형 degeneration factor(트랩핑셋 대응)대응 없음min-sum 계열이 아니므로 δ 개념 자체가 대응되지 않음; error-floor 대책이라는 목적만 유사
q=5bit LLR 양자화channel.cpp Set_LLR_Th()양자화 비트폭 설계 아이디어 참고 가능하나 AD 전용 스케일 파라미터라 직접 이식 어려움
무작위 구조 LDPC + RU 인코딩ecc_top.cpp Load_PCM()Prime ECC는 QC-LDPC 고정 구조라 비-QC 랜덤 구조 부호 설계는 이식 난이도 높음
완전병렬 ASIC 아키텍처대응 없음Prime ECC는 z=32 lifting 기반 부분병렬(HCU/GT) 구조로 완전병렬 설계와 아키텍처 궤가 다름

적용 가치: 낮음 — 광통신向 non-QC 랜덤 LDPC + binary degeneration 디코더로 Prime ECC의 QC-LDPC/min-sum 패러다임과 겹치지 않으며, 이미 확보한 min-sum·조기종료·적응형 LLR 기법과도 중복되지 않는 이질적 접근.
