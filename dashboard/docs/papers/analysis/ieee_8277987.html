B. 알고리즘 요약

  1. 시스템: b×Z 배열 스토리지(Z=디바이스 수, b=디바이스당 비트)에 코드워드 저장, 최대 r개 column이 소거확률 ε로 실패하는 2DAE(2차원 배열 소거) 채널.
  2. 문제: root-LDPC 기반 기존 방식은 정보비트만 복호 가능·다양한 rate 구성 곤란, long-burst 소거에 SC-LDPC가 취약.
  3. 핵심 아이디어: check node constraint 제약(한 체크노드의 인접 VN이 모두 서로 다른 column/device에 속하도록)을 SC-LDPC 구성에 적용 → 한 column 실패가 한 제약에서 다중 소거를 만들지 않음.
  4. 코드 구성 (c,d,L,Z): 코드워드 비트를 배열에 row-by-row 배치, 각 체크노드의 VN 디바이스 인덱스 ψj를 길이 Z 랜덤순열로 배정해 제약 만족.
  5. induced graph: 실패 column 집합 R에 대한 부분그래프의 induced degree distribution을 다변량 초기하분포 Ti로 유도 (식 3,11).
  6. density evolution: induced joint degree distribution ρ̃j, R̃m로 소거확률 x,y를 교대 갱신(식 13,14), 모든 메시지가 0으로 수렴하는 최대 ε를 BP threshold로 정의.
  7. MAP threshold: EBP EXIT 곡선을 수치적분해 산출, 제안 코드의 BP threshold가 이에 근접함을 확인.
  8. 설계 시사: (c,d)가 작을수록 2DAE에서 1D-2D 격차가 커 유리 → 작은 (c,d) SC-LDPC 권장.
  9. 결과: (3,6,L), (Z,r)=(12,7)에서 2D-SC-LDPC BP threshold가 1D 대비 상승(예 표 I: 0.8368→0.8511), BER 시뮬(N=43200,172800)에서 2D가 1D를 능가.
  10. 한계: 소거 채널·RAID 스토리지 전용, AWGN/soft-read 무관, HW 미설계, threshold/BER 시뮬만.

C. Prime ECC 관련 모듈 핀포인트

| 논문 요소 | Prime ECC 모듈 | 관련성 |
|---|---|---|
| 2D-SC-LDPC 부호 구성 (check node constraint) | 대응 없음 | Prime ECC는 고정 binary QC-LDPC, SC-convolutional/2D-array 구조 아님 |
| 2DAE erasure density evolution | 대응 없음 | 채널이 AWGN/RBER/fixed-error(channel.cpp)와 달리 column-failure 소거 |
| SC-LDPC threshold 분석 | 대응 없음 | SC-LDPC/threshold saturation 이론은 코드베이스와 무관 |

적용 가치: 낮음 — 2차원 배열 소거 채널을 겨냥한 SC-LDPC 구성·threshold 이론으로, NAND용 고정 binary QC-LDPC의 부호설계→디코더→HW와 채널 모델·부호 구조 모두 상이하여 떼어 쓸 요소가 없음.
