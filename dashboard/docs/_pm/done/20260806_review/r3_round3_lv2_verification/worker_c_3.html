  • ㉯ 개정본 Input/LLR/에 프로파일 데이터가 0개 → 데이터 자산 손실 없음
  • ㉰ 개정본은 이미 채널 magnitude 통로를 끊어 CH_HD가 무시되므로(H2 부록), 존치해도 반쪽 기능
