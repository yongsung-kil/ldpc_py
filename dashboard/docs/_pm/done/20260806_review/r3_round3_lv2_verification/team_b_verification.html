team_b: 디코더, 데이터 검증 (Round 3, lv2)

담당 발견: F2 (HIGH), F8 (MEDIUM), F11 (MEDIUM), F14 (MEDIUM) 워커: worker_b_1 (F2), worker_b_2 (F8, F14), worker_b_3 (F11) 검증 방식: 원본 C++ 원문 직접 재확인 + 스크래치패드 실증. Round 2 결론은 전제로 쓰지 않았다.

1. 가설 목록

각 발견을 "무엇이 참이면 Round 2 서술과 처방이 옳은가"의 형태로 형식화했다.

#가설참이면거짓이면
H2-AC++도 5-bit 채널값(ch)과 3-bit edge값(EDGE_MAG)을 같은 가산기에 섞으며, ch 범위를 막는 검사나 클리핑이 없다F2는 구현 결함이 아니라 데이터 문제F2는 Python의 도메인 불일치 구현 결함
H2-B처방 ch > edge_mag[0] * dv 검사가 정당한 파일을 오탐하지 않고, 부등식이 반전 불가의 필요조건으로 엄밀하다처방 유효처방 수정 또는 폐기
H2-CREADME:114-117 서술이 위 확인과 부합한다문서 유지문서 수정
H8-AC++는 비단조 th를 검사 없이 받아 캐스케이드 의미로 소비한다갈래 1(검사, 거부)은 C++이 받는 파일을 거부하므로 부적절, 갈래 2(캐스케이드 교체)가 옳다갈래 1도 성립
H8-B캐스케이드 교체의 성능 비용이 수용 가능하다갈래 2 채택 가능갈래 1 재검토
H11-Arestart가 마지막 iteration이어도 C++과 Python 모두 정상 판정을 낸다"restart 마지막 금지" 제거 안전제약 유지
