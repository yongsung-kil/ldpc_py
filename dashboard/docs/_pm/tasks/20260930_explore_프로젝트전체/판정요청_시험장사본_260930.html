판정요청: 시험장 사본에서 드러난 결정거리 세 가지

작성: 2026-09-30 03:20:00

  • ㉮ 답하는 법: 물음 끝의 % 줄에 번호를 적는다 (예: %1). 덧붙일 말은 번호 뒤에 적는다.
  • ㉯ 예시의 값은 전부 실제 기록이다 (2026-09-30 온보딩 때 이 저장소에서 실행하고 읽은 것. 온보딩은 저장소를 처음 읽어 안내 문서를 만드는 작업이다).
  • ㉰ 답하지 않는 동안: 물음 1은 아무것도 바꾸지 않은 상태(3️⃣)다. 물음 2와 3은 지금 글 그대로(각각 2️⃣와 1️⃣)다. 급한 물음은 없다. 새 디코더 변형 실험을 이 사본에서 돌리려 할 때 물음 1이 필요해진다.

물음 1. 이 사본에서 변형 디코더 실험을 돌릴 수 있게 실험 폴더의 실행 파일(run.py)을 고칠지 정한다

변형 디코더는 기본 디코더 클래스(BaseDecoder)를 상속해 계산 단계 일부만 바꿔 끼운 자식 클래스다. 실험 폴더는 workspace/ 아래 다섯 개(_template, base_run, test, matrix_sel_1_HD, matrix_sel_1_HD_fixed)이고, 각 폴더의 run.py(런처: 설정 파일을 읽어 본체 코드를 부르는 짧은 파이썬 파일)는 내용이 같다.

  • 🔎 예시: 2026-09-30 02:55, workspace/test/ 폴더에서 python run.py를 실행했다
    • 실행 파일이 조상 폴더(위로 올라가며 만나는 상위 폴더들)를 차례로 보며 2_LDPC_base/src 폴더를 찾는다 (workspace/test/run.py:12)
    • 이 저장소의 폴더 이름은 ldpc_py라 어느 조상 폴더에도 그 폴더가 없다
    • 화면에 이 글이 나오고 끝난다: 상위 폴더에서 2_LDPC_base/src를 찾지 못함 (이 파일은 LDPC_dev 하위 실험 폴더에 있어야 함)
    • 같은 날 03:01, 저장소 루트에서 python -m src.run <설정 파일>로 돌리면 정상 동작한다 (32프레임, 약 2.7초. 프레임은 부호 블록 하나를 보내고 복호하는 단위다). 그러나 이 명령은 기본 디코더만 쓴다. 변형 디코더를 받을 자리가 없다 (src/run.py:794-795)
    • 1️⃣ 이면: 다섯 run.py의 12행 조건에 "이 저장소의 src/run.py가 있는 조상 폴더"도 허용하도록 한 줄을 더한다. python run.py가 이 사본에서도 원본 배치(원래 폴더 구조 LDPC_dev/2_LDPC_base)에서도 동작한다. 변형 디코더는 run.py 안의 DECODER_CLASS 변수(어느 디코더 클래스를 쓸지 적는 자리)에 이름을 적어 넣는다
    • 2️⃣ 이면: 기존 run.py는 그대로 둔다. 저장소 루트를 찾아 넣는 새 실행 파일 하나(예: workspace/run_local.py)를 더한다. 변형 실험은 python ../run_local.py config.json처럼 새 파일로 돌린다. 원본 배치에는 이 새 파일이 없어 실험 폴더마다 실행 명령이 원본과 달라진다
