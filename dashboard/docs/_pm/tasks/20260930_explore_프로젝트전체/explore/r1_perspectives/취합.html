프로젝트 전체 탐색 취합 (r1)

작성: 2026-09-30 03:02. 탐색 작업자 A(아키텍처), B(데이터 흐름과 기법), C(컨벤션과 제약), D(의존성) 보고를 합쳤다. 경로는 저장소 루트 기준, 파일:줄은 그 파일의 줄 번호다. 메인이 직접 확인한 것은 "[메인 확인]"으로 표시했다.

개요

Python으로 짠 QC-LDPC(quasi-cyclic low-density parity-check, 순환 시프트 블록 구조의 저밀도 패리티 검사 부호) 복호 시뮬레이터다. 원본 C++ 시뮬레이터(Ref-C)의 DAO(decoder auto optimizer) 연동 빌드가 쓰는 syndrome-aided quantized min-sum 디코더를 numpy 프레임 배치로 재현하고, 채널 3종으로 FER(frame error rate, 프레임 에러율)를 측정한다. 목적은 후보 기법의 on/off 상대 비교이며 C++와의 절대 FER 일치는 보장하지 않는다 (README.md:4, 215). 디코더 변형은 src/를 고치지 않고 BaseDecoder를 상속한 자식에서 교체 지점 함수 6개만 재정의한다 (README.md:161-162, src/decoder.py:40-46).

모듈과 import 방향

run → {channel, encoder, decoder, llr_matrix, pcm, sim}, sim → decoder. 나머지 다섯(pcm, encoder, channel, llr_matrix, decoder)은 numpy만 import하는 잎 모듈이고 서로 import하지 않는다. decoder는 QCCode와 LLRMatrix 객체를 생성자 인자로 받아 결합한다 (src/decoder.py:100-118). 순환 없음. src/__init__.py:6-10의 공개 API는 QCCode, BaseDecoder, channel, encoder, sim이고 run과 llr_matrix는 __all__에 없다.

  • ㉮ H-matrix (src/pcm.py:58-82): 형식은 N_b M_b / J K / z / 빈 줄 / M_b×N_b shift 행렬 (-1은 zero block). lines[3:]를 이어 붙여 앞 M_b*N_b개만 쓰므로 행렬 뒤 내용은 무시된다. 확장자 검사 없음. 메모리에서는 base (M_b, N_b) int32와 column 우선 정렬 edge 배열 edge_row, edge_col, edge_shift (E,), col_edges (N_b개 리스트), row_deg, col_deg. edge (i, j, s)에서 VN 정렬 → CN 정렬은 np.roll(v, -s), 반대는 +s (src/pcm.py:4-5).
  • ㉯ LLR_MATRIX (src/llr_matrix.py:230-283): 순서대로 num_param / num_dv / dv_from / dv_to / num_group / num_row_each_group / type_each_group / num_restart / [restart_iter] / max_value / min_value / row들. row = [dv별 (ch..., th...)] + CSW + iter_start + iter_end + floor. 모드(HD/2SD/3SD)는 파일명 정규식 LLR_MATRIX_(HD|2SD|3SD)_로 판별 (:48, :237-241), ch 개수는 HD 1 / 2SD 2 / 3SD 4 (:45), th 개수 = num_param − ch. 사람이 만든 파일은 th 3개(3-bit, edge 레벨 {7,5,3,1}) 전용이고 아니면 NotImplementedError (:136-142). max_iter = 마지막 row의 iter_end (:162). _validate(:172-226)가 그룹 구간 겹침 금지, 1..max_iter 빈틈 금지, restart 그룹 단일 row를 검사한다.
  • ㉰ 균일 생성 경로: use_input_llr_matrix=false면 edge_quantization_levels(bits, max)(:60-89)로 레벨을 만들고 make_internal_uniform_matrix(:285-316)로 그룹 1개 ITER 매트릭스를 합성해 output.dir/_generated/LLR_MATRIX_{mode}_uniform_...txt로 저장한 뒤 같은 load로 다시 읽는다 (src/run.py:412-441). 두 경로가 "파일 로드" 하나로 합류한다.

config JSON (src/run.py:270-390)

base_dir = dirname(abspath(config))이 모든 상대 경로의 기준 (:277). 허용 키 집합 8개(:98-111)로 키맵 검사, _로 시작하는 키는 무시 (:120-122). 정규화 결과: H_matrix와 decoder.llr_matrix는 경로 문자열로 대체, output.dir 기본 base_dir/Sim_Output, config["seed"] 최상위 승격 (:357), log는 {"enabled", 항목 7개}로 평탄화 (:385-387), channels는 [{"type", "points", (SER, SCR)}] 리스트로 (:183-247). run 섹션 기본값 _RUN_DEFAULTS(max_frame_errors 50, max_frames 20000, frames_per_batch 128, progress_interval_frames 100, :116-117)는 검증, 소비(:557-563), 요약(:486-489) 세 곳이 같은 dict를 읽는다. 다른 기본값은 setdefault 인라인 (use_input_llr_matrix True :292, mode "HD" :299, edge bits 3 max 7 :260/:267, save_llr_matrix True :346, print_progress True :361, log.enabled True :374).

시뮬레이션 루프 (src/sim.py:29-167)

while frames < max_frames and errors < max_frame_errors (:95). 배치마다 channel_fn(batch, rng) → decoder.decoder_main(channel_out, log) → 집계 (errors, iter_hist, iteration 합계, 실패 프레임 상세). 진행 줄은 progress_interval_frames마다 콘솔 \r 갱신(tty일 때만)과 summary.txt 꼬리 제자리 갱신 (:21-26, :121-137). 결과 dict(:142-161)는 frames, errors, fer, post_fec_ber, avg_decoding_iteration, sec, iter_hist 등. stop_below_fer는 sim이 아니라 run_experiment의 포인트 루프에서 판단한다 (src/run.py:597-598). 난수는 포인트마다 np.random.default_rng([seed, channel_index, int(1e6*point)]) (src/run.py:586)이고 메시지 생성과 채널이 순서대로 소비하므로 같은 수치 재현에는 frames_per_batch까지 같아야 한다 (README.md:120-121).

채널 (src/channel.py)

공통 출력 dict {"mode", "hd", "sd", "cc"} (:9-11), hd는 (B, N_b, z) uint8 read bit. rber_channel(:43-68)은 RBER를 역 Q함수로 σ 환산, BPSK+가우시안, HD/2SD/3SD 지원 (_R_OFFSET 2SD (0.35,), 3SD (0.15, 0.35, 0.55), :21). fixed_error_channel(:78-88)은 HD 전용으로 프레임마다 정확히 E개 flip. strong_error_channel(:91-135)은 2SD 전용으로 SER, SCR 비율에 따라 strong/weak 배치. 모드 호환은 run.py _check_channel_mode(:504-512)가 측정 전 전 채널을 사전 확인하고, 디코더도 _read_channel_input(src/decoder.py:230-232)에서 다시 대조한다.

디코더 (src/decoder.py)

  • ㉮ 상태 _DecodeState(:54-96): 프레임 데이터 read_bit, decision_bits (B, N_b, z) uint8, syndrome (B, M_b, z) 1회 계산 후 유지, prev_csw (B,), region (SD만), seed_mag (SD만); CN 상태 min1, min2 (B, M_b, z) float32 초기 RESET = edge_mag[0], min1_pos (B, M_b, z) int32 초기 −1, check_sum (B, M_b, z) uint8, edge_sgn (B, E, z) uint8; 결과 버퍼 success, decode_success_iteration, final_err_bits, final_info_err_bits 등. B는 활성 프레임 수로 성공 프레임이 제외되며 줄어든다.
  • ㉯ _run_iteration(:336-370): _is_edge_clear_iter → True면 CN 상태 클리어(syndrome 유지, :343-349) → SD restart면 Pre 재실행 후 return (:350-359) → llr_matrix.row_index(iteration, prev_csw)로 프레임별 ch, th 선택 (:360-363) → for col in _column_order(iteration): _process_column (:365-366) → _collect_error_metrics → prev_csw = Σ(check_sum ⊕ syndrome) (:368-370).
  • ㉰ _process_column(:372-413): sum_t = 채널 항(항상 +, HD는 cur_ch[:, dv_idx], SD는 region으로 ch 열 선택) + Σ roll(+shift)한 C2V → flip = _vn_decide(sum_t) (sum_t <= 0, 동점 반전) → decision_bits = read_bit ^ flip → edge마다 _vnu_quantize(sum_t − vnu_in, vnu_in, th) (캐스케이드 |raw| >= th_k → edge_mag[k], 균일 레벨이면 _uniform_saturate) → roll(−shift) → _cnu_update (remove old, insert new with <=, 새 min1이면 min2=RESET).
  • ㉱ 성공 판정(genie): decision_bits[:, :N_b−M_b, :]가 전부 0이면 성공 (정답 all-zero 전제, :316-334). _check_errors(:433-452)가 성공 프레임을 확정하고 배치를 압축한다.
  • ㉲ SD Pre 단계 _seed_channel_magnitudes(:294-314): 2SD [5,1], 3SD [7,5,3,1] 고정 상수(C++ 대응, :122-123, :134)를 CN에 심는다.
